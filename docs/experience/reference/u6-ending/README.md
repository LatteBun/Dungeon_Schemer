# U6 엔딩 화면 레퍼런스

팀에서 공유한 엔딩 화면 시안이다. `U6EndingScreen` 은 이 구성을 따른다.

## 파일

| 파일 | 엔딩 |
| --- | --- |
| `ending-completed.png` | 원정 종료 |
| `ending-distrust.png` | 불신의 대가 |
| `ending-denounced.png` | 누적 고발 |
| `ending-exhausted.png` | 인력 소진 |
| `ending-unemployed.png` | 실직 |

## 구성

셸의 3:2 열을 쓰지 않는다. 캠페인이 끝난 화면이라 전체를 하나의 그림으로 쓴다. 인트로(`U2`)가 같은 이유로 전체 폭을 쓰는 것과 같다.

```text
                 ✦ 캠페인 종료 ✦
                    원정 종료                 ← 표제. 화면에서 가장 크다
        당신은 길을 안내했지만, 결국 …          ← 부제

  ┌─ 결말의 이유 ─┐      최종 등급        ┌─ 원정 보고서 ─┐
  │ ◆ 이유 1      │      ⬢ 문양          │ ✓ 항목 1      │
  │ ◆ 이유 2      │                     │ ✓ 항목 2      │
  │ ◆ 이유 3      │                     │ ✓ 항목 3      │
  └───────────────┘                     │ ✓ 항목 4  🔴  │
                                        └───────────────┘
  ┌─ 최종 결과 ─┐ ┌─ 당신의 캠페인 ─┐ ┌─ 주요 업적 ─┐
  │ 생존    9   │ │ 누적 조언 106회 │ │ ⬡ 완벽한 정복 │
  │ 사망    6   │ │ 전멸 원정  3회  │ │ ⬡ 명예로운 귀환│
  │ 명성  148   │ │ 전환점 …        │ │ ⬡ 전우와 함께 │
  │ 골드  382   │ │ 연대기 요약 …   │ │ ⬡ 길드의 영광 │
  └─────────────┘ └─────────────────┘ └───────────────┘

        ❝ 당신은 길을 안내했지만, … ❞
        ┌──── 길드 게시판으로 돌아가기 → ────┐
```

## 엔딩마다 바뀌는 것

표제·부제·배경 그림뿐 아니라 **오른쪽 문서와 세 번째 패널의 제목이 함께 바뀐다.** 결말의 성격을 이름으로 먼저 말하기 때문이다.

| 엔딩 | 오른쪽 문서 | 세 번째 패널 |
| --- | --- | --- |
| 원정 종료 | 원정 보고서 | 주요 업적 |
| 불신의 대가 | 최후 보고서 | 무너진 관계 |
| 누적 고발 | 길드 판결문 | 누적 기록 |
| 인력 소진 | 길드 현황 | 남겨진 자리 |
| 실직 | 게시판 상태 | 닫힌 게시판 |

## 앞선 구현과 다른 점

- 상단 상태 바를 두지 않는다. 캠페인이 끝나 더 볼 자원이 없다.
- 원정 연대기를 15줄로 나열하지 않고 **두세 문장의 산문 요약**으로 둔다.
- 결말의 이유가 한 문장이 아니라 **세 줄**이다.

## 아직 없는 자산

엔딩별 배경 그림 4종과 가운데 문양(깨진 악수, 저울 봉인, 세 사람)이 자산 묶음에 없다. 지금은 `emblems/` 와 `ranks/` 에 있는 것으로 대신하고, 그림이 들어오면 `--u6-ending-backdrop` 만 바꾸면 된다.
