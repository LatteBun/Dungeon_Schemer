# 온보딩과 인터페이스

## 목적

처음 게임을 실행한 플레이어가 30초 안에 자신이 고블린 던전 길잡이라는 사실과 캠페인의 목표를 이해하게 한다. 화면은 정보·신뢰·생존·명성·골드의 연결을 숨기지 않아야 한다.

## 30초 온보딩 목표

플레이어는 첫 공고를 고를 때까지 다음 내용을 이해해야 한다.

- 나는 직접 싸우지 않는 고블린 길잡이다.
- 목표는 던전 15개를 모두 클리어하며 S급을 노리는 것이다.
- 현재 명성은 지원 가능성과 승급 점수에 영향을 준다.
- 파티원은 각자 다른 HP·성격·신뢰·소지 골드를 가진다.
- 파티를 살리거나 위험에 빠뜨리는 선택이 모두 가능하다.

긴 설명 화면 대신 첫 게시판과 계약 비교에 설명을 붙인다. 첫 던전의 정보 전달 기회에서는 진실·거짓·중립이 각 파티원에게 다르게 받아들여지는 모습을 즉시 보여준다.

## 화면 흐름

| 화면 | 역할 |
| --- | --- |
| 공고 게시판 | 최대 5개 던전·파티 계약 비교와 지원 가능 여부 확인 |
| 계약·파티 확인 | 출전 인물과 전체 지도·위험 성격 확인 |
| 던전 지도 | 현재 위치, 전체 경로, 사건, 정보 전달 기회 선택 |
| 정보 전달 | 진실·거짓·중립 카드와 파티원별 반응 표시 |
| 사건 | 지원·방해·아이템·거래·관망 행동 선택 |
| 보스전 | 앞선 정보와 행동이 자동 전투에 미친 영향 표시 |
| 정산 | 생존·신뢰·보상·던전·파티·승급 변화를 순서대로 설명 |
| 캠페인 엔딩 | 완주 등급 또는 조기 종료 원인과 주요 선택 요약 |

## 캠페인 공통 헤더

탐험 중에도 다음 캠페인 정보를 잃지 않게 한다.

- 영구 길잡이 등급
- 현재 명성과 다음 공고 지원 상태
- 현재 골드와 누적 획득 골드
- 현재 승급 점수와 다음 등급 기준
- 남은 던전 수

현재 명성이 내려가도 영구 등급은 유지된다는 점을 서로 다른 표시로 구분한다.

## 공고 게시판

각 공고는 계약 전에 다음을 보여준다.

- 던전 등급·번호와 실패로 상승한 이력
- 지원 최소 명성과 지원 가능 여부
- 3명 생존 기준 명성·골드 보상
- 지도 지점 수와 대략적인 위험
- 연결된 파티원별 직업·성격·HP·신뢰·소지 골드

명성이 부족한 공고는 숨기지 않고 비활성 상태와 부족한 수치를 보여준다. 모든 공고가 막히면 왜 캠페인이 종료됐는지 설명한다.

## 던전 지도

지도는 아래 입구에서 위 보스방으로 진행한다. 두 갈래는 보스 전 공통 지점에서 합쳐진다.

도착 전 공개:

- 전체 연결 구조와 보스 위치
- 사건 제목·분류와 대략적인 위험
- 정보 전달 기회가 있는 지점

도착 전 비공개:

- 정확한 피해·보상과 난수 결과
- 진실·거짓·중립 카드의 구체적인 내용

지나온 경로, 현재 위치, 선택 가능한 다음 지점을 시각적으로 구분한다.

## 정보 전달 화면

이 화면은 모든 지점이 아니라 시드로 정한 일부 지점에서 사건 전에 열린다.

카드 선택 전에는 다음을 보여준다.

- 카드가 다루는 사건·몬스터·보스 정보
- 진실·거짓·중립 유형
- 알려진 이득과 발각 위험
- 살아 있는 파티원별 현재 신뢰와 성격

카드 유형은 색상만으로 구분하지 않고 텍스트·아이콘·형태 단서를 함께 사용한다. 선택 뒤에는 각 파티원의 수용·의심·적발과 효과 적용 여부를 따로 보여준다.

## 사건과 상인

정보 전달 뒤에도 사건 행동을 별도로 고른다. 선택지는 행동 대상, 예상 이득, 알려진 위험을 함께 표시한다.

상인 화면은 현재 골드로 정보·치료제·독·가짜 지도 등을 구매한다. 구매 뒤 현재 골드는 줄지만 누적 획득 골드와 승급 진행은 줄지 않는다는 점을 피드백한다.

## 보스전과 정산

보스전은 조작 화면이 아니라 누적 선택의 결과 화면이다. 파티원별 최종 피해 옆에 다음 원인을 연결한다.

- 수용한 보스 정보 카드와 피해 보정
- 사건·아이템 효과
- 거짓 또는 의심의 사후 검증

정산은 숫자만 나열하지 않고 다음 순서로 보여준다.

1. 생존자와 사망자
2. 개인 신뢰 변화와 이유
3. 계약 보상 또는 전멸 손실·유품
4. 던전 제거 또는 등급 상승
5. 승급 점수와 등급 변화
6. 파티 유지·충원·재편·비출전 회복
7. 다음 게시판 또는 엔딩 원인

## 캠페인 엔딩

엔딩 화면은 이름과 함께 판정 원인을 표시한다.

- `불신의 대가`
- `원정 종료`와 최종 C·B·A·S 등급
- `길잡이 자격 박탈`
- `용사들의 시대가 끝나다`

정상 완주에서는 생존시킨 파티, 전멸시킨 파티, 획득한 명성·골드와 대표적인 정보 선택을 요약해 `S급 목표를 위해 무엇을 했는가`에 답하게 한다.

## 프로토타입 범위 밖

- 최종 아트 스타일과 애니메이션
- 저장·복원과 계정 UI
- A급 4인·S급 5인 파티 레이아웃
- 고유 던전·보스 서사 화면
