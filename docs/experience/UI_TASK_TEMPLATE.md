## 12. 에셋보드 사용 규칙

- 에셋보드에 이미 쓸 수 있는 자산이 있으면 먼저 추출한다.
- 새로 생성할 때도 보드의 스타일, 시점, 조명, 재질을 계승한다.
- 작은 보드 crop을 대화면에서 과도하게 확대하지 않는다.
- 실제 UI 슬롯에 맞는 별도 고해상도 자산이 필요하면 다시 제작한다.

## 13. 고정 캔버스 요구사항

화면은 1920×1080 고정 캔버스 안에서 그린다. 필수 테스트는 창 비율 네 가지다.

- 1920×1080, 2560×1440 (16:9 — 레터박스 없음)
- 1440×900 (16:10 — 위아래 띠)
- 1280×1024 (5:4 — 위아래 두꺼운 띠)

절대 발생하면 안 되는 것:

- 가로·세로 스크롤
- 창 크기에 따라 줄바꿈이나 배치가 달라짐
- 카드 밖 텍스트 overflow
- CTA 잘림
- 이미지 비율 왜곡
- 아이콘/라벨 행 정렬 깨짐
- 새 `vw`·`vh`나 미디어 쿼리 추가

화면의 최상위 DOM 요소는 네 viewport 모두에서 `.game-canvas`와 같은 실제
폭·높이를 가져야 한다. 내부 패널과 배경의 의도적인 여백은 허용하며, 내부
요소를 무조건 화면 끝까지 늘리는 요구가 아니다. 전체 점유 예외가 필요하면
구현 전에 별도 spec과 테스트에서 이유와 기대 크기를 승인받는다.
