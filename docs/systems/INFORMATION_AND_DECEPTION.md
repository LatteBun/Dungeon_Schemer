# 정보와 기만 시스템

## 목적

정보와 기만은 고블린 길잡이가 전투 전에 결과를 바꾸는 핵심 수단이다. 플레이어는 일부 일반 지점에서 사건이 시작되기 전에 용사 파티에게 진실·거짓·중립 정보 중 하나를 전달한다.

## 대상과 주제

카드를 받는 대상은 살아 있는 용사 파티원뿐이다. 보스에게 파티 정보를 제공하거나 보스와 거래하지 않는다.

카드의 주제는 다음을 포함할 수 있다.

- 다음 경로와 현재 사건의 위험
- 몬스터의 약점과 행동
- 휴식처와 상인에 관한 정보
- 보스의 약점, 공격 방식과 함정

`보스 관련 정보`는 보스에게 주는 카드가 아니라 파티에게 보스에 관해 알려주는 카드다.

## 정보 전달 기회

카드는 모든 지점에서 나오지 않는다. 실제 선택 경로에서 다음 횟수를 보장한다.

| 던전 등급 | 전체 정보 전달 | 그중 보스 관련 정보 |
| --- | ---: | ---: |
| C | 2 | 1 |
| B | 3 | 1 |
| A | 4 | 2 |
| S | 5 | 2 |

방문하지 않은 갈림길의 카드는 횟수에 포함하지 않는다. 지도에는 정보 전달 기회가 있는 지점을 표시하지만 카드의 구체적인 내용은 도착할 때 공개한다.

```text
지점 선택
→ 정보 전달 기회가 있으면 카드 한 장 선택
→ 살아 있는 파티원별 반응과 즉시 효과
→ 실제 사건 진입
→ 사건별 행동 선택
```

정보 전달은 사건 행동을 대체하지 않는다.

## 카드 유형

### 진실

- 실제 상태와 일치한다.
- 수용되면 안정적인 전술 효과와 신뢰 상승을 제공한다.
- 의심받으면 정보 효과를 적용하지 않고 이후 결과를 검증한다.

### 거짓

- 실제 상태와 다르다.
- 수용되면 파티의 판단을 크게 왜곡하고 일시적으로 신뢰를 얻을 수 있다.
- 즉시 적발되거나 이후 사실이 드러나면 개인 신뢰가 하락한다.

### 중립

- 사실을 전부 밝히지 않지만 명백한 거짓도 아니다.
- 수용되면 진실보다 약한 효과를 준다.
- 즉시 신뢰를 바꾸지 않는 비교적 안전한 선택이다.

## 파티원별 독립 반응

같은 카드를 살아 있는 모든 파티원에게 전달하고, 각 인물은 자신의 신뢰와 성격으로 `수용`, `의심`, `적발`을 독립 판정한다. 사망자는 판정 대상에서 제외한다. `적발`은 거짓에서만 나온다.

기본 확률은 다음과 같다.

| 카드 유형 | 수용 | 적발 | 의심 |
| --- | ---: | ---: | --- |
| 진실 | 70% | 0% | 나머지 |
| 중립 | 55% | 0% | 나머지 |
| 거짓 | 45% | 15% | 나머지 |

| 조건 | 수용 보정 | 거짓 적발 보정 |
| --- | ---: | ---: |
| 신뢰 0~33 | -20 | +15 |
| 신뢰 34~66 | 0 | 0 |
| 신뢰 67~100 | +15 | -10 |
| 의심 많음 | -20 | +20 |
| 정의로움 | 진실 +15, 거짓 -10 | +15 |
| 탐욕스러움 | +10 | -5 |
| 신중함 | -10 | +10 |
| 충동적 | +15 | -10 |

정의로운 성격의 수용 보정은 중립에 적용하지 않는다. 진실·중립의 수용 확률은 5~95%로 제한한다. 거짓은 적발률을 5~80%로 먼저 제한하고 수용률은 5% 이상, `95% - 적발률` 이하로 제한한다.

대상마다 `card` 난수 스트림에서 1~100 정수를 하나 사용한다. 거짓은 적발 구간, 수용 구간, 의심 구간 순으로 판정한다. 신뢰 변화가 필요할 때만 `trust` 스트림을 사용한다.

## 반응 결과

- 진실 수용: 정보 효과 적용, `actHonestly` 신뢰 판정
- 거짓 수용: 정보 효과 적용, `deceptionAccepted` 신뢰 판정, 미검증 거짓 기록
- 중립 수용: 약한 정보 효과 적용, 즉시 신뢰 변화 없음
- 의심: 정보 효과 없음, 의심 검증 기록
- 거짓 적발: 정보 효과 없음, `deceptionExposed` 신뢰 판정

카드 효과는 수용한 파티원에게만 적용한다.

## 보스 관련 정보

수용한 보스 정보는 보스전까지 보관하고 해당 파티원이 받는 보스 피해를 바꾼다.

| 수용한 카드 | 피해 보정 |
| --- | ---: |
| 진실 | -20% |
| 중립 | -10% |
| 거짓 | +25% |
| 의심 또는 즉시 적발 | 0% |

A·S급에서 보스 카드 두 장을 수용하면 보정을 합산한다. 피해 감소는 최대 -30%, 피해 증가는 최대 +50%로 제한한다. 수치는 첫 백테스트 뒤 조정할 잠정 상수다.

보스방에서는 새 카드를 제시하지 않는다. 전투 결과로 수용한 거짓과 의심 기록을 검증하고 신뢰를 갱신한다.

## 미검증 정보와 사후 검증

수용한 거짓은 카드, 대상 파티원, 전달 시점, 적용 효과를 기록한다. 의심 기록은 효과를 적용하지 않은 결과가 그 파티원에게 실제로 이득이었는지 손해였는지를 연결한다.

- 수용한 거짓이 드러남: `deceptionExposed`
- 의심 때문에 손해를 봄: `suspicionWasCostly`
- 의심 덕분에 이득을 봄: `suspicionWasCorrect`
- 인과가 불분명함: 신뢰 변화 없음

검증된 기록은 미검증 목록에서 제거한다. 신뢰 변화량과 성격별 사유는 [파티와 신뢰](PARTY_AND_TRUST.md)의 프로토타입 신뢰 판정을 따른다.

## 피드백 원칙

### 선택 전

- 정보를 받을 파티원과 현재 신뢰·성격
- 카드 유형과 플레이어가 아는 사실
- 예상되는 이득과 발각 위험

### 선택 직후

- 파티원별 수용·의심·적발
- 적용된 효과와 즉시 신뢰 변화 사유

### 사후 검증

- 어떤 과거 정보가 현재 사건이나 보스 피해에 영향을 주었는지
- 거짓 또는 의심이 왜 신뢰를 바꾸었는지

## 생성 오류

실제 모든 경로가 등급별 전체 횟수와 보스 정보 횟수를 충족해야 한다. 카드 콘텐츠가 부족하거나 식별자가 중복되면 조용히 다시 뽑지 않고 생성 오류를 반환한다.

## F2 카드 콘텐츠 계약

`INFO_CARDS` 풀은 주제 6종과 진위 3종의 **모든 조합에 정확히 2개씩**, 총 36개다. 진위별로는 각각 12개이고 `subject === "boss"`인 카드는 6개다. 전체 수량과 진위별 수량은 조합 규칙에서 따라 나오므로 따로 세지 않는다.

조합마다 2개인 것은 A·S급 때문이다. 경로마다 보스 정보 보장이 2회인데 조합당 1개면 두 기회가 모든 시드에서 같은 세 장을 제시한다. 뽑을 것이 없기 때문이다.

보스 주제 카드는 보스에게 전달하는 카드가 아니라 살아 있는 용사 개인에게 보스의 약점·공격 방식·함정을 알려주는 콘텐츠다. 주제 6종에 진위 3종이 모두 채워져야 하는 이유는, 조합이 비면 그 지점에서 제시할 카드가 없어지고 보스 주제의 진위가 비면 그 진위의 피해 보정이 실제 플레이에서 발생하지 않기 때문이다.

카드 주제는 도착한 지점이 정한다. 보스 정보 보장 지점은 `boss`, 첫 갈래 선택 직후 지점은 `route`, 나머지는 사건 분류를 따라 `monster`·`rest`·`merchant`·`event`다. 한 지점은 한 주제만 제시하고 그 안에서 진실·거짓·중립을 한 장씩 고른다. 플레이어가 정하는 것은 `무엇에 대해 말할지`가 아니라 `어떻게 말할지`다.

카드 ID·주제·본문은 중복되거나 비어 있을 수 없다. F2 validator는 카드 수량과 문구를 검증하지만 진실성 판정, 수용·의심·적발 확률, 개인별 반응, 보스 피해 modifier는 계산하지 않는다. 이 데이터 계약과 선언적 태그를 실제 결과로 해석하는 작업은 Task 6~7에서 정한다.

카드 풀이 계약을 만족하지 않으면 조용히 재추첨하지 않고 `RuleError("INVALID_GENERATION")`으로 보고한다. `/f2-test`의 `f2-cards`와 의도적 실패 fixture에서 이 경계를 확인할 수 있다.
