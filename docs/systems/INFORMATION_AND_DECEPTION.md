# 정보와 기만 시스템

## 목적

정보와 기만은 고블린 길잡이가 전투 전에 결과를 바꾸는 핵심 수단이다. 플레이어는 일반 지점에서 사건이 시작되기 전에 용사 파티에게 조언을 건넨다.

플레이어가 정하는 것은 `무엇에 대해 말할지`가 아니라 `어떻게 조언할지`다.

## 대상과 조언

조언을 받는 대상은 살아 있는 용사 파티원뿐이다. 보스에게 파티 정보를 제공하거나 보스와 거래하지 않는다.

한 지점은 상황 묘사와 조언 3개로 이루어진다. 조언은 도움·방해·중립을 한 개씩 담고, 유형은 선택 전후 모두 내부 값으로만 유지한다.

조언은 효과가 언제 나타나는지로 갈린다.

| 시점 | 뜻 | 예 |
| --- | --- | --- |
| 즉시형 | 이 사건의 결과를 바꾼다 | 「횃불을 던지세요」로 거미가 흩어져 용사 피해가 준다 |
| 지연형 | 보스전까지 효과를 들고 간다 | 「보스의 왼쪽은 굳어 있습니다」로 보스 피해가 준다 |

대부분은 즉시형이다. 지연형은 보스 관련 정보뿐이며 위험도별로 횟수를 보장한다.

`보스 관련 정보`는 보스에게 주는 조언이 아니라 파티에게 보스에 관해 알려주는 조언이다.

## 조언 기회

**모든 일반 지점이 조언 기회다.** 지점 수가 곧 조언 횟수이므로 따로 세지 않는다. 지연형만 횟수를 보장한다.

| 현재 위험도 | ★1 | ★2 | ★3 | ★4 | ★5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 일반 지점 = 조언 기회 | 6 | 6 | 7 | 8 | 8 |
| 그중 보스 정보 보장(지연형) | 1 | 1 | 2 | 2 | 2 |

일반 지점 수는 초기 위험도로 정해 고정하고, 보스 정보 보장은 현재 위험도를 따른다. 실패로 위험도가 오른 던전은 다음 도전에서 보스 정보 기회가 늘어난다.

방문하지 않은 갈림길의 조언은 횟수에 포함하지 않는다.

```text
지점 선택
→ 상황 묘사 확인
→ 조언 3개 중 하나 선택
→ 살아 있는 파티원별 수용·의심·적발 판정
→ 한 명이라도 수용하면 실행, 아무도 수용하지 않으면 기본 결과
→ 실제 결과 확인
→ 결과를 알 수 있는 시점에 신뢰 검증
```

## 활성 생태 규칙 공개

던전에서 참인 활성 생태 규칙 3개는 C1이 생태 패키지와 함께 확정한다. E2는 이를 다시 뽑지 않는다. 계약 전 게시판에는 생태 규칙을 보여주지 않고, 원정에 진입한 뒤 현재 위험도에 따라 다음 수만 공개한다.

| 현재 위험도 | 공개 규칙 수 |
| --- | ---: |
| ★1~2 | 3 |
| ★3~4 | 2 |
| ★5 | 1 |

공개 우선순위는 `campaignSeed + dungeonId`로 결정적으로 고정한다. 재도전으로 위험도가 올라가 공개 수가 줄어들면 기존 공개 집합의 앞부분만 남으므로 새로운 규칙으로 무작위 교체되지 않는다. `attempt`는 공개 우선순위에 넣지 않는다.

공개된 규칙은 진행 화면의 생태 기록에서 다시 확인할 수 있다. 숨은 규칙은 사건 묘사·관찰·결과를 근거로 플레이어가 추론하며, 시스템이 관찰 단서를 숨은 규칙 문장으로 자동 승격하지 않는다.

## 유형과 생태 규칙

조언의 유형은 그 던전의 **활성 규칙**에 대해 정해진다. 각 조언은 `참조 규칙` 식별자와 정합·모순 태그를 가진다. 규칙 자체의 계약은 [던전 테마와 생태](DUNGEON_THEMES_AND_ECOLOGY.md)에 있다.

| 유형 | 활성 규칙과의 관계 | 파티에게 |
| --- | --- | --- |
| 도움 | 정합 | 이롭다 |
| 방해 | 모순 | 해롭다 |
| 중립 | 무관 | 약한 효과 |

이 표의 유형과 관계는 규칙 엔진용 내부 값이다. 플레이어에게 `도움 조언`, `방해 조언`, `정합`, `모순`이라는 정답 라벨을 직접 보여주지 않는다.

### 도움

- 참조 규칙과 정합한다.
- 수용되어 실제 효과가 확인되면 `adviceHelped`로 신뢰를 검증한다.
- 아무도 수용하지 않아 기본 결과가 더 나빴다면 의심한 인물에게 `suspicionWasCostly`를 적용한다.

### 방해

- 참조 규칙과 모순된다.
- 수용되어 실제 해로운 결과가 확인되면 `adviceHarmed`로 신뢰를 검증한다.
- 즉시 `적발`되면 `adviceHarmed` 뒤 `deceptionExposed`를 추가 적용한다.
- 아무도 수용하지 않아 위험을 피했다면 의심한 인물에게 `suspicionWasCorrect`를 적용한다.

### 중립

- 규칙과 무관하지만 해롭지 않다.
- 수용되면 도움보다 약한 효과를 준다.
- 조언 결과 자체로 즉시 신뢰를 바꾸지 않는 비교적 안전한 선택이다.

### 공용 사건의 유형

공용 사건은 생태 규칙을 참조하지 않으므로 세 조언의 관계가 모두 `무관`이다. 그러면 유형을 관계로 정할 수 없다. 공용 사건은 **콘텐츠가 유형을 직접 선언하고**, 판단의 근거는 그 장면에만 있는 관찰 가능한 사실이 진다.

```text
상황  상인이 말린 약초와 붕대를 내민다. 포대는 축축하지 않고,
      끈은 막 잘라낸 듯 깨끗하다. 상인은 뒤쪽 싸움 소리를 듣고 손가락으로 값을 재촉한다.

① 약초와 붕대를 사서 바로 처치하세요   도움
② 싸움 전까지 아끼자며 그냥 지나가세요  중립
③ 싸구려 분말을 사서 급히 바르세요      방해
```

위 도움·중립·방해 표시는 콘텐츠 계약을 설명하기 위한 내부 표기이며 실제 선택 UI에는 붙이지 않는다.

**테마 전용 사건은 던전의 생태를 알아야 풀리고, 공용 사건은 그 장면을 자세히 읽어야 풀린다.** 두 종류의 주의력을 요구하므로 테마 전용 30개와 공용 후보 풀을 함께 만나도 단조롭지 않다. merchant의 neutral은 0G 비구매이고, 공용 merchant는 정보 판매나 가짜 지도처럼 던전 정답을 직접 넘기지 않는다.

상황 묘사에는 사실을 적고 결론을 적지 않는다. `끈은 막 잘라낸 듯 깨끗하다`는 사실이고 `이 약초는 안전하다`는 결론이다.

같은 조언이라도 참조하는 규칙이 활성이 아닌 던전에서는 제시되지 않는다.

공급은 이렇게 센다. 테마의 규칙마다 **그 규칙을 참조하는 도움 2개·방해 2개** 이상이 있어야 하고, **중립은 규칙과 무관하므로 테마 전체에 2개** 이상이면 된다. 중립은 참조 규칙이 없어 규칙별로 셀 수 있는 대상이 아니다.

### 조건부 생태 규칙

조건부 규칙을 참조하는 조언은 그 규칙이 활성이라는 이유만으로 사용할 수 없다. **현재 사건 장면에서 조건이 실제로 성립했다는 별도 콘텐츠 선언**까지 있어야 한다.

- 조건부 규칙 참조와 장면 성립 선언은 독립 데이터로 관리한다.
- 조언 source를 읽어 성립 선언을 자동으로 참이라고 간주하지 않는다.
- 조건부 규칙이 비활성이거나 장면 조건이 성립하지 않으면 조언 하나만 제거하지 않고 사건 전체를 후보에서 제외한다.
- 자연어 문장을 런타임에서 파싱해 조건 성립을 추측하지 않는다.

## 파티원별 독립 반응

같은 조언을 살아 있는 모든 파티원에게 전달하고, 각 인물은 자신의 신뢰와 성격으로 `수용`, `의심`, `적발`을 독립 판정한다. 사망자는 판정 대상에서 제외한다. `적발`은 방해에서만 나온다.

기본 확률은 다음과 같다.

| 유형 | 수용 | 적발 | 의심 |
| --- | ---: | ---: | --- |
| 도움 | 70% | 0% | 나머지 |
| 중립 | 55% | 0% | 나머지 |
| 방해 | 45% | 15% | 나머지 |

| 조건 | 수용 보정 | 방해 적발 보정 |
| --- | ---: | ---: |
| 신뢰 0~33 | -20 | +15 |
| 신뢰 34~66 | 0 | 0 |
| 신뢰 67~100 | +15 | -10 |
| 의심 많음 | -20 | +20 |
| 정의로움 | 도움 +15, 방해 -10, 중립 0 | +15 |
| 탐욕스러움 | +10 | -5 |
| 신중함 | -10 | +10 |
| 충동적 | +15 | -10 |

도움·중립의 수용 확률은 5~95%로 제한한다. 방해는 적발률을 5~80%로 먼저 제한하고 수용률은 5% 이상, `95% - 적발률` 이하로 제한한다.

신뢰가 0인 캐릭터가 누적되면 캠페인 상태 기반 보정이 이 표 위에 더해진다. 이 추가 보정의 계산과 공급은 C6가 소유하고 E2는 전달받은 값을 더한다. 누적표는 [캐릭터와 신뢰](CHARACTERS_AND_TRUST.md)에 있다.

대상마다 `card` 난수 스트림에서 1~100 정수를 하나 사용한다. 인물 하나의 추가·제거가 다른 인물의 결과를 흔들지 않도록 난수 입력에는 `characterId`를 포함한다. 방해는 적발 구간, 수용 구간, 의심 구간 순으로 판정한다. 신뢰 변화가 필요할 때만 `trust` 스트림을 사용한다.

### 실행

파티원 3명이 각자 판정하지만 행동은 하나다. **한 명이라도 수용하면 실행된다.**

- 수용한 파티원 중 하나가 조언대로 행동하고, 상황 효과는 파티 전체에 한 번 적용된다
- 의심한 파티원은 실행에 참여하지 않았지만 결과는 함께 받는다
- 한 명이 방해를 적발해도 다른 한 명이 수용했다면 실행을 취소하지 않는다
- 아무도 수용하지 않으면 조언은 실행되지 않고 사건은 **기본 결과**로 흘러간다

기본 결과는 사건마다 콘텐츠가 제공한다. 기본 결과가 나온 뒤에는 선택한 조언이 실행되었다면 어땠을지와 비교해 의심을 검증한다. 도움을 거부해 더 손해를 봤다면 `suspicionWasCostly`, 방해를 거부해 위험을 피했다면 `suspicionWasCorrect`다. 중립 거부는 조언 결과 자체로 신뢰를 바꾸지 않는다.

즉시형은 파티 전체가 결과를 받는다. **지연형 보스 피해 보정만 수용한 파티원에게 적용한다** — 개인이 들고 가는 믿음이기 때문이다.

## 반응 결과

즉시형 사건은 `선택 → 개인 반응 → 사건 결과 → 신뢰 검증` 순서를 지킨다.

- 도움 수용: 효과 적용 뒤 수용한 인물에게 `adviceHelped`
- 방해 수용: 효과 적용 뒤 수용한 인물에게 `adviceHarmed`
- 중립 수용: 약한 효과 적용, 조언 결과 자체의 신뢰 변화 없음
- 실행된 사건에서 의심: 별도 즉시 신뢰 변화 없음
- 아무도 수용하지 않은 도움: 의심한 인물에게 `suspicionWasCostly`
- 아무도 수용하지 않은 방해: 의심한 인물에게 `suspicionWasCorrect`
- 방해 적발: 실행 여부와 무관하게 적발한 인물에게 `adviceHarmed` 뒤 `deceptionExposed`

## 보스 관련 정보

보스 정보는 E2의 Depth 예약이 아니라 E3가 계산한 숨은 `special` exact-once cut이다. 현재 위험도 ★1~2는 1개, ★3~5는 2개의 cut을 두며 첫·마지막 일반 Depth는 피한다. 실제 방문한 노드에서 어떤 보스 정보 사건 ID를 물질화할지는 E3가 담당한다.

보스 정보 사건은 현재 던전의 `bossId`와 `targetBossId`가 일치해야 한다. 수용한 보스 정보는 보스전까지 보관하고 해당 파티원이 받는 보스 피해를 바꾼다.

| 반응과 조언 | 피해 보정 |
| --- | ---: |
| 수용 + 도움 | -20% |
| 수용 + 중립 | -10% |
| 수용 + 방해 | +25% |
| 의심 또는 즉시 적발 | 0% |

보스 관련 보장이 2회인 위험도에서 보스 조언 둘을 수용하면 보정을 합산한다. 피해 감소는 최대 -30%, 피해 증가는 최대 +50%로 제한한다. 수치는 백테스트로 조정하는 잠정 상수다.

보스 정보를 선택한 시점에는 수용·의심의 결과 기반 신뢰를 확정하지 않는다. 방해를 즉시 적발한 인물만 `adviceHarmed`와 `deceptionExposed`를 그 자리에서 받는다. 나머지 help/harm 수용·의심 기록은 보스전 뒤 E4가 실제 전투 결과와 함께 다음처럼 검증한다.

- 수용 + 도움 → `adviceHelped`
- 수용 + 방해 → `adviceHarmed`
- 의심 + 도움 → `suspicionWasCostly`
- 의심 + 방해 → `suspicionWasCorrect`
- 중립 → 결과 기반 신뢰 변화 없음

보스방에서는 새 조언을 제시하지 않는다.

## 단서와 연계

모든 사건의 상황 묘사는 관찰 가능한 사실을 담는다. 규칙을 직접 말하지 않고 보이는 것으로만 드러낸다.

> 바닥과 벽에는 오래된 거미줄이 잔뜩 붙어 있다

현재 원정에서 얻은 관찰 단서는 진행 화면의 `진행 기록`에서 다시 볼 수 있다. 최소 `[전체] [단서] [전투] [생태]` 필터를 제공하며, `생태`에는 E2가 직접 공개한 규칙을, `단서`에는 실제로 본 사실과 사건 결과를 구분해 남긴다. **단서를 숨은 규칙 문장으로 자동 승격하거나 정답 표시하지 않는다.** 새 원정·재도전을 시작하면 시스템의 원정 기록은 초기화되지만 플레이어 자신의 기억은 남는다.

연계는 단서 하나로 표현하고 세기만 둘로 나눈다.

| 세기 | 규칙 |
| --- | --- |
| 약한 연계 | 단서를 보유하면 조언 세 슬롯 중 하나가 강화판으로 교체된다 |
| 강한 연계 | 단서를 보유하지 않으면 그 사건이 배치되지 않는다 |

강화판은 네 번째 선택지로 추가되지 않는다. 선택지는 항상 3개다. 교체 대상 슬롯은 콘텐츠가 정하며, 도움 슬롯일 수도 방해 슬롯일 수도 있다. 관찰의 보상은 정답을 알려주는 것이 아니라 수단이 늘어나는 것이다.

**강화판의 유형은 교체당하는 슬롯과 같아야 한다.** 도움 슬롯이 방해로 바뀌면 `도움·방해·중립 각 한 개씩`이 깨진다. 단서를 본 플레이어에게만 불변식이 다르게 적용될 이유가 없다. 강화판은 같은 유형의 더 강한 수단이다.

## 미검증 정보와 사후 검증

즉시형 사건은 결과가 바로 확인되므로 그 자리에서 검증한다. 보스 정보만 `InfoRecord`에 지연 검증 상태를 보관한다.

- 수용한 도움 보스 정보 → 보스전 뒤 `adviceHelped`
- 수용한 방해 보스 정보 → 보스전 뒤 `adviceHarmed`
- 의심한 도움 보스 정보 → 보스전 뒤 `suspicionWasCostly`
- 의심한 방해 보스 정보 → 보스전 뒤 `suspicionWasCorrect`
- 방해 즉시 적발 → 선택 시 `adviceHarmed` + `deceptionExposed`, 중복 지연 검증 없음
- 중립 → 결과 기반 지연 신뢰 검증 없음

적발되지 않은 방해가 나중에 해로운 결과를 냈다는 사실만으로 `deceptionExposed`를 추가하지 않는다. 그것은 파티에게 고의가 드러난 배신이 아니라 틀린 조언으로 남는다.

검증이 끝난 기록은 미검증 상태로 다시 처리하지 않는다.

## 피드백 원칙

### 선택 전

플레이어에게 보여주는 것은 판단의 재료이지 정답이 아니다.

- 정보를 받을 파티원과 현재 신뢰·성격
- E2가 현재 위험도에 따라 공개한 활성 생태 규칙
- 지금까지 진행 기록에 쌓인 관찰 단서

조언 세 개는 같은 디자인으로 제시하고 **유형, 정답 색, 발각 확률, 예상 신뢰 변화량을 모두 감춘다.** 어느 조언이 규칙과 정합하는지는 플레이어가 규칙과 단서로 판단할 몫이다.

감추는 것은 결론이지 근거가 아니다. 플레이어가 실패했을 때 `앞에서 나온 단서를 놓쳤구나`라고 생각해야 하며 `이걸 어떻게 알아?`가 되어서는 안 된다.

### 선택 직후

- 파티원별 수용·의심·적발
- 실제 사건 결과와 HP·골드·상태 변화
- 결과를 알 수 있는 시점에 적용된 신뢰 변화와 사람이 읽는 이유

`help / harm / neutral`, `consistent / contradictory` 같은 내부 판정값이나 `어떤 규칙과 정합/모순했다`는 정답 문구는 선택 뒤에도 직접 공개하지 않는다.

### 사후 검증

- 어떤 과거 조언이 현재 사건이나 보스 피해에 영향을 주었는지
- 방해 또는 의심이 왜 신뢰를 바꾸었는지

## 생성 오류

실제 모든 경로가 일반 지점 수와 현재 위험도의 보스 정보 횟수를 충족해야 한다. 조언 콘텐츠가 부족하거나, 식별자가 중복되거나, 활성 규칙에 대해 유형 조합이 비거나, 조건부 장면 선언이 참조 규칙과 맞지 않거나, 다른 보스의 정보 사건이 들어오면 조용히 다시 뽑지 않고 전역 오류 계약 `RuleError("INVALID_GENERATION", ...)`를 반환한다.

## 조언 콘텐츠 계약

사건 하나는 상황 묘사와 조언 3개로 이루어지고, 조언은 도움·방해·중립을 정확히 한 개씩 담는다.

각 사건은 다음을 가진다.

- 상황 묘사. 관찰 가능한 사실을 담고 단서를 실어 나른다
- 조언 3개. 각각 선택지 문구, 고블린의 근거 대사, 결과 문구를 가진다
- 결과 문구는 **무슨 일이 왜 일어났는지** 드러낸다. `실패했다`가 아니라 `벽을 두드리자 진동이 굴을 타고 퍼진다. 옆 굴의 거미 한 마리가 더 다가온다`로 쓴다
- 각 조언의 참조 규칙 식별자와 정합·모순 태그. 중립은 참조 규칙이 없다
- 아무도 수용하지 않았을 때의 기본 결과 문구
- 강화판이 있으면 교체할 슬롯과 그 대체 조언
- 조건부 생태 규칙을 참조하면 현재 장면에서 그 조건이 실제로 성립한다는 독립 선언

사건은 생태 규칙을 참조하면 테마 전용이고, 참조하지 않으면 공용이다. 공용 사건은 모든 테마의 던전에 나온다.

| 구분 | 수량 |
| --- | ---: |
| 테마 전용 | 테마당 30 |
| 공용 | 90 |
| 한 테마에서 만날 수 있는 것 | 120 |

사건 식별자·문구는 중복되거나 비어 있을 수 없다. 한 던전 안에서 같은 사건을 두 번 쓰지 않는다.

콘텐츠 검증은 수량·문구·태그·조건부 장면 선언을 확인하며 유형 판정, 수용·의심·적발 확률, 개인별 반응, 보스 피해 보정은 계산하지 않는다. 이 데이터 계약을 실제 결과로 해석하는 것은 규칙의 몫이다.

계약을 만족하지 않으면 조용히 재추첨하지 않고 전역 오류 계약 `RuleError("INVALID_GENERATION", ...)`로 보고한다.
