# 캐릭터와 신뢰 시스템

## 목적

캐릭터와 신뢰 시스템은 캠페인 동안 이어지는 인간관계를 만들고, 같은 조언도 누구와 함께하느냐에 따라 다른 결과를 내도록 한다.

원정대는 하나의 수치로 움직이는 집단이 아니다. 각 캐릭터는 직업, 성격, 개인 신뢰를 가지며 플레이어의 말과 행동을 서로 다르게 평가한다.

이 문서는 **개인이 들고 다니는 것**을 다룬다. 30명을 어떻게 굴리는지는 [캐릭터 풀과 월드턴](CHARACTER_POOL_AND_WORLDTURN.md)에 있다.

## 캐릭터 상태

각 캐릭터가 캠페인 내내 들고 다니는 상태는 다음과 같다.

| 상태 | 규칙 |
| --- | --- |
| HP | 직업별 최대 HP. 원정·백그라운드·휴식으로 변한다 |
| 개인 신뢰 | 0~100 정수. 성격별 기본값에 시드로 −5~+5 |
| 소지 골드 | 시드로 20~45. 전멸 유품으로만 회수된다 |
| 행동 기억 | 유지한다. 다만 UI에 내부 상태 문구로 직접 노출하지 않는다 |
| 출전 가능 | 신뢰 > 0 이고, 생존해 있고, 중상이 아닐 때 |

상태는 원정이 끝나도 초기화되지 않는다. 같은 인물이 다시 편성되면 지난 원정의 HP와 신뢰를 그대로 들고 온다.

## 직업

초기 직업은 전사·궁수·성직자·마법사·도적 다섯이다.

직업마다 최대 HP와 보스전 능력치를 가진다. 정확한 수치는 콘텐츠 데이터로 관리하고 백테스트에서 조정한다. 직업 목록은 열려 있으며 새 직업을 추가할 때 신뢰 규칙 자체를 고칠 필요는 없다.

## 성격

성격은 다음 **5종으로 고정한다.**

| 성격 | 식별자 |
| --- | --- |
| 의심 많음 | `suspicious` |
| 정의로움 | `righteous` |
| 탐욕스러움 | `greedy` |
| 신중함 | `prudent` |
| 충동적 | `impulsive` |

성격은 신뢰 변화뿐 아니라 조언의 수용·방해 적발 확률에도 관여한다. 목록이 닫혀 있는 이유는 판정이 성격마다 규칙으로 분기하기 때문이다. 성격 추가는 콘텐츠 추가가 아니라 규칙 변경이다.

## 개인 신뢰

신뢰는 원정대 전체가 아니라 **캐릭터별 0~100 정수**다.

- `0`은 플레이어를 더 이상 믿지 않아 플레이어 원정 후보에서 빠지는 상태다.
- `100`은 현재 신뢰 상한이다.
- 결과가 범위를 벗어나면 0~100으로 자른다.

초기 신뢰는 성격별 기본값에 시드로 고른 `-5~+5`를 더한다.

| 성격 | 초기 신뢰 기본값 |
| --- | ---: |
| 의심 많음 | 35 |
| 신중함 | 45 |
| 탐욕스러움 | 50 |
| 정의로움 | 55 |
| 충동적 | 60 |

신뢰가 높을수록 조언을 받아들이기 쉬워지고 방해를 적발할 가능성이 낮아진다. 신뢰가 낮을수록 조언을 의심하기 쉬우며 방해 적발 가능성이 높아진다. 정확한 반응 확률표와 clamp는 [정보와 기만](INFORMATION_AND_DECEPTION.md)이 정한다.

## 신뢰 0

신뢰가 0이 된 캐릭터는 **사망하지 않고 세계에서 사라지지도 않는다.** 플레이어 원정 후보에서만 빠지고 휴식과 백그라운드 활동은 계속한다.

일반 신뢰 판정으로 0에서 회복하지 않는다. 되돌릴 수 없는 손실이라는 점이 배신 전략의 장기 대가다.

### 신뢰 0 누적

신뢰 0인 캐릭터가 늘어나면 남은 인물들의 조언 반응이 함께 나빠진다.

| 누적 인원 | 효과 |
| ---: | --- |
| 1명 | 해당 캐릭터 플레이어 원정 출전 불가 |
| 2명 | 모든 파티원의 조언 수용 확률 −5 |
| 3명 | 수용 −10, 방해 적발 +5 |
| 4명 | 수용 −15, 방해 적발 +15 |
| 5명 | `누적 고발` 엔딩. 조사 이벤트 없이 즉시 |

이 캠페인 상태 보정의 계산과 공급은 C6가 소유한다. E2는 보정값을 입력으로 받아 개인 반응 확률에 더하며 누적 인원을 직접 계산하지 않는다.

신뢰 0이 엔딩으로 이어지는 경로는 누적 5명과 원정 중 생존 파티원 전원의 신뢰가 0인 경우다. 판정 순서는 [성장과 엔딩](PROGRESSION_AND_ENDINGS.md)에 있다.

## 성격과 신뢰 변화

성격별 반응은 플레이어가 이해할 수 있는 가치관으로 설명한다.

- **탐욕스러움**: 본인 이익과 보상에 민감하다.
- **정의로움**: 정직과 동료 보호를 높게 보고 기만·배신을 강하게 싫어한다.
- **의심 많음**: 정보 근거와 모순에 민감하다.
- **신중함**: 안전과 위험 회피를 중시한다.
- **충동적**: 즉각적인 행동과 위험 감수를 선호한다.

신뢰 판정은 구체적 사건을 직접 알지 않는다. 상위 규칙이 사건을 공통 `TrustAction`으로 해석하면 대상 캐릭터 성격에 따라 변화를 계산한다.

## 프로토타입 신뢰 판정

### 일반 행동

| 행동 | 의심 많음 | 정의로움 | 탐욕스러움 | 신중함 | 충동적 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 정직한 행동 | +8 | +12 | 0 | +5 | +3 |
| 기만 적발 | -14 | -16 | -6 | -10 | -7 |
| 동료 보호 | +3 | +12 | 0 | +7 | +8 |
| 동료 배신 | -8 | -16 | -4 | -10 | -10 |
| 본인 이익 확보 | +3 | +4 | +14 | +5 | +7 |
| 본인 이익 박탈 | -5 | -6 | -16 | -7 | -8 |
| 위험 감수 | -5 | -3 | +3 | -12 | +12 |
| 위험 회피 | +7 | +3 | 0 | +12 | -10 |

### 조언 결과 행동

| 공통 행동 | 의심 많음 | 정의로움 | 탐욕스러움 | 신중함 | 충동적 | 의미 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `adviceHelped` | +2 | +3 | +2 | +3 | +4 | 수용한 조언이 실제로 도움을 줌 |
| `adviceHarmed` | -4 | -3 | -3 | -4 | -2 | 조언이 실제로 해를 줌 |
| `suspicionWasCostly` | +10 | +8 | +4 | +9 | +7 | 도움 조언을 거절해 더 나쁜 기본 결과를 맞음 |
| `suspicionWasCorrect` | -5 | -8 | -5 | -7 | -6 | 방해 조언을 거절해 위험을 피함 |

`adviceHelped`와 `adviceHarmed`는 모든 일반 지점에서 자주 발생하므로 변화량을 작게 둔다.

`deceptionAccepted`는 사용하지 않는다. 방해 조언이 단순히 믿어졌다는 이유만으로 결과 확인 전에 신뢰를 올리지 않는다.

### 즉시형 조언의 적용 시점

신뢰는 조언 선택 순간이 아니라 사건 결과가 확인된 뒤 움직인다.

- 실행된 accepted help → `adviceHelped`
- 실행된 accepted harm → `adviceHarmed`
- accepted neutral → 변화 없음
- 실행된 사건의 suspected → 즉시 변화 없음
- 아무도 수용하지 않은 help의 suspected → `suspicionWasCostly`
- 아무도 수용하지 않은 harm의 suspected → `suspicionWasCorrect`
- exposed harm → 실행 여부와 무관하게 `adviceHarmed` 후 `deceptionExposed`

방해가 적발되지 않고 실행돼 실제로 해를 줬다면 `adviceHarmed`만 적용한다. 파티는 길잡이의 말이 틀렸다는 것까지는 알지만 고의였다고 단정하지 않는다. 적발된 경우에만 `deceptionExposed`가 추가되어 고의와 실수의 차이를 만든다.

### 보스 지연형 조언

보스 정보의 accepted/suspected help·harm은 선택 순간 신뢰를 확정하지 않는다. E2는 개인별 지연 기록만 남기고 E4가 실제 보스전 뒤 결과 기반 행동으로 바꾼다.

- accepted help → 보스전 뒤 `adviceHelped`
- accepted harm → 보스전 뒤 `adviceHarmed`
- suspected help → 보스전 뒤 `suspicionWasCostly`
- suspected harm → 보스전 뒤 `suspicionWasCorrect`
- neutral → 결과 기반 신뢰 변화 없음
- exposed harm → 선택 순간 `adviceHarmed` + `deceptionExposed`, 보스전에서 중복 처리하지 않음

## 난수 변동과 clamp

모든 신뢰 행동의 기본 변화량에는 기존 ±20% 시드 변동을 적용한다.

기본 변화량이 0이 아니면 `abs(baseDelta) * 0.2`를 정수로 반올림해 변동 폭을 구하고 최소 1로 둔다. `trust` 난수 스트림에서 `-변동 폭`부터 `+변동 폭`까지의 양 끝을 포함한 정수를 골라 기본값에 더한다. 결과는 기본 변화량의 부호를 보존한다.

기본 변화량이 0이면 난수를 소비하지 않고 변화량도 0이다. 계산 후 신뢰는 0~100으로 제한하고, 기록하는 `delta`는 제한 전 계산값이 아니라 실제 적용된 차이다.

모든 판정은 성격과 행동에 맞는 사람이 읽을 수 있는 변화 사유를 함께 만든다. 구체적인 사건 내용은 사건·조언 결과 기록이 담당하고 신뢰 판정의 reason은 해당 성격이 왜 좋아하거나 싫어했는지를 설명한다.

## 플레이어에게 보여줄 정보

플레이어는 최소한 다음을 파악할 수 있어야 한다.

- 각 캐릭터의 직업과 성격
- 현재 개인 신뢰 또는 이해 가능한 신뢰 상태
- 최근 신뢰 변화의 원인
- 어떤 조언을 누가 수용·의심·적발했는지
- 신뢰 하락으로 출전 불가에 가까워졌는지

수용·적발의 정확한 내부 확률이나 `help / harm / neutral` 정답 라벨은 공개하지 않는다. 다만 신뢰 변화가 무작위로 느껴지지 않도록 결과와 이유를 연결한다.

## 다른 시스템과의 연결

- E2는 개인 신뢰·성격과 C6의 캠페인 보정을 사용해 조언 반응을 판정한다.
- E2는 즉시 사건 결과가 나온 뒤 신뢰 행동을 확정한다.
- E4는 보스 정보의 pending 기록을 전투 뒤 검증한다.
- C6는 신뢰 0 누적 보정과 누적 고발 엔딩을 소유한다.
- 사망과 신뢰 0은 되돌릴 수 없는 인력 손실 압력이 된다.
- 신뢰 변화는 원정이 끝나도 남아 같은 인물이 다시 편성됐을 때 이어진다.
