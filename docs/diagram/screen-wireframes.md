# 대표 화면 와이어프레임

초기 스케치인 [proto_image.png](../initialization/proto_image.png)의 조우·지도·결과
구도를 유지하면서, 최신 던전 15개 캠페인의 게시판과 정산 구조를 함께 보여주는
대표 화면군 5개다. 화면은 구조 참고용 와이어프레임이며 최종 아트나 실제 React
구현을 확정하지 않는다.

[전체 모음 SVG](svg/screen-overview.svg) ·
[전체 모음 PNG](png/screen-overview.png)

## 공통 캠페인 HUD

모든 화면의 상단은 다음 정보를 유지한다.

- 영구 길잡이 등급
- 현재 명성과 다음 공고 지원 상태
- 현재 골드와 누적 획득 골드
- 승급 점수와 다음 등급 기준
- 남은 던전 수

영구 등급과 현재 명성은 서로 다른 그룹과 라벨로 구분한다. 명성이 내려가도 영구
등급은 강등되지 않지만, 현재 명성은 계속 공고 지원을 제한하기 때문이다.

## 1. 공고 게시판과 계약·파티 확인

[![공고 게시판과 계약·파티 확인](png/screen-01-campaign-board.png)](svg/screen-01-campaign-board.svg)

- 왼쪽에서 최대 5개 공고의 지원 조건, 보상과 위험을 비교한다.
- 오른쪽에서 선택한 던전과 출전 파티 3인의 상세 상태를 확인한다.
- 각 파티원은 직업·성격·HP·개인 신뢰·소지 골드를 따로 표시한다.
- 잠긴 공고도 숨기지 않고 `× 지원 불가`와 부족한 명성 수치를 함께 보여준다.

## 2. 던전 분기 지도

[![던전 분기 지도](png/screen-02-dungeon-map.png)](svg/screen-02-dungeon-map.svg)

- 초기 스케치처럼 입구는 아래, 보스방은 위에 둔다.
- 전체 연결, 사건 분류·대략적인 위험, 정보 기회와 보스 위치를 미리 공개한다.
- 현재·방문·다음·잠긴 지점은 색뿐 아니라 기호, 선과 테두리 형태로 구분한다.
- 중앙 지도를 가장 크게 두고 왼쪽 범례와 오른쪽 개인 파티 상태를 함께 본다.

## 3. 정보 전달과 사건 조우

[![정보 전달과 사건 조우](png/screen-03-info-event.png)](svg/screen-03-info-event.svg)

- 위쪽은 파티와 사건 상황을 보는 관람 영역이다.
- 아래쪽은 진실·거짓·중립 카드와 사건 행동을 구분한 조작 영역이다.
- 카드 선택 뒤 살아 있는 파티원별 `✓ 수용`, `? 의심`, `! 적발`을 따로 보여준다.
- 정보 반응을 처리한 뒤에도 지원·방해·아이템·거래·관망 행동을 별도로 선택한다.

## 4. 자동 보스전과 정산

[![자동 보스전과 정산](png/screen-04-boss-settlement.png)](svg/screen-04-boss-settlement.svg)

- 자동 보스전의 생존·사망, 파티원별 피해와 원인을 먼저 보여준다.
- 이어서 생존·신뢰, 보상·유품, 던전·승급, 파티·회복 순서를 번호로 설명한다.
- `선택 → 개인 반응 → 피해 → 보상·손실 → 캠페인 변화`의 원인 사슬을 강조한다.

## 5. 캠페인 엔딩

[![캠페인 엔딩](png/screen-05-campaign-ending.png)](svg/screen-05-campaign-ending.svg)

- 엔딩 이름, 판정 원인과 최종 영구 등급을 가장 크게 보여준다.
- 생존·전멸 파티, 최종 명성·골드와 대표 정보 선택을 요약한다.
- 정상 완주와 조기 종료 모두 `S급 목표를 위해 어떤 선택을 했는가?`를 회고한다.

## 가시성 원칙

- 개별 화면은 1920×1080, 전체 모음은 3840×2160이다.
- 본문 24px 이상, 제목 36px 이상, 주요 선 3px 이상을 사용한다.
- 어두운 잉크 배경과 밝은 양피지 글자로 대비를 확보한다.
- 외부 이미지와 이모지에 의존하지 않고 SVG 기본 도형과 텍스트 기호를 사용한다.
- 색은 보조 단서이며 라벨, 기호, 선 종류와 테두리 형태가 의미를 함께 전달한다.
