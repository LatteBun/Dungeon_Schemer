> 상태: 답변 및 설계 합의 완료
> 작성일: 2026-08-13
> 작성 도구: Codex
> 문서 지위: 합의 과정을 보존하는 협업 기록이다. 최종 규칙은 공식 문서와 상위 spec을 따른다.

## 작성 방법

1. 선택한 항목의 `[ ]`를 `[x]`로 바꾼다.
2. 제시된 선택지와 다른 답이면 `직접 답변`에 적는다.
3. `권장안 그대로`를 체크하면 해당 질문의 권장안을 채택한 것으로 본다.
4. 수치가 아직 중요하지 않으면 `규칙만 확정하고 수치는 밸런스 상수로 둔다`를 선택할 수 있다.
5. **필수 질문**을 먼저 답하면 상위 설계를 확정할 수 있다. **밸런스 질문**은 권장안으로 일괄 위임해도 된다.

답변 예시:

```text
- [x] B. 전체 지도와 위험 성격 공개
- [ ] 권장안 그대로
- 직접 답변:
```

## 지금까지 확정된 내용

다음 내용은 대화에서 이미 합의했으므로 다시 답하지 않아도 된다.

- 캠페인은 남은 던전 15개를 모두 클리어하면 끝난다.
- 캠페인 종료 시 누적 상태를 기준으로 C~S 최종 길잡이 등급을 평가한다.
- 각 등급은 **현재 명성**과 **누적 획득 골드**를 가중 합산한 승급 점수가 등급별 기준을 충족하면 오른다. 세부 가중치와 기준 점수는 설계에서 확정한다.
- 신뢰도 0에 따른 처형은 탐험 정산 시점에 생존 파티원 전원의 신뢰도가 0일 때 발생한다.
- 파티원과 개인 신뢰도는 탐험이 끝난 뒤에도 유지된다.
- 파티원 3명이 모두 생존하면 같은 팀으로 유지된다.
- 생존자가 1~2명이면 예비 명단에서 직업이 겹치지 않도록 충원한다.
- 게시판에서는 현재 공고 5개만 선택할 수 있다.
- 게시판은 남은 던전을 C→B→A→S 순으로 정렬해 낮은 등급부터 최대 5개를 보여준다.
- 현재 공고가 모두 명성 제한에 막히면 즉시 `지원 불가` 엔딩으로 간다.
- 초기 던전 15개의 잠정 분포는 C 6개, B 4개, A 3개, S 2개다.
- 파티원이 한 명이라도 생존하면 던전 클리어다. 전멸만 실패다.
- 부분 생존 클리어에서는 유품을 얻지 않고 계약 보상만 감액한다.
- 파티 전멸 실패에서만 파티원들이 소지한 골드를 모두 획득한다.
- 보스 거래와 **보스에게 파티 정보를 제공하는 행동**은 제거한다.
- 진실·거짓·중립 카드를 받는 대상은 용사 파티뿐이다. 카드가 다루는 주제에는 경로·사건·몬스터뿐 아니라 보스의 약점과 행동도 포함할 수 있다.

## Q14. 카드 제시 빈도

모든 지점에서 카드 세 장을 고르면 반복이 과해질 수 있고, 너무 적으면 핵심 시스템이 약해질 수 있다.

- [ ] A. 모든 일반 이벤트마다 진실·거짓·중립 카드 세 장을 제시한다.
- [x] B. 던전마다 정해진 수의 핵심 이벤트에서만 제시한다. 등급이 높을수록 횟수가 늘어난다.
- [ ] C. 카드 이벤트 여부를 완전히 무작위로 정한다.
- [ ] 권장안 그대로: **B**
- 직접 답변:

## Q28. 길잡이 승급 기준

현재 등급 C는 시작 등급이다. 이후 등급은 아래 두 자원을 가중 합산한 승급 점수가 등급별 기준을 충족하면 오른다.

```text
승급 점수 = (현재 명성 × 2) + 누적 획득 골드
```

- [x] 명성과 골드의 개별 최소 조건 대신 가중 합산 점수를 사용한다.
- [x] 명성에는 실패로 인한 손실까지 반영되는 현재 명성을 사용한다.
- [x] 골드에는 소비와 무관한 누적 획득 골드를 사용한다.
- [x] 한 자원의 점수 기여에 상한을 두지 않아 명성 또는 골드 중심의 조합도 승급할 수 있다.

프로토타입의 등급별 기준 점수는 다음 기준 진행에서 승급 점수를 갖추도록 조정한다. 아래 클리어 횟수는 별도의 필수 승급 조건이 아니라 가중치와 기준 점수를 정하기 위한 밸런스 목표다.

- C→B: C급 던전 3개를 각각 파티원 3명 전원 생존으로 클리어
- B→A: B급으로 승급한 뒤, B급 던전 2개를 각각 파티원 3명 전원 생존으로 클리어하고 C급 던전 1개를 파티원 2명 이상 생존으로 클리어. C→B의 기준이 된 C급 클리어는 다시 세지 않는다.
- A→S: S급 던전 1개 또는 A급 던전 2개를 각각 파티원 2명 이상 생존으로 클리어

| 길잡이 등급 | 필요한 승급 점수 |
| --- | ---: |
| C | 0 |
| B | 120 |
| A | 274 |
| S | 370 |

기준 진행을 따르면 B 승급 시 `현재 명성 30 / 누적 골드 60 = 120점`, A 승급 시 `66 / 142 = 274점`이다. S급 던전 하나를 2명 생존으로 클리어하는 경로는 `90 / 190 = 370점`, A급 던전 둘을 각각 2명 생존으로 클리어하는 경로는 `96 / 208 = 400점`으로 S 기준을 넘는다.

매 정산 후 조건을 만족한 가장 높은 등급으로 즉시 승급하므로 한 정산에서 여러 등급을 건너뛸 수 있다. 한번 달성한 등급은 이후 점수가 내려가도 유지하며, 캠페인 완주 시 이 영구 등급을 최종 평가로 사용한다.

- 직접 답변: 보스방을 제외한 실제 선택 경로의 일반 사건에서 C 2회 / B 3회 / A 4회 / S 5회를 반드시 제시한다. 방문하지 않은 갈림길의 카드 사건은 이 횟수에 포함하지 않는다. 어느 경로를 선택해도 등급별 횟수를 충족하도록 생성한다. 이 가운데 보스 관련 정보 카드는 C·B에서 1회, A·S에서 2회를 보장한다. 파티원별 수용 결과는 보스전까지 유지되어 해당 파티원이 받는 HP 피해를 늘리거나 줄인다. 보스전에서는 새 카드를 제시하지 않고 이전 카드 반응과 미검증 정보를 사후 검증한다.

프로토타입에서 보스 정보 카드를 수용한 파티원은 진실이면 보스 피해 `-20%`, 중립이면 `-10%`, 거짓이면 `+25%`를 적용한다. 의심하거나 즉시 적발한 카드는 전투 보정을 적용하지 않는다. 보스 정보 카드가 두 장이면 합산하되 피해 감소는 최대 `-30%`, 피해 증가는 최대 `+50%`로 제한한다. 이 값은 백테스트 후 조정할 잠정 밸런스 상수다.
