# F3-4 공용 사건 90종 확장 설계

- 작성일: 2026-08-21
- 대상: `LatteBun/Dungeon_Schemer`
- 작업: F3-4 공용 사건 확장
- 상태: 사용자 브레인스토밍 승인 완료, 구현 전 Spec

## 1. 목적

F3-4는 현재 15개인 공용 사건을 `rest / merchant / special` 각각 30개, 총 90개로 확장한다.

공용 사건의 고유한 플레이 경험은 다음 한 문장으로 정의한다.

> 테마 전용 사건은 던전의 생태를 알아야 풀리고, 공용 사건은 그 장면을 자세히 읽어야 풀린다.

따라서 F3-4의 목표는 단순 수량 증가가 아니라 다음 세 가지를 동시에 달성하는 것이다.

1. 반복감이 적은 충분한 사건 풀을 만든다.
2. 장면 속 관찰 가능한 단서를 읽고 추론하는 재미를 강화한다.
3. 기존 F3-1 조언 콘텐츠 계약과 validator를 그대로 유지한다.

## 2. 확정된 설계 원칙

### 2.1 총량 및 분류

공용 사건은 총 90개다.

- `rest`: 30개
- `merchant`: 30개
- `special`: 30개

각 대분류는 6개 상황군으로 나누며, 상황군마다 정확히 5개 사건을 둔다.

### 2.2 상황군

#### rest

1. 부상/치료
2. 식량/물
3. 휴식 장소
4. 불/온도
5. 경계/불침번
6. 장비 정비

#### merchant

1. 가격/흥정
2. 물건 진위
3. 계약/외상
4. 정보 거래
5. 수상한 상인 행동
6. 위험한 물품

#### special

1. 함정/장치
2. 시체/흔적
3. 경로/환경 판단
4. 낯선 인물
5. 환경 변화
6. 파티 내부 갈등

이 18개 상황군은 **콘텐츠 제작/리뷰용 분류**이며 런타임 enum 또는 새로운 domain field로 추가하지 않는다.

### 2.3 상황군별 난이도 배분

각 상황군의 5개 사건은 아래 비율을 목표로 한다.

- 직관형 2개
- 추론형 2개
- 함정형 1개

난이도 역시 콘텐츠 제작 메타데이터일 뿐 런타임 데이터로 추가하지 않는다.

### 2.4 조언 작성 규칙

모든 사건은 정확히 3개의 조언을 가진다.

- `help`: 장면 속 단서와 가장 잘 맞는 조언
- `harm`: 겉으로는 합리적이지만 장면의 단서와 충돌하는 조언
- `neutral`: 무의미한 선택이 아니라 위험 회피, 관망, 지연 등 손익이 제한적인 조언

추가 규칙:

- 세 선택지만 보고 help/harm/neutral이 노골적으로 드러나면 안 된다.
- harm은 바보 같은 선택지가 되어서는 안 된다.
- 플레이어가 실제 의학·화학·기계 등 전문지식을 알아야만 풀 수 있는 사건은 금지한다.
- 필요한 판단 근거는 반드시 `description` 안에 존재해야 한다.
- description에는 관찰 가능한 사실을 쓰고 결론을 직접 쓰지 않는다.
- 결과 문구는 선택과 결과 사이의 인과가 드러나야 한다.
- 길잡이 고블린은 직접 행동하는 주체가 아니라 파티에게 조언한다.

### 2.5 기존 15개 처리

기존 공용 사건 15개는 버리지 않고 새 90개 안에 편입한다.

원칙:

- 좋은 기존 사건은 유지한다.
- 단서가 약한 사건은 보강한다.
- 같은 트릭이 겹치는 사건은 하나를 교체한다.

특히:

- `shared-rest-fire`: 바람/연기 방향 단서를 더 명확히 보강한다.
- `shared-merchant-credit`: 유지한다.
- `shared-special-contract`: 작은 글씨 계약 트릭이 위 사건과 중복되므로 새 special 사건으로 교체한다.

## 3. 파일 구조

권장 구조:

```text
lib/content/
├─ shared-event-builders.ts
├─ shared-rest-events.ts
├─ shared-merchant-events.ts
├─ shared-special-events.ts
├─ shared-events.ts
└─ shared-events.test.ts
```

역할:

- `shared-event-builders.ts`: 현재 `advice()` / `sharedEvent()` 정도의 최소 헬퍼만 보유한다.
- `shared-rest-events.ts`: rest 30개
- `shared-merchant-events.ts`: merchant 30개
- `shared-special-events.ts`: special 30개
- `shared-events.ts`: 세 배열을 합쳐 `SHARED_EVENTS`를 export한다.

새로운 추상화 계층이나 콘텐츠 DSL은 만들지 않는다.

## 4. 검증 및 테스트

기존 `situation-validation.ts` 계약은 변경하지 않는 것이 기본 원칙이다.

반드시 만족할 것:

- 사건마다 조언 정확히 3개
- help/harm/neutral 각 1개
- 공용 사건 advice는 `relation: "unrelated"`
- 공용 사건 advice는 `source` 없음
- 공용 사건 advice는 `bossDamageModifier` 없음
- 빈 제목/설명/조언/결과 없음
- event ID 중복 없음
- advice ID 중복 없음

F3-4 테스트에서는 추가로:

- rest 정확히 30
- merchant 정확히 30
- special 정확히 30
- 전체 정확히 90
- 제목 완전 중복 없음
- description 완전 중복 없음
- advice label 완전 중복은 가능한 한 방지

다음은 자동 테스트가 아니라 콘텐츠 리뷰 체크리스트로 관리한다.

- 상황군별 5개
- 직관 2 / 추론 2 / 함정 1
- 전문지식 없이 해석 가능
- harm이 충분히 그럴듯함
- 같은 트릭의 단순 명사 치환 반복 금지

# 5. 공용 사건 콘텐츠 명세

표기법:

- `[직관]`, `[추론]`, `[함정]`은 제작/리뷰용이며 런타임 필드가 아니다.
- `H` = help, `X` = harm, `N` = neutral.
- 각 조언은 `선택 문구 → 결과 문구` 순서다.

## 5.1 REST — 부상/치료 5

### R01 [직관] 벌어진 상처 — 기존 유지

**상황:** 전사의 상처가 다시 벌어졌다. 감아둔 천은 이미 검게 젖었고, 물통은 절반이 비어 있다.

- H: `마른 천을 찢어 새로 감으라고 하세요` → 마른 천으로 다시 감자 배어나오던 피가 멎는다.
- X: `남은 물을 상처에 부어 씻으라고 하세요` → 물통만 비고 젖은 천은 그대로라 이동 준비가 더 나빠진다.
- N: `잠시 앉아 쉬라고 하세요` → 숨은 돌렸지만 상처는 그대로다.

### R02 [직관] 발목의 끈

**상황:** 마법사의 발목이 부어 장화 끈 자국이 깊게 남았다. 끈은 위쪽까지 단단히 조여져 있고 걸을 때마다 발을 끈다.

- H: `끈을 풀어 압박을 줄이라고 하세요` → 장화가 느슨해지자 절뚝임이 줄어든다.
- X: `더 단단히 묶어 흔들리지 않게 하라고 하세요` → 발끝 감각이 둔해져 걸음이 더 느려진다.
- N: `속도를 늦춰 걷자고 하세요` → 악화되지는 않았지만 이동이 지연된다.

### R03 [추론] 피 묻은 장갑

**상황:** 도적의 손바닥이 베였다. 장갑 안쪽은 피로 젖었지만 바깥은 멀쩡하고, 손가락은 모두 움직인다.

- H: `장갑을 벗기고 안쪽 상처부터 확인하라고 하세요` → 작은 절개 부위를 찾아 새 천으로 감는다.
- X: `장갑 위를 천으로 단단히 감으라고 하세요` → 젖은 장갑이 눌리며 상처가 다시 벌어진다.
- N: `반대손만 쓰게 하세요` → 손은 아꼈지만 불편함이 계속된다.

### R04 [추론] 어지러운 성직자

**상황:** 성직자가 일어서자 휘청인다. 아침부터 거의 먹지 않았고 물통은 아직 가득하지만 열이나 상처는 없다.

- H: `조금 먹이고 물도 마시게 하라고 하세요` → 잠시 뒤 얼굴빛이 돌아오고 걸음이 안정된다.
- X: `갑옷을 벗기고 찬 바닥에 눕히라고 하세요` → 몸만 식고 기운은 돌아오지 않는다.
- N: `벽에 기대 잠깐 쉬게 하세요` → 어지럼은 조금 가라앉지만 원인은 남는다.

### R05 [함정] 부러지지 않은 팔

**상황:** 전사가 넘어져 팔을 부여잡는다. 팔 모양은 반대쪽과 같고 손가락도 움직이지만, 어깨를 들 때만 얼굴을 찡그린다.

- H: `팔을 몸에 붙여 움직임을 줄이라고 하세요` → 흔들림이 줄어 통증이 가라앉는다.
- X: `뼈가 맞는지 세게 당겨보라고 하세요` → 멀쩡한 관절이 더 자극돼 통증이 심해진다.
- N: `짐을 다른 사람에게 넘기라고 하세요` → 부담은 줄었지만 팔은 계속 아프다.

## 5.2 REST — 식량/물 5

### R06 [직관] 마지막 이틀치 — 기존 유지

**상황:** 식량이 이틀치 남았다. 도적은 아까부터 자기 몫을 조금씩 아껴 주머니에 넣고 있다.

- H: `오늘 몫만 꺼내 나누라고 하세요` → 각자 한 끼씩 나누고 내일 몫이 남는다.
- X: `오늘 다 먹고 힘을 내라고 하세요` → 배는 부르지만 다음 날 먹을 것이 없다.
- N: `각자 알아서 먹으라고 하세요` → 섭취량이 들쭉날쭉하지만 총량은 크게 변하지 않는다.

### R07 [직관] 고인 물 — 기존 유지

**상황:** 벽을 타고 흘러내린 물이 바닥 웅덩이에 고여 있다. 웅덩이에는 벌레 몇 마리가 떠 있고 벽에서는 아직 물이 흐른다.

- H: `벽에서 흐르는 물을 받으라고 하세요` → 물통을 채운다.
- X: `웅덩이 물을 그대로 뜨라고 하세요` → 마신 사람들의 배가 뒤틀린다.
- N: `물은 건드리지 말라고 하세요` → 안전하지만 물통은 그대로다.

### R08 [추론] 젖은 건빵 자루

**상황:** 식량 자루 한쪽이 축축하다. 안쪽 건빵 몇 개만 눅눅하고 나머지는 마른 상태다.

- H: `젖은 것만 골라 따로 빼라고 하세요` → 남은 건빵까지 젖는 것을 막는다.
- X: `전부 한데 섞어 흔들어 말리라고 하세요` → 습기가 퍼져 멀쩡한 건빵까지 눅눅해진다.
- N: `자루 입구만 열어두라고 하세요` → 조금 마르지만 이동 중 흘릴 위험 때문에 오래 두지 못한다.

### R09 [추론] 짠 육포

**상황:** 남은 육포는 평소보다 소금이 많이 묻어 있다. 파티의 물통은 한 병뿐이고 다음 보급 지점은 아직 멀다.

- H: `조금만 먹고 나머지는 남기라고 하세요` → 허기를 달래면서 물 소비를 억제한다.
- X: `육포를 든든하게 먹고 출발하라고 하세요` → 목이 말라 남은 물을 빠르게 비운다.
- N: `육포는 아예 먹지 말자고 하세요` → 물은 아끼지만 배고픔이 남는다.

### R10 [함정] 반쪽 사과

**상황:** 상자에서 멀쩡해 보이는 사과 몇 개가 나왔다. 한 개를 자르자 씨 주변만 갈색이고 냄새와 겉면은 평범하다.

- H: `갈색 부분만 넉넉히 도려내고 나눠 먹자고 하세요` → 먹을 수 있는 부분만 챙긴다.
- X: `겉이 멀쩡하니 통째로 나눠 먹자고 하세요` → 상한 중심부까지 먹어 속이 불편해진다.
- N: `모두 버리고 기존 식량만 먹자고 하세요` → 위험은 없지만 얻은 식량도 없다.

## 5.3 REST — 휴식 장소 5

### R11 [직관] 물 떨어지는 천장

**상황:** 넓고 평평한 공간이지만 천장에서 일정하게 물방울이 떨어져 바닥 중앙이 젖어 있다. 벽 쪽은 말라 있다.

- H: `마른 벽 쪽에 자리를 펴라고 하세요` → 장비를 젖히지 않고 쉰다.
- X: `넓은 중앙에 자리를 펴라고 하세요` → 담요와 짐이 젖는다.
- N: `서서 잠깐만 쉬자고 하세요` → 장비는 안전하지만 피로 회복이 적다.

### R12 [직관] 기울어진 바닥

**상황:** 바닥이 한쪽으로 완만하게 기울어 있고 작은 돌을 놓자 낮은 쪽으로 굴러간다. 높은 쪽에는 평평한 턱이 있다.

- H: `높은 쪽 턱에 기대 쉬라고 하세요` → 몸이 굴러가지 않아 편하게 쉰다.
- X: `낮은 쪽 넓은 곳에 눕자고 하세요` → 자는 동안 짐과 사람이 한쪽으로 밀린다.
- N: `앉아서만 쉬자고 하세요` → 사고는 없지만 숙면하지 못한다.

### R13 [추론] 두 개의 방

**상황:** 한 방은 입구가 넓고 바닥이 깨끗하다. 다른 방은 입구가 좁고 먼지가 쌓였으며 오래된 발자국만 하나 남아 있다.

- H: `좁고 먼지 쌓인 방에서 쉬자고 하세요` → 최근 왕래가 적어 방해받지 않는다.
- X: `깨끗한 방이 안전해 보이니 거기서 쉬자고 하세요` → 얼마 지나지 않아 통행하는 무리와 마주친다.
- N: `두 방 사이 통로에서 쉬자고 하세요` → 어느 쪽도 완전히 피하지 못해 자주 깬다.

### R14 [추론] 따뜻한 돌바닥

**상황:** 주변은 서늘한데 한 구역의 돌바닥만 미지근하다. 그 위에 놓인 마른 잎이 가장자리부터 갈색으로 말라 있다.

- H: `따뜻한 구역을 피해 자리를 잡으라고 하세요` → 밤사이 바닥 열기가 더 올라와도 영향을 받지 않는다.
- X: `따뜻하니 그 위에서 자자고 하세요` → 휴식 중 바닥이 뜨거워져 급히 자리를 옮긴다.
- N: `가까운 곳에서 상태를 지켜보며 쉬자고 하세요` → 온기는 얻지만 깊게 자지 못한다.

### R15 [함정] 문이 있는 방

**상황:** 작은 방에 멀쩡한 문이 하나 있다. 문 안쪽 손잡이에는 먼지가 없고 문밖 바닥에는 여러 방향의 발자국이 겹쳐 있다.

- H: `문을 잠그지 말고 바로 빠져나갈 수 있게 두라고 하세요` → 누군가 다가오자 지체 없이 자리를 뜬다.
- X: `문이 있으니 잠그고 푹 자자고 하세요` → 밖에서 문을 막아버려 빠져나오느라 시간을 잃는다.
- N: `방을 쓰지 않고 통로 끝에서 쉬자고 하세요` → 편안함은 줄지만 갇힐 위험은 없다.

## 5.4 REST — 불/온도 5

- X: `불 가까이에 겹쳐 쌓아두라고 하세요` → 겉만 마르고 안쪽은 축축하게 남는다.

- H: `굴뚝 덮개부터 열고 불을 피우라고 하세요` → 연기가 위로 빠져나간다.

- X: `따뜻한 물을 손잡이에 부으라고 하세요` → 물이 바닥까지 흘러 금세 얼어 출입구가 더 미끄러워진다.
- N: `다른 길부터 찾아보자고 하세요` → 안전하지만 우회에 시간이 든다.

### R20 [함정] 작은 불 여러 개

- X: `방이 넓으니 여러 곳에 불을 나눠 피우자고 하세요` → 연기가 여러 군데에서 차올라 공기가 탁해진다.
- N: `초만 켜고 쉬자고 하세요` → 시야는 확보하지만 추위는 남는다.

- H: `불꽃이 줄어들 때 통로를 살피라고 하세요` → 바람을 밀고 다가오는 움직임을 일찍 발견한다.
- X: `횃불이 불량하니 꺼버리자고 하세요` → 접근을 알려주던 변화를 놓친다.

**상황:** 상인은 빨간 병은 힘의 물약, 파란 병은 회복약이라고 한다. 두 병을 열자 색은 다르지만 냄새와 점도가 완전히 같다.

- H: `효과를 확인할 방법이 없으면 둘 다 사지 말자고 하세요` → 정체 불명의 물약을 피한다.
- X: `색이 다르니 효과도 다를 거라며 둘 다 사라고 하세요` → 같은 내용물 두 병을 다른 물약 가격으로 산다.
- N: `싼 쪽 한 병만 사자고 하세요` → 위험은 남지만 손실 규모는 줄어든다.

### M10 [함정] 지나치게 깨끗한 지도

**상황:** 상인은 던전에서 직접 그린 지도라며 종이를 편다. 종이는 구김 하나 없고 잉크도 손에 묻을 만큼 아직 덜 말라 있다.

- H: `언제 그린 지도인지 먼저 묻자고 하세요` → 상인이 말을 바꾸며 즉석에서 만든 것임이 드러난다.
- X: `새 지도라 최신 정보라며 사자고 하세요` → 검증되지 않은 지도를 산다.
- N: `지도 없이 가자고 하세요` → 정보는 얻지 못하지만 속지는 않는다.

## 5.9 MERCHANT — 계약/외상 5

### M11 [직관] 외상 계약 — 기존 유지

**상황:** 상인이 지금 돈이 없어도 된다며 종이를 내민다. 아래쪽 몇 줄은 위쪽보다 글씨가 눈에 띄게 작다.

- H: `작은 글씨를 소리 내어 읽어달라고 하세요` → 숨겨진 이자 조항을 확인하고 서명을 미룬다.
- X: `서명하고 물건부터 받으라고 하세요` → 높은 이자를 떠안는다.
- N: `다음에 오겠다고 하세요` → 거래하지 않는다.

### M12 [직관] 빈칸이 남은 영수증

**상황:** 계약서의 물품 수량 칸과 최종 금액 칸이 비어 있는데 상인은 먼저 서명해달라고 한다.

- H: `빈칸부터 모두 채워달라고 하세요` → 조건을 확정한 뒤 거래한다.
- X: `상인을 믿고 먼저 서명하라고 하세요` → 나중에 더 큰 금액이 적힌다.
- N: `계약 거래를 포기하라고 하세요` → 아무 의무도 생기지 않는다.

### M13 [추론] 담보 목걸이

**상황:** 상인은 10골드를 빌려주는 대신 목걸이를 담보로 맡기라 한다. 목걸이에는 길드 문장이 새겨져 있고 상인은 계속 문양을 손가락으로 문지른다.

- H: `개인 물건을 담보로 할 수 있는지 다른 조건을 묻자고 하세요` → 길드 물품을 넘기지 않고 다른 담보를 찾는다.
- X: `돈이 급하니 목걸이를 맡기라고 하세요` → 길드 표식이 시장에 넘어가 문제가 된다.
- N: `대출 없이 가진 돈만 쓰자고 하세요` → 거래 규모를 줄인다.

### M14 [추론] 두 날짜

**상황:** 계약 첫 장에는 상환일이 열흘 뒤라고 적혀 있고 마지막 장에는 오늘로부터 닷새 뒤라고 적혀 있다.

- H: `날짜가 다른 두 조항부터 맞춰달라고 하세요` → 상인이 계약서를 다시 쓰게 된다.
- X: `첫 장만 확인했으니 서명하자고 하세요` → 더 짧은 상환 기한이 적용된다.
- N: `계약서를 들고 길드에서 확인하자고 하세요` → 거래가 지연되지만 즉시 위험은 없다.

### M15 [함정] 무료 수리

**상황:** 상인은 무기를 무료로 수리해주겠다고 한다. 대신 수리하는 동안 맡긴 물건에 대한 분실 책임이 없다는 문장이 접힌 부분 안쪽에 적혀 있다.

- H: `분실 책임 조항을 빼면 맡기겠다고 하세요` → 조건을 고쳐 안전하게 수리한다.
- X: `무료니까 바로 맡기라고 하세요` → 좋은 부품 하나가 사라져도 보상받지 못한다.
- N: `지금은 수리하지 말자고 하세요` → 무기 상태는 그대로다.

## 5.10 MERCHANT — 정보 거래 5

### M16 [직관] 앞길을 안다는 자 — 기존 유지

**상황:** 앞쪽 길을 잘 안다며 값을 부르는 자가 있다. 던전 안쪽은 온통 젖은 진흙인데 그의 신발은 깨끗하다.

- H: `값을 치르기 전에 무엇을 직접 봤는지 물어보라고 하세요` → 대답을 얼버무려 거짓 정보임을 눈치챈다.
- X: `값을 치르고 앞길 이야기를 사라고 하세요` → 틀린 정보에 돈까지 잃는다.
- N: `그냥 지나치라고 하세요` → 정보 없이 진행한다.

### M17 [직관] 오래된 소문

**상황:** 상인은 오늘 아침 들은 정보라면서 말끝에 “지난달에도 똑같았다”고 덧붙인다.

- H: `오늘 직접 확인한 내용이 있는지 묻자고 하세요` → 새 정보가 아니라 오래된 소문임이 드러난다.
- X: `반복된 정보니 믿을 만하다며 돈을 내자고 하세요` → 낡은 정보에 값을 치른다.
- N: `무료로 들은 부분만 기억하자고 하세요` → 추가 정보는 없지만 골드는 지킨다.

### M18 [추론] 서로 다른 두 길

**상황:** 상인은 왼쪽 길이 안전하다고 한다. 그의 메모에는 왼쪽 옆에 해골 표시, 오른쪽 옆에 동그라미가 그려져 있다.

- H: `메모의 표시가 무슨 뜻인지 먼저 묻자고 하세요` → 말과 기록이 어긋나 있음을 확인한다.
- X: `입으로 한 말을 믿고 왼쪽 정보를 사자고 하세요` → 위험한 길을 안전하다고 믿는다.
- N: `두 길 모두 직접 확인하자고 하세요` → 시간이 들지만 정보에 의존하지 않는다.

### M19 [추론] 지나치게 구체적인 시간

**상황:** 상인은 “정확히 스무 걸음 뒤, 정확히 세 번째 문”이라고 말하지만 자신은 횃불 없이 다녀왔다고 한다. 통로는 지금도 완전히 어둡다.

- H: `어둠 속에서 어떻게 셌는지 물어보라고 하세요` → 설명이 막혀 정보 신뢰도가 떨어진다.
- X: `구체적인 정보니 확실하다며 값을 내라고 하세요` → 꾸며낸 정보에 속는다.
- N: `위치 정보 대신 주변 특징만 무료로 물어보자고 하세요` → 제한적인 단서만 얻는다.

### M20 [함정] 공짜 첫 문장

**상황:** 상인은 첫 문장은 공짜라며 “앞에는 적이 없다”고 말한다. 바로 이어서 “적어도 내가 돌아설 때까지는”이라고 덧붙인다.

- H: `언제 돌아섰는지부터 확인하자고 하세요` → 오래된 관찰인지 확인해 구매 여부를 판단한다.
- X: `공짜 정보가 맞았으니 나머지도 사자고 하세요` → 현재성 없는 정보에 돈을 낸다.
- N: `첫 문장만 참고하고 거래하지 말자고 하세요` → 불완전하지만 무료 정보만 챙긴다.

## 5.11 MERCHANT — 수상한 상인 행동 5

### M21 [직관] 닫히는 상자

**상황:** 파티가 다가가자 상인은 열려 있던 작은 상자를 급히 닫고 그 위에 팔꿈치를 올린다.

- H: `보이는 물건만 거래하자고 하세요` → 숨기려는 물건에는 손대지 않는다.
- X: `좋은 물건을 숨기는 것 같다며 상자까지 보여달라고 하세요` → 언쟁이 커져 거래 자체가 깨진다.
- N: `거리를 두고 필요한 물건 가격만 물어보세요` → 제한적으로 거래한다.

### M22 [직관] 바뀌는 이름

**상황:** 상인은 처음에는 자신을 로안이라고 소개했지만 잠시 뒤 다른 손님에게는 마렉이라고 말한다.

- H: `거래 전에 이름부터 다시 확인하자고 하세요` → 당황하는 반응을 보고 큰 거래를 피한다.
- X: `가명 정도는 흔하다며 귀중품까지 맡기자고 하세요` → 신원 불명인 사람에게 물건을 넘긴다.
- N: `현금 소액 거래만 하자고 하세요` → 위험을 제한한다.

### M23 [추론] 계속 바뀌는 자리

**상황:** 상인은 같은 대화를 하면서도 계속 출구 쪽으로 짐을 조금씩 옮긴다. 아직 거래는 끝나지 않았다.

- H: `돈을 먼저 넘기지 말고 물건과 동시에 교환하자고 하세요` → 상인이 달아날 틈을 줄인다.
- X: `급해 보이니 돈부터 건네고 포장하게 하자고 하세요` → 돈을 받은 상인이 짐을 들고 달아난다.
- N: `거래를 중단하고 보내주자고 하세요` → 손실 없이 끝난다.

### M24 [추론] 손님을 피하는 상인

**상황:** 멀리서 다른 파티가 보이자 상인은 목소리를 낮추고 상품 표식을 천으로 덮는다. 다른 파티는 그를 보며 손가락질한다.

- H: `다른 파티가 왜 저러는지 먼저 확인하자고 하세요` → 이전 거래 문제를 듣고 거래를 피한다.
- X: `경쟁 상인이겠거니 하고 빨리 사자고 하세요` → 문제 있는 상인에게 서둘러 돈을 준다.
- N: `양쪽 모두 상대하지 말고 떠나자고 하세요` → 정보도 거래도 포기한다.

### M25 [함정] 친절한 선결제

**상황:** 상인은 파티가 피곤해 보인다며 물건은 나중에 고르라 하고 먼저 할인된 금액만 내두라고 권한다. 그의 짐은 이미 끈으로 묶여 있다.

- H: `물건을 고른 뒤에 계산하자고 하세요` → 선결제를 피하고 실제 물건을 확인한다.
- X: `친절하게 할인해준다니 먼저 돈을 내자고 하세요` → 상인이 짐을 들고 떠난다.
- N: `오늘 거래는 하지 말자고 하세요` → 아무 손실 없이 지나간다.

## 5.12 MERCHANT — 위험한 물품 5

### M26 [직관] 새는 기름병

**상황:** 등불 기름병 마개 주변이 젖어 있고 상인의 손에도 기름이 묻어 있다.

- H: `새지 않는 병으로 바꿔달라고 하세요` → 안전한 병을 받는다.
- X: `값이 싸니 그대로 사서 가방에 넣자고 하세요` → 가방 안으로 기름이 새어 다른 물건까지 젖는다.
- N: `기름은 사지 말자고 하세요` → 위험도 보급도 없다.

### M27 [직관] 깨진 화살촉 묶음

**상황:** 할인 화살 묶음의 앞쪽 몇 개는 멀쩡하지만 뒤쪽 화살촉 하나는 금이 가 있다.

- H: `묶음을 풀어 전부 확인하고 멀쩡한 것만 사자고 하세요` → 사용할 수 있는 화살만 산다.
- X: `앞쪽이 멀쩡하니 묶음째 사자고 하세요` → 전투 중 깨지는 화살이 섞여 있다.
- N: `화살 구매를 미루자고 하세요` → 현재 비축량만 사용한다.

### M28 [추론] 열 나는 부적

**상황:** 상인이 행운의 부적이라며 건넨 금속 조각은 손에 오래 쥘수록 뜨거워진다. 천 위에 놓으면 천 색이 조금 진해진다.

- H: `맨몸에 차는 물건은 사지 말자고 하세요` → 화상 위험을 피한다.
- X: `따뜻하니 추위에도 좋겠다며 목에 걸자고 하세요` → 피부가 빨갛게 달아오른다.
- N: `직접 착용하지 않고 싸게 사서 길드에 가져가자고 하세요` → 즉시 사용은 피하지만 짐 하나가 늘어난다.

### M29 [추론] 흔들리는 연막탄

**상황:** 연막탄을 흔들면 안에서 딱딱한 것이 굴러가는 소리가 난다. 다른 연막탄은 같은 소리가 나지 않는다.

- H: `소리 나는 것은 빼고 정상 제품만 사자고 하세요` → 불량품을 피한다.
- X: `안에 내용물이 많아서 그렇다며 그걸 고르자고 하세요` → 사용 순간 껍질이 깨져 손에서 터진다.
- N: `연막탄을 아예 사지 말자고 하세요` → 장비 추가 없이 지나간다.

### M30 [함정] 강력한 횃불 가루

**상황:** 상인은 불꽃을 크게 만드는 가루라며 작은 주머니를 판다. 주머니 겉면 한쪽에는 불에 그을린 자국이 있고 상인은 불 근처에 두지 않는다.

- H: `휴대용으로는 위험하니 사지 말자고 하세요` → 불안정한 가루를 피한다.
- X: `불꽃이 강하면 던전에서 유용하다며 사서 횃불 옆에 넣자고 하세요` → 열에 반응해 가방 안에서 연기가 난다.
- N: `사용법만 듣고 구매는 미루자고 하세요` → 정보만 얻고 물건은 받지 않는다.

- N: `돌 위에 짐을 던져 먼저 시험하자고 하세요` → 장치는 작동하지만 짐 하나가 손상된다.

### S26 [직관] 벽의 낙서 — 기존 유지

**상황:** 벽에 급히 새긴 글씨가 있다. `셋을 두고 혼자 나오면 몫이 는다.` 글씨 아래에는 마른 핏자국이 있고 성직자가 바로 뒤에서 같은 벽을 따라 걸어오고 있다.

- H: `글씨를 파티에게 보여주세요` → 모두가 같은 정보를 공유해 길잡이만 숨겼다는 의심을 막는다.
- X: `글씨를 문질러 지우세요` → 성직자가 지우는 모습을 보고 의심한다.
- N: `못 본 척 지나가세요` → 아무도 내용을 읽지 않는다.

### S27 [직관] 남은 회복약 하나

**상황:** 회복약이 한 병뿐이다. 전사는 피가 나지만 서 있을 수 있고, 마법사는 상처는 없지만 숨을 헐떡인다.

- H: `당장 필요한 사람이 생길 때까지 보관하자고 하세요` → 누구도 독점하지 않고 비상용으로 남긴다.
- X: `전투를 많이 한 전사에게 미리 마시게 하자고 하세요` → 필요 이상의 회복약을 써 다른 파티원이 불만을 가진다.
- N: `누가 마실지 둘이 결정하게 두세요` → 길잡이는 개입하지 않지만 논쟁이 길어진다.

### S28 [추론] 없어진 동전

**상황:** 공용 주머니에서 동전 두 개가 사라졌다. 도적은 주머니 근처에 있었지만, 바닥에는 주머니 솔기가 터져 생긴 작은 구멍과 동전 끌린 자국이 있다.

- H: `바닥부터 찾아보자고 하세요` → 틈에 굴러간 동전을 찾아 불필요한 의심을 막는다.
- X: `가장 가까이 있던 도적부터 추궁하자고 하세요` → 근거 없는 의심으로 관계가 악화된다.
- N: `동전 두 개는 포기하자고 하세요` → 갈등은 피하지만 자원을 잃는다.

### S29 [추론] 다른 기억

**상황:** 전사는 왼쪽에서 왔다고 하고 성직자는 오른쪽이라고 기억한다. 뒤를 보니 양쪽 바닥에 파티의 발자국이 있지만 오른쪽 발자국 위에만 최근 먼지가 다시 내려앉았다.

- H: `먼지가 덜 쌓인 왼쪽 흔적을 따라가자고 하세요` → 최근 지나온 길을 찾아 논쟁을 끝낸다.
- X: `목소리가 더 큰 전사의 기억대로 가자고 하세요` → 근거 대신 주장으로 결정해 길을 잃는다.
- N: `둘 다 조금씩 확인하자고 하세요` → 갈등은 줄지만 시간이 든다.

### S30 [함정] 계약서 사본 대체 — 무거운 전리품

**상황:** 파티가 큰 금속 상자를 발견했다. 전사는 보상 때문에 가져가자고 하고 도적은 버리자고 한다. 상자를 한 명이 들어보자 걸음이 눈에 띄게 느려지고 금속이 바닥에 계속 긁힌다.

- H: `내용물만 확인해 필요한 것만 나눠 들자고 하세요` → 이동 속도와 소음을 줄이면서 가치 있는 물건만 챙긴다.
- X: `발견한 건 전부 보상이라며 상자째 들고 가자고 하세요` → 속도가 크게 느려지고 소리 때문에 위험을 끌어들인다.
- N: `상자를 표시만 해두고 돌아올 때 결정하자고 하세요` → 현재 갈등을 미루지만 확보는 보장되지 않는다.

# 7. ID 규칙

기존 사건 ID는 가능한 한 보존한다.

신규 사건은 다음 형식을 권장한다.

```text
shared-rest-<slug>
shared-merchant-<slug>
shared-special-<slug>
```

조언 ID는 기존 규칙처럼 사건 ID에 `-a`, `-b`, `-c`를 붙인다.

단, a/b/c 자체가 help/harm/neutral을 의미한다는 계약은 만들지 않는다. 실제 `outcome` 필드가 진실의 원천이다.

# 8. Effect tag 사용

F3-4는 신규 effect tag를 추가하지 않는다.

현재 존재하는 범위 안에서 의미에 맞게 재사용한다.

- `support`
- `sabotage`
- `rest`
- `trade`
- `item`
- `information`
- `observe`

정확한 tag 배치는 구현 시 기존 domain 정의와 테스트를 기준으로 한다.

# 9. 범위 밖

F3-4에서 하지 않는다.

- 테마별 ecology source 추가
- boss 전용 modifier 추가

- UI 변경
- 자동전투 연출 구현
- 아이템 시스템 F5 구현

- validator 계약 완화

# 10. 완료 조건

F3-4 완료 조건:

1. 공용 사건 총 90개
2. `rest / merchant / special` 각각 정확히 30개
3. 각 대분류는 문서상 6개 상황군 × 5개 균형을 만족
4. 각 상황군은 직관 2 / 추론 2 / 함정 1을 목표로 리뷰 완료
5. 기존 15개 중 좋은 콘텐츠는 유지, 약한 단서 및 중복 트릭은 보수
6. 기존 `validateSituationEvents(SHARED_EVENTS)` 통과
7. event/advice ID 중복 없음
8. 제목/description의 명백한 완전 중복 없음
9. 모든 사건이 description 내부 단서만으로 판단 가능
10. harm 선택지가 얼핏 합리적으로 보임
11. `pnpm lint` 통과
12. `pnpm typecheck` 통과
13. `pnpm test` 통과
14. `pnpm build` 통과
15. 작업 배정표 F3-4를 완료 상태로 갱신
