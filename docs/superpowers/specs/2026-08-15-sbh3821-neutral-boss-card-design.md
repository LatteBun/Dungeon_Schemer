# 중립 보스 정보 카드 설계

- 작성일: 2026-08-15
- 작성자: sbh3821
- 작업 ID: [F3](../../technical/PROTOTYPE_WORK_ASSIGNMENT.md)
- 상위 spec: [던전 15개 캠페인 게임 방향 개편](2026-08-13-sanghwan-yoo-game-direction-rework-design.md)의 `정보 카드와 개인 반응`
- 발견 경위: [용사 대상 정보 판정](2026-08-15-sbh3821-party-info-evaluation-design.md) 구현 중

## 문제

정보 카드 12장 중 주제가 `boss`인 것은 `card-truth-boss`와 `card-lie-boss`
둘뿐이다. 중립 보스 카드가 없어서 두 가지가 어긋난다.

**상위 spec의 규칙 하나가 실행되지 않는다.** 수용한 보스 정보의 피해 보정은
진실 -20%, 중립 -10%, 거짓 +25%인데, 중립 보스 카드가 없으므로 `-10%`가 한 번도
발생하지 않는다. `E3`이 계산 규칙을 구현했지만 실제 콘텐츠로는 도달할 수 없다.

**보장 지점의 선택지가 두 장으로 줄어든다.** `E2`는 보스 보장 지점에서 보스 주제
카드만 제시한다. 상위 spec은 `진실·거짓·중립 카드 중 하나를 고른다`고 정했는데
지금은 중립으로 빠질 길이 없다.

## 해결

**카드를 추가하지 않고 기존 중립 카드 하나를 보스 주제로 바꾼다.**

`validateContentPools`는 카드가 정확히 12장이고 진위별로 정확히 4장일 것을
요구한다. 13장이 되면 어느 한 진위가 5장이 되어 그 검사를 깨뜨린다. 균형을 지키며
늘리려면 15장이 되어야 하는데, 이 작업은 죽어 있는 규칙 하나를 살리는 것이지 카드
풀을 키우는 것이 아니다.

바꿀 카드는 `card-neutral-route`다. `route` 주제가 진실·거짓·중립 세 장으로 가장
많아서, 여기서 하나를 빼면 주제 분포가 가장 고르게 남는다.

| 주제 | 지금 | 바꾼 뒤 |
| --- | ---: | ---: |
| route | 3 | 2 |
| event | 2 | 2 |
| monster | 2 | 2 |
| rest | 1 | 1 |
| merchant | 2 | 2 |
| boss | 2 | **3** |

전체 12장과 진위별 4장은 그대로다.

## 새 카드

```
id       card-neutral-boss
truthType neutral
subject   boss
topic    보스의 소문
text     보스를 본 사람들의 말이 서로 엇갈린다.
```

중립 카드는 참도 거짓도 아닌 정보다. `보스는 반복되는 소리에 반응한다`(진실)나
`보스는 같은 공격을 두 번 사용하지 않는다`(거짓)와 달리, 검증할 주장을 담지 않고
판단을 파티에게 넘긴다. 수용하면 보스전 준비에 조금 도움이 되지만 결정적이지는
않다는 `-10%`의 성격과 맞는다.

## 남는 한계

A·S급은 경로마다 보스 보장이 2회다. 보스 카드가 3장뿐이므로 두 기회가 같은 세
장에서 뽑힌다. 카드 중복 금지는 사건에만 걸린 규칙이라 규칙 위반은 아니지만,
A·S 플레이에서 같은 카드를 다시 보게 된다.

이번 범위에서 늘리지 않는 이유는 12장·진위별 4장이라는 F2 계약을 지키기
때문이다. 늘리려면 15장으로 가야 하고, 그것은 콘텐츠 확장 결정이지 죽은 규칙을
살리는 작업이 아니다. `C4` 백테스트가 보스 정보 분포를 보고한 뒤 판단할 일이다.

## 테스트 목록

- 보스 주제 카드가 진실·거짓·중립 세 유형을 모두 갖는다
- 전체 12장과 진위별 4장이 유지된다
- 보스 보장 지점이 세 유형을 한 장씩, 모두 보스 주제로 제시한다
- 실제 콘텐츠에서 `수용한 중립 보스 정보`가 `-0.1` 보정을 만든다
- 일반 정보 지점은 여전히 보스가 아닌 카드로 세 유형을 채운다
