## 1. 목적

사막 테마의 일반 몬스터 5종과 위험도 구간별 보스 4종을 실제 전투 장면에서 재사용할 수 있는 개별 투명 PNG 에셋으로 만든다. 에셋은 공식 콘텐츠 이름·생태 특성·보스 행동을 외형에서 읽을 수 있게 하되, UI 아이콘이나 로고가 아니라 U2/U3와 같은 세계의 회화풍 게임 일러스트로 보여야 한다.

이번 작업은 전투 규칙이나 몬스터 수치를 바꾸지 않는다. `lib/content/themes.ts`의 공식 콘텐츠를 시각 에셋으로 옮기고, 실제 UI에 연결하기 전 검수 가능한 카탈로그 화면과 자동 자산 검사를 제공한다.

## 3. 공통 시각 계약

모든 9종은 다음을 공유한다.

- 반실사 다크 판타지 회화풍이다.
- U2/U3의 낮은 채도, 거친 재질, 따뜻한 금빛 림라이트와 암색 명암을 계승한다.
- 플랫 벡터, 픽토그램, 로고, 원형 메달리온, 카툰 스타일로 만들지 않는다.
- 피사체는 화면 왼쪽을 향한 약 30도 3/4 시점이다. 완전 정면이나 완전 좌측면을 피한다.
- 전투 화면에서 몬스터가 위쪽에 놓이고 아래쪽 파티를 바라본다고 가정해 머리와 공격 축이 왼쪽 아래 방향으로 자연스럽게 읽히게 한다.
- 피사체 전체 실루엣과 주요 공격 부위를 한눈에 식별할 수 있게 한다.
- 배경은 투명하다. UI 프레임, 이름표, 텍스트, 배경 장면을 에셋 안에 포함하지 않는다.
- 각 파일의 캔버스는 1:1이며 실제 피사체 둘레에 안전 여백을 둔다. 다양한 전투 슬롯에서 `object-fit: contain`으로 사용할 수 있어야 한다.
- 원본 PNG는 최소 1024×1024 RGBA다.
- 개별 에셋끼리 묘사 밀도와 광원 방향을 맞춘다. 보스는 일반 몬스터보다 실루엣 복잡도와 체급감이 높아야 한다.

## 4. 파일 계약

경로는 기존 거미 에셋과 같은 구조를 따른다.

```text
public/assets/monsters/desert/
├─ monster-desert-scorpion.png
├─ monster-desert-lizard.png
├─ monster-desert-cobra.png
├─ monster-desert-spirit.png
├─ monster-desert-mummy.png
├─ boss-desert-01-zakar.png
├─ boss-desert-02-kardum.png
├─ boss-desert-03-obelon.png
└─ boss-desert-04-nephris.png
```

파일명은 콘텐츠 ID와 1:1로 대응하며 임의 별칭을 추가하지 않는다.

## 5. 검수 카탈로그 화면

실제 전투 U5 구현과 분리된 개발용 하네스를 만든다.

```text
/desert-monsters-test
```

화면은 두 섹션으로 나눈다.

1. 일반 몬스터 5종
2. 보스 4종

각 카드에는 개발 검수용으로 이름, 콘텐츠 ID, 공식 특성/보스 설명, 실제 PNG를 표시한다. 이 정보는 게임 플레이 UI가 아니라 자산 검수 하네스에만 존재한다.

검수 화면의 목적은 다음이다.

- 피사체가 잘리지 않는지 확인
- 개별 PNG가 투명 배경인지 확인
- 전 종의 시점·광원·묘사 밀도가 한 세트처럼 보이는지 확인
- 보스가 일반 몬스터보다 충분히 위압적인지 확인
- 1024×640부터 3440×1440까지 카드가 왜곡 없이 재배치되는지 확인

## 6. 반응형 계약

검수 페이지는 게임 셸을 흉내 내기보다 에셋 검수에 집중하는 독립 카탈로그다. 그리드는 viewport에 따라 열 수를 바꾸며 카드 자체는 최소 폭을 가진다.

필수 검증 viewport:

- 1024×640
- 1280×720
- 1366×768
- 1536×720
- 1536×864
- 1920×1080
- 2560×1440
- 3440×1440

모든 viewport에서 다음을 만족한다.

- 가로 스크롤 없음
- 이미지 비율 왜곡 없음
- 피사체 잘림 없음
- 이름·ID·특성 텍스트 카드 밖 overflow 없음
- PNG는 `object-fit: contain`으로 표시
- 큰 화면에서 이미지가 지나치게 작게 고정되지 않음

## 7. 자동 테스트

새 자산 테스트는 다음을 확인한다.

- `public/assets/monsters/desert/`에 정확히 9개 계약 파일이 존재한다.
- 각 파일이 PNG signature를 가진다.
- 각 PNG의 IHDR 폭·높이가 최소 1024×1024다.
- PNG color type이 alpha를 포함하는 RGBA/GA 계열이다.
- 검수 컴포넌트가 9개 파일 경로와 공식 이름을 모두 참조한다.
- 검수 페이지 route가 카탈로그 컴포넌트를 렌더링한다.

이미지의 미적 품질, 30도 시점, 실루엣은 자동 테스트로 판정하지 않고 브라우저 캡처로 사람이 검수한다.

## 9. 완료 기준

- 공식 사막 일반 몬스터 5종과 보스 4종이 누락 없이 개별 PNG로 존재한다.
- 모든 파일이 기존 거미와 같은 `public/assets/monsters/<theme>/` 규칙을 따른다.
- 투명 1:1 고해상도 에셋이며 UI 프레임·텍스트·배경이 이미지 안에 없다.
- U2/U3 레퍼런스의 반실사 다크 판타지 톤과 왼쪽 30도 3/4 시점을 한 세트로 유지한다.
- `/desert-monsters-test`에서 9종을 한 화면에서 검수할 수 있다.
- 자동 자산 테스트가 통과한다.
- 브라우저에서 노트북, 1920×1080, QHD 이상을 포함한 필수 viewport를 검수하고 캡처를 남긴다.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`를 실행해 결과를 PR에 기록한다.
- `feature/desert-monster-assets` 브랜치에서 `main` 대상 Draft PR을 연다.
