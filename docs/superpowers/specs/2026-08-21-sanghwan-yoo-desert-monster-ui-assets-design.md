# 사막 몬스터 UI 에셋 패키지 설계

작성 도구: Codex

## 목적

사막 테마의 잡몹·보스 UI 에셋 9개를 저장소에 추가하고, 향후 던전 진행·보스 정보 UI가 기존 자산을 우선 재사용할 수 있도록 자산 카탈로그와 공식 문서 연결을 만든다.

## 범위

- `public/assets/monsters/dessert/`의 사막 PNG 9개를 추가한다. 폴더명 `dessert`는 기존 경로이므로 이번 작업에서 바꾸지 않는다.
- `docs/experience/DESERT_MONSTER_ASSETS.md`에 파일 경로, 실제 해상도, 공식 콘텐츠 이름, 재사용 규칙을 기록한다.
- `docs/systems/DUNGEON_THEMES_AND_ECOLOGY.md`의 사막 콘텐츠 관련 문서 목록에 위 카탈로그를 연결한다.
- UI 컴포넌트, 게임 데이터, 이미지 변환·리사이즈, 묘지·거미굴 에셋은 변경하지 않는다.

## 에셋 계약

| 구분 | 공식 콘텐츠 | 파일 | 원본 해상도 |
| --- | --- | --- | --- |
| 잡몹 | 사막전갈 | `monster-desert-scorpion.png` | 1024×1024 |
| 잡몹 | 모래도마뱀 | `monster-desert-lizard.png` | 1024×1024 |
| 잡몹 | 사막코브라 | `monster-desert-cobra.png` | 1254×1254 |
| 잡몹 | 모래정령 | `monster-desert-spirit.png` | 1254×1254 |
| 잡몹 | 미이라 | `monster-desert-mummy.png` | 1254×1254 |
| 보스 ★1 | 거대 전갈 자카르 | `boss-desert-01-zakar.png` | 1254×1254 |
| 보스 ★2 | 샌드웜 카르둠 | `boss-desert-02-kardum.png` | 1024×1024 |
| 보스 ★3 | 모래거신 오벨론 | `boss-desert-03-obelon.png` | 1024×1024 |
| 보스 ★4~5 | 스핑크스 네프리스 | `boss-desert-04-nephris.png` | 1254×1254 |

모든 경로는 `/assets/monsters/dessert/<파일명>`으로 정적 제공된다. UI는 도메인 데이터가 가리키는 현재 출현 몬스터 또는 보스에만 해당 에셋을 매핑하며, 이미지 파일명으로 게임 규칙·위험도·보스를 추론하거나 재정의하지 않는다.

## 향후 UI 재사용 규칙

- 던전 진행 화면의 장면 슬롯, 몬스터 정보 영역, 보스 정보·정산 UI에서 사막 몬스터를 표시해야 할 때 이 카탈로그를 먼저 확인한다.
- 원본이 정사각형이므로 표시 슬롯에서 비율을 왜곡하지 않고 `object-fit: contain`을 기본으로 한다. 의도된 crop이 필요하면 해당 UI 작업 문서에 별도로 기록한다.
- 사막 패키지에 실제로 출현하지 않는 잡몹을 장식용으로 노출하지 않는다. 보스도 공식 콘텐츠의 초기 위험도 구간 선택 결과에 맞는 이미지만 사용한다.
- 새 사막 몬스터·보스 UI 에셋을 만들 때는 이 카탈로그, `DUNGEON_THEMES_AND_ECOLOGY.md`, `UI_IMPLEMENTATION_GUIDE.md`를 함께 확인해 기존 다크 판타지 시각 언어와 콘텐츠 계약을 따른다.

## 문서 구조

```text
docs/systems/DUNGEON_THEMES_AND_ECOLOGY.md
└─ 사막 몬스터 UI 에셋 카탈로그 링크

docs/experience/DESERT_MONSTER_ASSETS.md
└─ 자산 목록 · 해상도 · 정적 경로 · UI 재사용 규칙
```

시스템 문서에는 자산 세부 목록을 중복하지 않고 카탈로그 링크만 둔다. 카탈로그는 콘텐츠 규칙을 새로 정의하지 않으며, 공식 이름과 위험도 구간은 시스템 문서를 따른다.

## 오류 방지와 검증

- 추가하는 9개 파일이 모두 PNG이고, 카탈로그의 경로·해상도와 일치하는지 확인한다.
- 카탈로그의 몬스터·보스 이름과 위험도 구간이 공식 테마 문서의 확정 콘텐츠 목록과 일치하는지 확인한다.
- Markdown 링크가 실제 파일을 가리키는지 문서 검증 테스트로 확인한다.
- 코드 변경이 없으므로 자산·문서 변경 후 기존 typecheck와 test를 실행한다.

## 완료 조건

- 사막 잡몹 5개와 보스 4개가 한 PR에만 포함된다.
- 향후 UI 작업자가 자산 위치·표시 조건·비율 보존 규칙을 문서에서 확인할 수 있다.
- 거미굴·캐릭터 자산 및 UI 컴포넌트는 이 PR에 포함하지 않는다.
