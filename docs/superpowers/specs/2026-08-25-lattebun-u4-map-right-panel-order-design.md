# U4 지도 우측 패널 순서 개선 설계

- 작성자: LatteBun
- 작성 도구: Codex
- 작성일: 2026-08-25
- 상태: 사용자 설계 승인 완료, 서면 spec 검토 대기

## 1. 목적

던전 지도 우측 패널에서 `계약 전 답사`와 `선택한 지점`의 순서를 바꾼다.
플레이어가 이동 판단의 근거를 먼저 읽고 목적지를 확인한 뒤, 패널의 가장 아래에
있는 `이 지점으로 이동` CTA로 결정을 확정하게 한다.

## 2. 현재 문제

현재 우측 패널은 다음 순서다.

```text
파티 상태
선택한 지점
이 지점으로 이동
계약 전 답사
```

이 순서는 이동 CTA 아래에 참고 정보가 이어져, CTA가 화면 흐름의 마지막
행동처럼 보이지 않는다. 사용자가 요청한 정보 위계는 답사 정보를 먼저 읽고
선택한 지점과 이동 행동을 마지막에 확인하는 구조다.

## 3. 승인된 배치

우측 패널의 DOM과 시각 순서를 모두 다음처럼 맞춘다.

```text
파티 상태
계약 전 답사
선택한 지점
이 지점으로 이동
```

- `파티 상태`는 기존처럼 상단에 둔다.
- `계약 전 답사`는 중앙의 가변 높이 영역을 사용한다.
- `선택한 지점`과 그 안의 이동 CTA는 하단의 내용 높이 영역에 둔다.
- 답사 규칙이 길어지면 기존처럼 답사 영역 내부만 세로 스크롤한다.
- `survey`가 없는 프리뷰에서도 선택 지점 영역은 최하단 자리를 유지한다.
- 키보드와 스크린 리더의 읽기 순서도 화면 순서와 같게 DOM을 재배치한다.

## 4. 구현 경계

### 컴포넌트

`components/game/U4DungeonMapScreen.tsx`의 `RightPanel`에서 답사 section을
선택 지점 section 앞으로 옮긴다. 표시 문구와 조건부 렌더링, 목적지 선택과 이동
callback은 바꾸지 않는다.

### 레이아웃

`app/u4-dungeon-map.css`의 우측 패널을 `상단 자동 높이 / 중앙 가변 높이 /
하단 자동 높이` 세 행으로 정의한다. 파티, 답사, 선택 지점 section에 명시적인
행을 부여해 답사 section이 없더라도 선택 지점과 CTA가 마지막 행에 남게 한다.

`app/u4-dungeon-map-fixes.css`에는 우측 패널 행 구성을 덮어쓰는 규칙을 추가하지
않는다.

## 5. 유지할 동작

- 선택 가능한 지도 지점과 `aria-pressed` 상태
- 선택 지점의 사건 분류 아이콘과 설명
- 목적지가 없을 때 CTA 비활성화
- CTA가 선택한 NodeId를 `onMove`에 전달하는 동작
- 계약 전 답사의 공개 생태 규칙과 지나온 지점 수
- 파티 카드와 원정 변화 내역
- 1920×1080 고정 캔버스와 기존 색·에셋·타이포그래피

도메인, Store, 사건 생성, 생태 공개 규칙, 이미지 에셋은 변경하지 않는다.

## 6. 공식 문서 반영

- `docs/experience/U4_DUNGEON_MAP.md`에 우측 패널의 상단·중앙·하단 순서와
  CTA 최하단 기준을 기록한다.
- `docs/experience/SCREEN_LAYOUT.md`의 지도 RightPanel 설명을 같은 순서로
  갱신한다.
- 게임 원칙과 게임 규칙은 바뀌지 않으므로 `docs/GAME_PRINCIPLES.md`와 시스템
  문서는 수정하지 않는다.

## 7. 검증

1. 컴포넌트 테스트에서 `계약 전 답사`가 `선택한 지점`보다 먼저, `이 지점으로
   이동`이 그 뒤에 렌더링되는지 검사한다.
2. 고정 캔버스 CSS 계약 테스트에서 우측 패널이 `auto minmax(0, 1fr) auto` 세
   행이며 파티·답사·선택 지점이 각각 1·2·3행을 사용하는지 검사한다.
3. 전체 단위 테스트, lint, typecheck를 실행한다.
4. 실제 캠페인 지도에서 답사 내용이 긴 상태와 목적지 미선택·선택 상태를
   확인하고, CTA가 우측 패널 최하단에 있으며 잘리거나 겹치지 않는지 검증한다.
5. 고정 캔버스 기준 viewport에서 가로·세로 스크롤과 레이아웃 재배치가 없는지
   확인한다.

## 8. 완료 조건

- 우측 패널이 `파티 상태 → 계약 전 답사 → 선택한 지점 → 이 지점으로 이동`
  순서로 보이고 읽힌다.
- `이 지점으로 이동` CTA가 우측 패널의 가장 아래에 있다.
- 답사 내용이 길어져도 선택 지점과 CTA를 밀어내지 않는다.
- 기존 선택·이동·답사·파티 동작과 데이터는 변하지 않는다.
- 관련 자동 테스트와 실제 화면 검증이 통과한다.
