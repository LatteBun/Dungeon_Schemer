# U6 정산 복귀 CTA 크기 개선 설계

- 작성자: LatteBun
- 작성 도구: Codex
- 작성일: 2026-08-25
- 상태: 사용자 설계 승인 완료, 서면 spec 검토 대기

## 1. 목적

던전 결과 정산 화면의 `길드로 돌아간다` 버튼이 우측 패널 전체 폭으로 늘어나
지나치게 커 보이는 문제를 해결한다. 다른 화면의 다음 단계 CTA와 같은 조형과
크기 체계를 사용하면서, 정산 화면에서는 문구에 필요한 폭만 차지하게 한다.

## 2. 현재 문제와 원인

`길드로 돌아간다`, U5의 결과 확인 버튼, 보스전의 정산 버튼은
`app/globals.css`에서 같은 공통 CTA 규칙을 공유한다. 이 규칙은 내용 폭,
공통 최소 높이, 좌우 padding, 글자 크기와 포커스 표시를 제공한다.

정산 화면은 `app/u6-result.css`에서 버튼에 `justify-self: stretch`를 추가한다.
이 화면 전용 선언 때문에 공통 CTA의 내용 폭 대신 우측 패널 전체 폭을 사용하며,
문구와 비교해 버튼의 시각적 면적이 지나치게 커진다.

## 3. 승인된 배치

- 버튼 문구는 `길드로 돌아간다`를 유지한다.
- 버튼은 기존처럼 정산 우측 패널의 최하단에 둔다.
- 버튼은 우측에 정렬한다.
- 버튼 폭은 고정 px 값이나 패널 전체 폭이 아니라 문구와 공통 좌우 padding으로
  결정되는 내용 폭을 사용한다.
- 높이, 글자 크기, 테두리, 배경, hover와 `focus-visible`은 다른 다음 단계 CTA가
  사용하는 공통 규칙을 그대로 따른다.
- 클릭 callback과 캠페인 화면 전환은 변경하지 않는다.

## 4. 구현 경계

`app/u6-result.css`의 정산 화면 전용 CTA 규칙에서 가로 늘림을 제거하고
`justify-self: end`로 우측 정렬한다. 공통 CTA 규칙이 있는 `app/globals.css`와
React 컴포넌트 구조는 변경하지 않는다.

CSS 계약 테스트에는 정산 CTA가 `stretch`가 아니며 우측 정렬된다는 기대를
추가한다. 도메인 모델, 정산 계산, 캠페인 전환 로직, 이미지 에셋은 변경하지
않는다.

## 5. 공식 문서 반영

`docs/experience/SCREEN_LAYOUT.md`의 정산·엔딩 절에 복귀 CTA의 최하단 위치,
공통 크기 사용, 내용 폭과 우측 정렬 기준을 기록한다.

게임 규칙과 핵심 방향은 바뀌지 않으므로 `docs/GAME_PRINCIPLES.md`와 시스템
문서는 수정하지 않는다.

## 6. 검증

1. CSS 계약 테스트에서 정산 CTA가 공통 CTA 크기를 물려받고, 화면 전용
   규칙에서는 `justify-self: end`만 사용하며 `stretch`하지 않는지 확인한다.
2. 전체 단위 테스트, lint, typecheck를 실행한다.
3. `/u6-test` 정산 화면과 실제 캠페인 정산 화면에서 버튼이 우측 하단에 있고,
   문구가 잘리지 않으며 다른 다음 단계 CTA와 높이·글자 크기가 같은지 확인한다.
4. 공식 viewport에서 버튼과 우측 패널 콘텐츠가 겹치거나 잘리지 않는지 확인한다.

## 7. 완료 조건

- `길드로 돌아간다` 버튼이 패널 전체 폭보다 작고 내용에 맞는 폭으로 보인다.
- 버튼은 우측 패널 최하단의 우측 정렬을 유지한다.
- 공통 CTA의 최소 높이, 글자 크기, 상태 스타일과 키보드 포커스가 유지된다.
- 정산과 캠페인 전환 동작이 바뀌지 않는다.
- 관련 자동 테스트와 실제 화면 검증이 통과한다.
