# 진행 화면 UX 개선 설계

## 문서 정보

- 작성자: LatteBun
- 작성 도구: Codex
- 작성일: 2026-08-25
- 대상: 진행 화면 조언 카드, 비전투 파티 장면, 일반 몬스터 전투 CTA
- 기준 브랜치: `main` (`e83ae24`)

## 1. 목표

진행 화면의 조작 영역을 덜 답답하고 더 세계관 안의 물건처럼 보이게 하며, 일반 몬스터 전투 중에는 지도로 빠져나갈 수 없다는 상태를 한 개의 주요 CTA로 명확히 전달한다.

완료 목표는 다음과 같다.

- 좌측 하단 조언 카드 3장의 상하 길이를 줄인다.
- 세 카드를 승인된 `A1 · 원안 정제` 금속 명패 형태로 바꾼다.
- 전투가 아닌 진행 장면에도 현재 파티원 3명을 좌측에 표시한다.
- 일반 몬스터 전투 중 우측 하단의 기존 지도 복귀 자리를 `전투 건너뛰기`가 사용한다.
- 전투가 끝난 뒤 같은 버튼이 `지도로 돌아간다`로 바뀐다.
- 전투 중에는 지도 이동 콜백을 실행할 수 없다.

## 2. 근거와 범위

근거 문서는 다음과 같다.

- `docs/GAME_PRINCIPLES.md` — 플레이어는 전투원이 아니며 전투는 앞선 판단의 결과 장면이다.
- `docs/experience/SCREEN_LAYOUT.md` — 진행 화면의 상단 장면 40%, 하단 콘솔 60%, 동일 디자인 조언 3개 계약.
- `docs/experience/UI_IMPLEMENTATION_GUIDE.md` — 확정된 전투 기록만 재생하고 건너뛰기·다시 보기가 결과를 바꾸지 않는 계약.
- `docs/superpowers/specs/2026-08-22-sbh3821-u5-dungeon-progress-design.md` — U5 화면 구조와 ViewModel 경계.
- `docs/superpowers/specs/2026-08-23-sbh3821-u5-2-battle-replay-design.md` — 자동 재생 frame, complete, 건너뛰기, 다시 보기 계약.

이번 변경은 표현과 화면 내 이동 게이트만 다룬다. 전투 피해, HP, 신뢰, RNG, 사건 해결, 캠페인 phase는 바꾸지 않는다.

## 3. 승인된 시각 방향

### 3.1 조언 카드

사용자가 비교 시안에서 `A1 · 원안 정제`를 승인했다.

카드는 다음 외형을 사용한다.

- 모서리를 짧게 잘라낸 팔각형에 가까운 실루엣
- 짙은 갈색·흑철 바탕
- 얇은 금속 외곽선과 안쪽 이중 테두리
- 네 모서리의 작은 리벳
- 기존 슬롯 번호, 조언 문구, 구분선, 근거 문구의 정보 순서 유지

세 카드의 색, 장식, 크기, hover, focus 표현은 같다. `help / harm / neutral`, 정합 여부, 발각 확률, 예상 신뢰 변화는 외형으로도 드러내지 않는다.

카드는 하단 콘솔의 남은 세로 공간을 전부 채우지 않는다. 세 장을 같은 공통 높이로 만들고 카드 목록 영역 안에서 세로 중앙 정렬한다. 문구가 긴 카드 하나만 커지지 않으며, 승인 시안처럼 카드 위아래에 숨 쉴 공간이 남아야 한다.

### 3.2 비전투 파티 배치

전투 replay가 없는 진행 장면에서는 현재 파티원 3명의 기존 투명 PNG를 장면 좌측 하단에 표시한다.

- 원본 캐릭터가 오른쪽을 바라보므로 좌우 반전하지 않는다.
- 세 인물은 같은 바닥선에 서되 안정적인 파티 슬롯 순서에 따라 높이와 크기를 조금 달리해 깊이감을 준다. HP·신뢰·생존 여부에 따라 배치가 바뀌지 않는다.
- 인물끼리 실루엣을 가리지 않을 정도로만 겹친다.
- 장면의 장소 문구와 핵심 배경 피사체를 가리지 않는다.
- 우측 파티 카드가 상태 정보를 소유하므로 장면에는 이름, HP, 신뢰, 골드를 중복 표시하지 않는다.
- 장식 표현이므로 스크린 리더가 우측 파티 정보를 중복 읽지 않게 한다.

전투 replay가 있으면 이 배치를 렌더링하지 않는다. 기존 `U5BattleScene`의 파티·적 참가자만 표시한다.

## 4. 일반 몬스터 전투 CTA 상태

### 4.1 상태 전이

```text
replaying
  우측 하단: 전투 건너뛰기
  지도 이동: 불가
  ├─ 자연 재생 완료 ─────────┐
  └─ 전투 건너뛰기 ─────────┤
                              ▼
complete
  우측 하단: 지도로 돌아간다
  지도 이동: 가능
  └─ 다시 보기 → replaying
```

우측 하단에는 동시에 하나의 주요 CTA만 존재한다.

### 4.2 재생 중

- 기존 `지도로 돌아간다` 자리에는 `전투 건너뛰기`를 표시한다.
- 지도 이동 버튼을 숨기거나 disabled 복제본으로 남기지 않는다.
- 건너뛰기는 이미 만들어진 replay의 마지막 complete frame으로 이동한다.
- 건너뛰기에서 `ACKNOWLEDGE_OUTCOME`, BattleEngine, E2, E3, E4를 호출하지 않는다.

### 4.3 완료 후

- 자연 재생 또는 건너뛰기로 complete frame에 도달하면 같은 CTA의 문구와 handler를 `지도로 돌아간다`로 바꾼다.
- 이때만 `onAcknowledge`를 호출할 수 있다.
- 완료 장면의 `다시 보기`는 장면 안의 보조 버튼으로 유지한다.
- `다시 보기`를 누르면 frame index를 처음으로 되돌리고 우측 CTA를 다시 `전투 건너뛰기`로 바꾼다. 재생이 다시 끝날 때까지 지도 이동은 잠긴다.

### 4.4 적용 범위

게이트는 `CampaignScreen`이 일반 몬스터 사건 결과에 명시적으로 지정한다. 다음을 근거로 암묵 추론하지 않는다.

- `battleReplay`가 존재한다는 사실
- `acknowledgeLabel`이 특정 문자열이라는 사실
- scene kind가 `monster`처럼 보인다는 사실

보스전의 `정산으로`와 비전투 사건의 `지도로 돌아간다`는 기존 동작을 유지한다. 독립 `/u5-2-test` 프리뷰는 재생 중 건너뛰기와 완료 후 다시 보기를 계속 검증하지만 실제 지도 이동을 만들지 않는다.

## 5. 컴포넌트와 상태 소유권

### 5.1 재생 제어

현재 `U5BattleScene`이 소유한 frame index와 timer를 진행 화면이 사용할 수 있는 재생 제어 단위로 분리한다.

```text
U5ProgressScreen
├─ playback controller
│  ├─ currentFrame
│  ├─ isComplete
│  ├─ skipToComplete()
│  └─ replayFromStart()
├─ U5BattleScene (현재 frame 표현)
└─ RightPanel CTA (재생 상태에 따른 단일 버튼)
```

재생 제어 단위는 replay 내용 signature가 바뀌면 첫 frame으로 초기화한다. timer는 complete frame에서 예약하지 않고 replay 변경·unmount 때 정리한다. reduced motion은 공간 모션만 줄이며 frame 진행과 CTA 상태는 동일하게 유지한다.

`U5BattleScene`은 다음 표현만 담당한다.

- 현재 frame의 참가자, HP, 피해, 문장
- complete frame의 승패와 검증 문구
- complete 상태에서 `다시 보기` 보조 버튼

우측 하단 CTA와 지도 이동 가능 여부는 `U5ProgressScreen`이 담당한다.

### 5.2 명시적 일반전 정책

`U5ProgressScreen`에는 일반 몬스터 전투에서만 쓰는 명시적 exit 정책을 전달한다. 기본값은 기존 동작을 보존한다.

정책이 활성이고 `battleReplay`가 있을 때:

- `isComplete === false`: CTA는 `skipToComplete()`를 호출한다.
- `isComplete === true`: CTA는 기존 `onAcknowledge()`를 호출한다.

정책이 없으면 보스전과 비전투 화면의 기존 `onAcknowledge`·`acknowledgeLabel` 계약을 유지한다.

### 5.3 비전투 파티

비전투 장면 표현은 `progress.party`의 `portraitSrc`와 생존 상태를 그대로 소비한다. 새 캐릭터 registry나 경로 조합 로직을 만들지 않는다. 초상 경로가 없는 멤버는 깨진 이미지 대신 해당 자리만 비우며 장면과 우측 상태 카드는 계속 렌더링한다.

## 6. 접근성

- 조언 카드는 기존 실제 `button`과 native tab 순서를 유지한다.
- 잘린 모서리와 리벳은 장식이며 focus outline을 가리지 않는다.
- 비전투 장면의 파티 PNG는 우측 파티 카드와 중복되므로 장식으로 처리한다.
- `전투 건너뛰기`, `지도로 돌아간다`, `다시 보기`는 모두 실제 `button`이다.
- 우측 CTA가 전환될 때 버튼의 보이는 문구와 accessible name이 함께 바뀐다.
- 전투 행동 알림의 기존 단일 `aria-live="polite"` 계약을 유지하고 CTA 변경용 live region을 추가하지 않는다.

## 7. 오류와 경계 조건

- replay frame이 비어 있으면 전투 장면과 건너뛰기 CTA를 렌더링하지 않는다.
- replay가 바뀌면 이전 timer와 frame index를 재사용하지 않는다.
- 연속으로 건너뛰기를 눌러도 마지막 frame을 넘지 않으며 `onAcknowledge`를 호출하지 않는다.
- complete 전에 지도 이동 callback을 DOM에 연결하지 않는다.
- 긴 조언 문구가 카드 밖으로 넘치면 카드마다 높이를 달리 키우지 않고 기존 줄바꿈 규칙으로 수용한다. 고정 캔버스에서 수용할 수 없는 콘텐츠는 테스트 실패로 다룬다.
- 캐릭터 초상 하나가 없어도 나머지 인물의 순서와 좌측 배치를 유지한다.

## 8. CSS와 고정 캔버스

- 1920×1080 고정 캔버스와 60:40 GameShell을 유지한다.
- 상단 장면 40%, 하단 콘솔 60% 비율을 바꾸지 않는다.
- `rem`, `cqw`, `cqh`를 사용하고 `vw`, `vh`, 화면별 `@media`를 추가하지 않는다.
- 카드 외형은 `app/u5-progress.css`, 전투 표현은 `app/u5-battle.css`의 기존 namespace 안에서 관리한다.
- 우측 하단 CTA는 기존 `.u5-outcome-continue` 자리와 공용 CTA 조형을 재사용한다.
- 캐릭터 PNG는 `object-fit: contain`으로 원본 비율을 보존하고 반전 transform을 적용하지 않는다.

## 9. 테스트 계약

### 9.1 단위·렌더 테스트

- 조언 카드 3장이 같은 class와 구조를 유지한다.
- 카드 목록이 남은 높이를 강제로 채우지 않고 세로 중앙 정렬 계약을 가진다.
- A1의 잘린 모서리, 이중 테두리, 리벳과 focus-visible이 존재한다.
- replay가 없으면 `progress.party`의 초상 3개가 좌측 비전투 장면에 렌더링된다.
- replay가 있으면 비전투 파티가 렌더링되지 않는다.
- 재생 중 우측 CTA는 하나이며 `전투 건너뛰기`다.
- 자연 완료와 건너뛰기 뒤 같은 CTA가 `지도로 돌아간다`로 바뀐다.
- 다시 보기 중 CTA가 `전투 건너뛰기`로 돌아간다.
- complete 전에는 `onAcknowledge`가 호출되지 않고 complete 뒤에만 호출된다.
- 보스전 `정산으로`와 비전투 사건의 기존 CTA 회귀가 없다.

### 9.2 브라우저 검증

실제 `/campaign` 흐름에서 일반 몬스터 사건을 사용해 다음을 확인한다.

1. 1920×1080에서 비전투 파티가 장면 좌측에 있고 조언 카드가 낮은 A1 형태다.
2. 전투 재생 중 우측 하단에는 `전투 건너뛰기`만 있다.
3. 건너뛰기 전에는 지도 이동이 불가능하다.
4. 자연 완료와 건너뛰기 모두 같은 최종 HP와 `지도로 돌아간다`를 보여준다.
5. 다시 보기 동안 지도 이동이 다시 잠긴다.
6. 1024×640에서도 동일한 고정 캔버스 배치가 균일 축소된다.
7. 두 viewport에서 겹침, clipping, 가로·세로 스크롤, 콘솔 오류가 없다.

전체 검증은 `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `git diff --check`를 포함한다. 게임 수치를 바꾸지 않으므로 `pnpm backtest`는 실행하지 않는다.

## 10. 완료 조건

- 조언 카드 3장이 승인된 A1 외형과 낮은 공통 높이를 가진다.
- 비전투 진행 장면의 좌측에 현재 파티원 3명이 원본 방향으로 보인다.
- 전투 장면과 비전투 파티가 중복되지 않는다.
- 일반 몬스터 전투 재생 중에는 우측 하단에서 건너뛰기만 가능하다.
- 전투 complete 이후에만 같은 자리에서 지도로 돌아갈 수 있다.
- 다시 보기 중 지도 이동이 다시 잠긴다.
- 비전투 사건, 보스전, 전투 계산과 캠페인 규칙에는 회귀가 없다.

## 11. 변경하지 않는 것

- 전투 규칙, 피해, HP, 신뢰, RNG와 action record
- 사건 선택·판정과 캠페인 phase 전이
- GameShell 60:40, 상단 상태 바, 진행 화면 40:60 구조
- 우측 파티 카드의 정보 구조와 뒤집기 기록
- 캐릭터·몬스터·배경 이미지 파일
- 보스전의 `정산으로` 흐름
- 비전투 사건 결과를 확인한 뒤 지도로 복귀하는 기존 흐름
