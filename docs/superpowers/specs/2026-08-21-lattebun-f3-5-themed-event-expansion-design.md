# F3-5 테마 전용 사건 90종 확장 설계

- 작성일: 2026-08-21
- 대상: `LatteBun/Dungeon_Schemer`
- 작업: F3-5 테마 전용 사건 확장
- 상태: 브레인스토밍 승인 완료, 구현 전 Spec

## 1. 목적

F3-5는 거미굴·사막·묘지 테마의 전용 사건을 각각 20개에서 30개로 확장한다. 기존 60개를 유지하면서 테마별 10개씩, 총 30개의 신규 사건을 추가한다.

테마 전용 사건의 역할은 다음과 같이 정의한다.

> 공용 사건은 장면의 관찰 사실을 읽어 풀고, 테마 전용 사건은 던전의 생태 규칙을 적용하거나 조합해 푼다.

F3-5의 목표는 단순 수량 확장이 아니라 다음 세 가지다.

1. 생태 규칙 6개가 반복적으로 실제 플레이 판단에 쓰이게 한다.
2. 단일 규칙 적용 문제와 복합 규칙 추론 문제를 구분해 난이도 층을 만든다.
3. 기존 F3-2/F3-3의 validator·clue·boss 계약을 변경하지 않는다.

## 2. 최종 수량 구조

각 테마는 아래 구조를 갖는다.

| 구성 | 기존 | 신규 | 최종 |
| --- | ---: | ---: | ---: |
| 일반 `monster` | 12 | +6 | 18 |
| 일반 `special` | 0 | +4 | 4 |
| 보스 정보 `special` | 8 | +0 | 8 |
| 합계 | 20 | +10 | 30 |

세 테마 전체는 60개에서 90개가 된다.

기존 20개는 원칙적으로 수정하지 않는다. 신규 사건이 기존 사건과 명백히 중복되는 경우에만 문구를 소폭 보정할 수 있으며, 기존 event ID·clue 연계·보스 정보 구조는 보존한다.

## 3. 신규 사건 작성 원칙

### 3.1 신규 monster 6개

테마의 생태 규칙 6개에 신규 monster 사건을 정확히 하나씩 대응시킨다.

- 핵심 판단 근거는 생태 규칙 1개다.
- help는 해당 규칙과 일치한다.
- harm은 겉보기에는 합리적이지만 해당 규칙과 충돌한다.
- neutral은 회피·지연·관망 등 제한적인 선택이다.
- 기존 사건과 같은 규칙을 사용해도 장면과 행동 방식은 다르게 만든다.
- 난이도는 `직관 2 / 추론 3 / 함정 1`이다.

### 3.2 신규 일반 special 4개

일반 special은 생태 규칙 둘 이상이 함께 작용하는 복합 상황이다.

- `직관 1 / 추론 2 / 함정 1`.
- 장면에 복수의 생태 단서가 함께 존재한다.
- 플레이어는 어느 규칙을 현재 상황에 적용해야 하는지 판단해야 한다.
- 함정형은 한 규칙만 기억하면 틀리고, 조건부 예외나 두 번째 규칙까지 봐야 풀린다.
- 런타임에 복합 source 타입을 추가하지 않는다. 각 advice의 기존 `source` 계약은 유지한다.

### 3.3 난이도 메타데이터

`직관 / 추론 / 함정` 표시는 Spec과 콘텐츠 리뷰에서만 사용한다. 런타임 field나 enum을 추가하지 않는다.

### 3.4 clue·boss 구조

기존 `revealsClue`, `upgrades`, `requiresClue`, `targetBossId`, `bossDamageModifier` 계약은 변경하지 않는다.

F3-5 신규 30개는 기본적으로 독립 사건으로 작성한다. 기존 clue를 재사용하는 것이 장면상 매우 자연스러운 경우를 제외하면 강한 연계를 새로 늘리지 않는다. 사건 풀이 커졌는데 `requiresClue` 때문에 실제 등장 가능한 풀이 줄어드는 것을 피하기 위함이다.

## 4. 테마별 복합 special 조합

### 거미굴

1. 직관: 시체 냄새 + 어둠
2. 추론: 불 + 그림자
3. 추론: 진동 + 시체 냄새
4. 함정: 일반 거미의 불 회피 + 새끼거미의 불빛 선호

### 사막

1. 직관: 물기 + 완전 건조
2. 추론: 열기 + 물
3. 추론: 미이라 무발자국 + 바람의 흔적 삭제
4. 함정: 코브라의 열기 회피 + 모래도마뱀의 열기 선호

### 묘지

1. 직관: 부장품 수호 + 도굴 반응
2. 추론: 소리 + 빛
3. 추론: 해골 마법사의 빛 추적 + 스켈레톤 궁수의 빛 회피
4. 함정: 좀비의 소리 둔감 + 구울의 소리 민감

## 5. 신규 사건 콘텐츠 명세

표기법:

- `M` = 신규 monster
- `S` = 신규 일반 special
- `[직관] [추론] [함정]`은 리뷰용 메타데이터다.
- H = help, X = harm, N = neutral.
- `규칙`은 구현 시 H/X source가 참조할 기본 ecology rule을 뜻한다.

# 5.1 거미굴 신규 10개

## SP-M01 [직관] 불길 앞의 동굴거미

- 제안 ID: `spider-fire-smoke-gap`
- 종류: `monster`
- 규칙: `spider-fire`
- 상황: 좁은 통로 앞을 동굴거미 한 마리가 막고 있다. 옆에는 아직 불씨가 남은 횃불통이 있고, 거미는 불씨가 튈 때마다 몸을 뒤로 뺀다.
- H: `불씨를 살려 통로 옆으로 밀어붙이라고 하세요` → 불길을 피해 거미가 벽 쪽으로 물러나며 길이 열린다.
- X: `불씨를 끄고 어둠 속에서 천천히 다가가라고 하세요` → 불빛이 사라지자 거미가 통로 중앙으로 돌아와 파티를 막는다.
- N: `다른 길을 찾아보라고 하세요` → 충돌은 피하지만 시간이 더 든다.

## SP-M02 [함정] 고치방의 등불

- 제안 ID: `spider-brood-lantern-cluster`
- 종류: `monster`
- 규칙: `spider-brood-light`
- 상황: 천장 고치 여러 개가 갓 찢어진 방이다. 바닥에는 손바닥만 한 새끼거미들이 흩어져 있고, 파티의 등불이 흔들릴 때마다 가까운 개체들이 빛 쪽으로 방향을 튼다.
- H: `등불을 가리고 벽을 따라 조용히 빠져나가라고 하세요` → 빛이 줄자 새끼거미 떼가 흩어져 길이 열린다.
- X: `횃불을 더 밝게 들어 거미들을 겁주라고 하세요` → 새끼거미들이 불빛 쪽으로 한꺼번에 몰려든다.
- N: `고치방 밖에서 잠시 기다리라고 하세요` → 당장은 안전하지만 길이 막힌 채 시간이 흐른다.

## SP-M03 [추론] 자갈 깔린 바닥

- 제안 ID: `spider-vibration-loose-gravel`
- 종류: `monster`
- 규칙: `spider-vibration`
- 상황: 천장에 동굴거미 두 마리가 붙어 있다. 아래 바닥은 작은 자갈과 깨진 금속 조각으로 덮여 있어 평소처럼 걸으면 계속 소리가 나고 바닥이 울린다.
- H: `천천히 발을 디딜 자리를 골라 진동을 줄이라고 하세요` → 천장 거미들이 움직이지 않는 사이 통로를 빠져나간다.
- X: `한 번에 뛰어 지나가라고 하세요` → 자갈이 크게 튀며 진동이 퍼지고 거미들이 동시에 내려온다.
- N: `자갈을 치우며 길을 만들라고 하세요` → 안전해지지만 준비에 시간이 오래 걸린다.

## SP-M04 [추론] 움직이지 않는 철갑거미

- 제안 ID: `spider-armor-vibration-hammer`
- 종류: `monster`
- 규칙: `spider-armor-vibration`
- 상황: 철갑거미 한 마리가 통로 벽에 붙어 있다. 파티가 조금 전 돌을 떨어뜨려 바닥이 크게 울렸는데도 거미는 고개조차 돌리지 않았다.
- H: `진동에 반응하지 않으니 시야 밖으로 붙어 지나가라고 하세요` → 거미가 눈치채지 못한 사이 파티가 통과한다.
- X: `바닥을 두드려 반대편으로 유인하라고 하세요` → 아무 반응도 없어 파티가 가까이 접근한 뒤에야 거미와 맞닥뜨린다.
- N: `멀리서 계속 관찰하라고 하세요` → 위험은 늘지 않지만 진전도 없다.

## SP-M05 [직관] 썩은 냄새가 밴 천

- 제안 ID: `spider-carrion-bloody-cloth`
- 종류: `monster`
- 규칙: `spider-carrion`
- 상황: 전투 뒤 피 묻은 천 조각을 짐에 묶어 두었다. 앞쪽 통로에서 시체거미 한 마리가 나타나더니 파티보다 천 조각 쪽으로 먼저 방향을 튼다.
- H: `피 묻은 천을 멀리 던지고 반대쪽으로 지나가라고 하세요` → 시체거미가 냄새를 따라가며 길이 비어진다.
- X: `천을 짐 안쪽에 숨기고 그대로 지나가라고 하세요` → 냄새를 맡은 거미가 짐 쪽으로 달라붙는다.
- N: `천을 버리고 뒤로 물러나라고 하세요` → 위험은 줄지만 이동은 지연된다.

## SP-M06 [추론] 사라지는 다리

- 종류: `monster`
- 규칙: `spider-shadow`
- 상황: 횃불 빛이 닿는 벽에는 아무것도 없지만, 불빛 경계 바로 밖 어둠 속에서 가느다란 다리 모양이 나타났다 사라진다.
- H: `빛의 범위를 넓혀 어둠을 줄이라고 하세요` → 그림자거미의 은신 공간이 줄어 모습을 드러낸 채 뒤로 물러난다.
- X: `횃불을 끄고 눈을 어둠에 익히자고 하세요` → 방 전체가 어두워지자 여러 방향에서 움직임이 시작된다.
- N: `현재 불빛 안에서 움직이지 말라고 하세요` → 당장은 안전하지만 앞으로 나아가지 못한다.

## SP-S01 [직관] 검은 고치 저장소

- 제안 ID: `spider-special-carrion-dark-store`
- 종류: `special`
- 조합: `spider-carrion` + `spider-shadow`
- 상황: 빛이 거의 들지 않는 방에 오래된 시체 고치가 여러 개 쌓여 있다. 썩은 냄새가 강하고, 벽 끝 어둠에서는 가끔 다리 윤곽이 움직인다.
- H: `불을 밝히고 고치와 거리를 둔 채 가장자리로 지나가라고 하세요` → 어둠을 줄이고 시체 냄새 중심부를 피하면서 두 종류의 위험을 모두 낮춘다.
- X: `고치 사이 어두운 틈으로 몸을 숨겨 지나가라고 하세요` → 시체 냄새와 어둠이 겹친 곳으로 들어가 거미들의 움직임이 한꺼번에 시작된다.
- N: `방을 포기하고 돌아가라고 하세요` → 위험은 피하지만 우회한다.

## SP-S02 [추론] 횃불 하나뿐인 갈림방

- 제안 ID: `spider-special-fire-shadow-lane`
- 종류: `special`
- 조합: `spider-fire` + `spider-shadow`
- 상황: 한쪽 통로에는 작은 거미 여러 마리가 불빛을 피해 물러나 있고, 다른 쪽은 완전히 어두워 가끔 검은 다리만 보인다. 파티에게 남은 횃불은 하나뿐이다.
- H: `횃불을 어두운 통로 쪽에 두고 밝은 가장자리로 움직이라고 하세요` → 그림자거미의 은신을 막으면서 일반 거미도 불 가까이 오지 못한다.
- X: `횃불을 끄고 두 무리를 모두 자극하지 말자고 하세요` → 일반 거미는 조용해지지만 어둠 속 그림자거미가 활동하기 시작한다.
- N: `횃불을 들고 입구에서 상황만 더 보자고 하세요` → 안전하지만 이동이 지연된다.

## SP-S03 [추론] 끌린 시체와 울리는 판자

- 제안 ID: `spider-special-vibration-carrion-floor`
- 종류: `special`
- 조합: `spider-vibration` + `spider-carrion`
- 상황: 통로 중앙에 오래된 시체가 놓여 있고 그 주변 바닥에는 비어 있는 나무판이 깔려 있다. 판자를 밟으면 아래가 울리고, 안쪽에서는 시체거미가 시체 냄새 쪽으로 움직이고 있다.
- H: `시체를 건드리지 말고 판자 가장자리를 골라 진동을 줄이며 지나가라고 하세요` → 시체거미의 관심과 동굴거미의 진동 감지를 모두 피한다.
- X: `시체를 판자 위로 끌어 반대편에 던지라고 하세요` → 썩은 냄새와 큰 진동이 동시에 퍼져 여러 거미가 반응한다.
- N: `판자를 치우고 길을 만들라고 하세요` → 안전하지만 시간이 많이 든다.

## SP-S04 [함정] 새끼거미가 깨어난 둥지

- 제안 ID: `spider-special-fire-brood-trap`
- 종류: `special`
- 조합: `spider-fire` + `spider-brood-light`
- 상황: 성체 거미 두 마리는 횃불을 보자 뒤로 물러나지만, 찢어진 고치 아래의 새끼거미 떼는 반대로 횃불 빛을 향해 조금씩 모여든다.
- H: `횃불을 둥지 반대편에 내려놓고 파티는 빛에서 멀어지라고 하세요` → 성체는 불을 피하고 새끼들은 파티 대신 떨어진 불빛 쪽으로 몰린다.
- X: `횃불을 높이 들고 정면으로 밀어붙이라고 하세요` → 성체는 물러나지만 새끼거미 떼가 파티 쪽 빛으로 몰려든다.
- N: `불을 유지한 채 뒤로 물러나자고 하세요` → 당장은 안전하지만 통과하지 못한다.

- H: `횃불을 빈 측면 통로에 두고 두 적의 위치를 갈라놓으라고 하세요` → 마법사는 빛을 따라가고 궁수는 반대 그림자로 물러나 중앙 통로가 열린다.
- X: `빛을 꺼 둘 다 움직이지 못하게 하자고 하세요` → 마법사의 유인은 사라지고 궁수는 어둠 속에서 자유롭게 위치를 잡는다.
- N: `횃불을 그대로 유지하며 엄폐 뒤에서 기다리자고 하세요` → 위치는 유지되지만 진전이 없다.

## GR-S04 [함정] 조용한 시체실

- 제안 ID: `graveyard-special-zombie-ghoul-sound-trap`
- 종류: `special`
- 조합: `graveyard-silence` + `graveyard-ghoul-sound`
- 상황: 시체실 앞쪽에는 썩은 좀비가 멍하니 서 있고, 뒤쪽 시체더미 사이에서는 구울의 손톱이 돌을 긁는 작은 소리가 난다. 좀비는 파티의 발소리에도 반응하지 않는다.
- H: `좀비 반응만 보고 안심하지 말고 최대한 조용히 지나가라고 하세요` → 좀비와 구울의 서로 다른 청각 반응을 모두 고려해 통과한다.
- X: `좀비가 소리를 못 듣는 걸 확인했으니 빠르게 뛰자고 하세요` → 좀비는 그대로지만 뒤쪽 구울들이 작은 소리에도 반응해 달려온다.
- N: `시체실을 우회하자고 하세요` → 위험은 피하지만 길이 길어진다.

## 6. 구현 시 데이터 계약

기존 F3-2/F3-3 방식과 동일하게 구현한다.

- 테마 사건은 각 테마 파일 안에 추가한다.
- 새 runtime enum/field를 만들지 않는다.
- 기존 `SituationEvent` / `AdviceOption` / `AdviceUpgrade` 구조를 그대로 사용한다.
- monster와 일반 special 모두 정확히 help/harm/neutral 각 1개를 가진다.
- help/harm advice는 해당 테마의 ecology source와 consistent/contradictory 관계를 만족해야 한다.
- neutral은 기존 계약대로 unrelated를 유지한다.
- 신규 일반 special은 `targetBossId`와 `bossDamageModifier`를 사용하지 않는다.
- 보스 정보 기존 8개는 그대로 유지한다.

## 7. 테스트 및 검증

테마별 테스트를 20개 기준에서 30개 기준으로 갱신한다.

반드시 검증할 것:

- 각 테마 사건 정확히 30개
- 각 테마 `monster` 정확히 18개
- 각 테마 일반 special 4개
- 각 테마 보스 정보 special 8개
- 보스 4종마다 기존 정보 사건 정확히 2개 유지
- 각 ecology rule이 help 2개 이상, harm 2개 이상 공급
- 기존 테마별 neutral 공급 계약 유지
- event ID 중복 없음
- advice ID 중복 없음
- title/description의 완전 중복 없음
- 기존 `validateSituationEvents(events, theme)` 통과
- 기존 약한 연계·강한 연계 테스트 유지

리뷰 체크리스트:

- 신규 monster 6개가 규칙 6개에 정확히 1개씩 대응하는가
- monster 난이도가 직관 2 / 추론 3 / 함정 1인가
- 일반 special 난이도가 직관 1 / 추론 2 / 함정 1인가
- special이 실제로 두 규칙을 함께 읽게 만드는가
- 함정형이 랜덤 함정이 아니라 조건부 규칙/두 번째 단서를 놓쳤을 때만 틀리게 되어 있는가
- 공용 사건처럼 장면만 읽으면 풀리는 문제가 아니라 생태 규칙을 활용해야 하는가

최종 검증 명령:

- `pnpm test`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm build`
