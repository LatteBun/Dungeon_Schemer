# F2-2 사막·묘지 콘텐츠 메모

작성 도구: Claude Code (Opus 5)

## 이 문서의 지위

**이 문서는 승인된 spec이 아니다.** `F2-2` 구현에 들어가기 전 확정된 몬스터·보스 이름을 잃어버리지 않으려고 저장해 두는 메모다. `F2-1`처럼 spec으로 옮기려면 생태 규칙 6개(테마마다 조건부 1개 이상)를 마저 정하고, brainstorming 절차(질문 → 설계 제시 → 사용자 승인)를 거쳐야 한다.

몬스터·보스 이름과 위험도 구간은 사용자가 확정했다. 아래 두 가지는 정리 과정에서 걸러낸 것이다.

- 사막 보스는 5개 중 **파라오 아멘호텝**을 빼고 4종으로 맞췄다(테마당 보스 4종 계약)
- 묘지 몬스터는 6종 중 **미이라**를 빼고 5종으로 맞췄다(테마당 몬스터 5종 계약). 사막 잡몹에 이미 미이라가 있어 테마별 상징이 덜 겹치게 뺐다

## 사막

### 몬스터 5종 (확정)

- 사막전갈
- 모래도마뱀
- 사막코브라
- 모래정령
- 미이라

### 보스 4종 (확정, `minRiskLevel` 오름차순)

| `minRiskLevel` | 이름 |
| --- | --- |
| 1 | 거대 전갈 자카르 |
| 2 | 샌드웜 카르둠 |
| 3 | 모래거신 오벨론 |
| 4 (★4~5 담당) | 스핑크스 네프리스 |

### 생태 규칙 — 아직 없음

`DUNGEON_THEMES_AND_ECOLOGY.md`가 사막의 성격을 "더위와 갈증. 열기·물·발자국이 얽힌다"로 잡아 뒀다. 위 몬스터 5종에 이 축을 연결해 6개(조건부 1개 이상)를 지어야 한다.

## 묘지

### 몬스터 5종 (확정)

- 썩은 좀비
- 구울
- 스켈레톤 병사
- 스켈레톤 궁수
- 해골 마법사

### 보스 4종 (확정, `minRiskLevel` 오름차순)

| `minRiskLevel` | 이름 |
| --- | --- |
| 1 | 스켈레톤 장군 바르칸 |
| 2 | 리치 모르비안 |
| 3 | 사신 아즈라엘 |
| 4 (★4~5 담당) | 데스나이트 발드라크 |

### 생태 규칙 — 아직 없음

`DUNGEON_THEMES_AND_ECOLOGY.md`가 묘지의 성격을 "정숙과 부정. 빛·소리·매장물이 얽힌다"로 잡아 뒀다.
