## 1. 목적

실제 캠페인의 첫 화면인 `/campaign` 인트로에서 본문 글자가 전반적으로 작아 보이는 문제를 개선한다. 플레이어가 첫 공고로 이동하기 전에 길잡이의 역할, 개입 수단, 캠페인 목표를 더 편하게 읽을 수 있도록 본문 타이포그래피를 약 15% 확대한다.

이번 변경은 문구, 정보 구조, 화면 전이, 공용 상단 상태 바를 바꾸지 않는다.

## 2. 현재 구현

- `components/game/CampaignScreen.tsx`는 캠페인 단계가 `intro`일 때 `IntroScreen`을 렌더링한다.
- `components/game/IntroScreen.tsx`는 눈썹 문구, 메인 제목, 두 줄 소개문, 역할·수단·목표 카드 세 장, 게시판 진입 CTA를 렌더링한다.
- `app/u2-intro.css`가 인트로 본문의 글자 크기를 개별 `clamp()` 값으로 정의한다.
- 공용 상단 상태 바 글자 크기는 `app/globals.css`의 `--status-*` 토큰이 소유하며 다른 캠페인 화면도 함께 사용한다.
- 현재 작업 브랜치와 `main`의 `IntroScreen` 및 `u2-intro.css` 구현은 동일하다.

## 3. 사용자 승인으로 확정한 범위

### 3.1 확대 대상

다음 인트로 전용 텍스트의 `clamp()` 최솟값, 유동값, 최댓값을 기존 대비 약 15% 확대한다.

- `길잡이의 첫 기록` 눈썹 문구
- `던전은 검보다 먼저 말을 건넨다` 메인 제목
- 메인 제목 아래 두 줄 소개문
- 역할·수단·목표 카드 제목
- 역할·수단·목표 카드 본문
- `길드 게시판으로` CTA 문구

각 선택자의 변경값은 다음과 같이 고정한다.

| 대상 | 현재 값 | 변경 값 |
| --- | --- | --- |
| 눈썹 문구 | `clamp(0.75rem, 1cqw, 0.92rem)` | `clamp(0.86rem, 1.15cqw, 1.06rem)` |
| 메인 제목 | `clamp(1.9rem, 3cqw, 3.1rem)` | `clamp(2.18rem, 3.45cqw, 3.55rem)` |
| 소개문 | `clamp(0.78rem, 1.12cqw, 0.96rem)` | `clamp(0.9rem, 1.29cqw, 1.1rem)` |
| 카드 제목 | `clamp(1.05rem, 1.45cqw, 1.35rem)` | `clamp(1.2rem, 1.67cqw, 1.55rem)` |
| 카드 본문 | `clamp(0.7rem, 0.95cqw, 0.84rem)` | `clamp(0.81rem, 1.09cqw, 0.97rem)` |
| CTA 문구 | `clamp(1.18rem, 2cqw, 1.65rem)` | `clamp(1.36rem, 2.3cqw, 1.9rem)` |

모든 값을 하나의 배율 변수로 묶지 않고 현재 선택자별 `clamp()` 계약을 유지한다.

### 3.2 제외 대상

- 공용 상단 상태 바
- 아이콘과 배경 이미지
- 문구와 DOM 구조
- 카드와 CTA의 기본 크기
- 다른 캠페인 화면의 타이포그래피

공용 상태 바를 인트로에서만 덮어쓰지 않는다. [화면 규격](../../experience/SCREEN_LAYOUT.md)이 공용 요소를 한 곳에서 정의하도록 요구하고, 사용자가 본문만 확대하도록 범위를 확정했기 때문이다.

### 3.3 레이아웃 안전 조정

1920×1080 고정 캔버스에서 텍스트 잘림, 겹침, 의도하지 않은 줄바꿈이 생기지 않으면 간격과 컨테이너 크기는 그대로 둔다. 문제가 확인될 때만 인트로 전용 여백이나 행간을 최소한으로 조정하며 카드·CTA 자체를 재설계하지 않는다.

메인 제목과 소개문의 현재 한 줄·두 줄 의미 단위는 유지한다. 카드 본문은 `word-break: keep-all`과 균형 줄바꿈을 계속 사용한다.

## 4. 구현 경계

### `app/u2-intro.css`

- 인트로 전용 여섯 타이포그래피 선택자의 크기만 조정한다.
- `--cta-text-size`가 바뀌면 기존 광학 중심 보정 계산이 새 글자 크기를 그대로 소비하게 한다.
- 공용 `app/globals.css` 토큰은 수정하지 않는다.

### `components/game/IntroScreen.test.ts`

- 인트로 본문의 확대된 CSS 계약을 검사한다.
- 상단 상태 바용 공용 토큰이나 선택자를 인트로 CSS가 덮어쓰지 않는다는 경계를 확인한다.
- 기존 문구와 마크업 계약은 유지한다.

컴포넌트의 문구와 구조가 바뀌지 않으므로 `IntroScreen.tsx`는 원칙적으로 수정하지 않는다.

## 5. 검증

### 자동 검증

- 실패하는 CSS 계약 테스트를 먼저 추가한다.
- `IntroScreen.test.ts`를 통과시킨다.
- 관련 캠페인 렌더 테스트, 타입 검사, 린트를 실행한다.

### 브라우저 검증

실제 통합 경로인 `/campaign`의 첫 화면을 1920×1080 고정 캔버스에서 확인한다.

1. 눈썹 문구, 제목, 소개문, 카드 제목·본문, CTA가 이전보다 분명히 크게 보인다.
2. 상단 상태 바 크기는 바뀌지 않는다.
3. 제목과 소개문의 지정된 줄 구성이 유지된다.
4. 카드 본문과 CTA 문구에 잘림이나 겹침이 없다.
5. 가로·세로 스크롤, Next 오류 오버레이, 콘솔 오류가 없다.

사용자 확인용 화면은 프리뷰 전용 `/u2-test`가 아니라 `/campaign`에서 제공한다.

## 6. 문서 영향

이번 변경은 게임 규칙, 온보딩에서 전달하는 정보, 화면 구조를 바꾸지 않는다. 따라서 `GAME_PRINCIPLES.md`, `SCREEN_LAYOUT.md`, `ONBOARDING_AND_INTERFACE.md`, `UI_IMPLEMENTATION_GUIDE.md` 본문은 수정하지 않는다.

`docs/README.md`에는 승인된 spec과 plan을 찾을 수 있도록 색인만 추가한다.

## 7. 범위 밖

- 상단 상태 바 또는 다른 화면의 글자 크기 변경
- 인트로 문구 개정
- 카드, CTA, 배경, 아이콘의 시각 재설계
- 반응형 재배치나 모바일 레이아웃 추가
- 캠페인 상태와 게시판 전이 변경

## 8. 완료 기준

- 인트로 본문의 모든 지정 텍스트가 약 15% 커진다.
- 공용 상단 상태 바와 다른 화면은 영향을 받지 않는다.
- 1920×1080 `/campaign` 화면에서 잘림, 겹침, 의도하지 않은 줄바꿈이 없다.
- 관련 자동 테스트, 타입 검사, 린트가 통과한다.
- 사용자가 실제 `/campaign` 화면을 보고 결과를 확인할 수 있다.
