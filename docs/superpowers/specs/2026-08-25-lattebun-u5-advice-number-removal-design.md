## 1. 목적

던전 진행 화면에서 조언 카드 세 장을 고를 때 각 카드 위에 표시되는 숫자
`1`·`2`·`3`을 제거한다. 플레이어가 카드의 문구와 근거에 집중하도록 하며,
숫자가 카드의 의미나 우선순위를 암시하는 시각 요소로 읽히지 않게 한다.

이번 변경은 카드의 순서, 조언 섞기, 선택 결과, 키보드 조작과 캠페인 상태를
바꾸지 않는다.

## 2. 현재 구현

- `components/game/U5ProgressScreen.tsx`의 `AdviceOption`은 내부 `slot` 값을
  선택 callback에 전달한다.
- 같은 컴포넌트가 `slot + 1`을 `.u5-advice__slot` 요소로 렌더링해 카드마다
  `1`·`2`·`3`을 보여준다.
- `app/u5-progress.css`는 숫자 요소를 금색 테두리 배지로 표현하며, 비활성 카드의
  배지 상태도 별도로 정의한다.
- 슬롯 값은 화면 모델과 실제 `ChoiceId`를 연결하는 내부 계약이므로 선택 동작에
  계속 필요하지만, 플레이어에게 표시할 필요는 없다.

## 3. 승인된 변경

- 세 조언 카드에서 숫자 배지를 모두 제거한다.
- 카드 문구, 근거, 골드 비용과 선택 불가 사유는 그대로 표시한다.
- 카드 세 장의 순서와 동일한 외형, 리벳, 테두리, hover, 비활성 상태,
  `focus-visible` 표현은 유지한다.
- 내부 `slot` 값과 `onSelect(slot)` 호출은 유지해 기존 선택 연결을 바꾸지 않는다.
- 숫자가 사라진 자리는 별도 아이콘이나 장식으로 대체하지 않는다.

## 4. 구현 경계

### `components/game/U5ProgressScreen.tsx`

- `.u5-advice__slot` 마크업과 숫자 표기를 제거한다.
- 슬롯 번호를 화면 차이로 설명하던 주석을 현재 계약에 맞게 고친다.
- `slot` prop, React key와 선택 callback 전달은 유지한다.

### `app/u5-progress.css`

- `.u5-advice__slot`과 비활성 카드용 슬롯 배지 규칙을 제거한다.
- 카드 콘텐츠의 중앙 정렬과 간격은 기존 규칙을 유지한다. 숫자 제거로 시각적
  균형이 깨지는 경우에만 카드 콘텐츠 전용 행 정의를 최소한으로 조정한다.

### `components/game/U5ProgressScreen.test.tsx`

- 조언 카드 세 장이 계속 같은 구조로 렌더링되는지 확인한다.
- 카드 마크업에 숫자 슬롯 요소가 없음을 회귀 계약으로 추가한다.
- 카드 선택 callback이 기존 내부 슬롯 값을 그대로 받는 테스트는 유지하거나
  필요하면 보강한다.

## 5. 공식 문서 영향

숫자 배지는 게임 규칙이나 공식 화면 구조가 아니라 구현 세부 표현이다.
`SCREEN_LAYOUT.md`가 요구하는 같은 디자인의 조언 세 장과 선택 전 정보 은폐는
숫자를 제거해도 유지된다. 따라서 `GAME_PRINCIPLES.md`, 시스템 문서와 경험 문서
본문은 수정하지 않는다.

`docs/README.md`에는 승인된 spec과 이후 plan을 찾을 수 있도록 색인만 추가한다.

## 6. 검증

### 자동 검증

1. 숫자 슬롯 요소가 없어야 한다는 실패 테스트를 먼저 추가한다.
2. `U5ProgressScreen.test.tsx`와 조언 표시 관련 테스트를 통과시킨다.
3. 전체 단위 테스트, 타입 검사와 lint를 실행한다.

### 화면 검증

실제 던전 진행 화면에서 조언을 선택할 수 있는 순간을 공식 1920×1080 고정
캔버스로 확인한다.

1. 세 카드 어디에도 `1`·`2`·`3` 숫자 배지가 보이지 않는다.
2. 카드 문구, 근거, 비용과 선택 불가 사유가 잘리거나 겹치지 않는다.
3. 세 카드의 크기와 외형이 서로 같고 콘텐츠가 자연스럽게 중앙 정렬된다.
4. 각 카드를 클릭하면 이전과 같은 조언이 선택된다.
5. 키보드 포커스, 비활성 상태와 다음 단계 흐름이 유지된다.

## 7. 범위 밖

- 조언 문구, 근거 또는 비용 정보 변경
- 카드 순서나 조언 셔플 규칙 변경
- 조언 카드의 크기, 색상, 테두리와 장식 재설계
- 숫자를 아이콘, 문자 또는 다른 순서 표식으로 교체
- 파티 반응, 사건 결과와 진행 기록 변경

## 8. 완료 기준

- 던전 진행 화면의 세 조언 카드에서 숫자 `1`·`2`·`3` 표기가 사라진다.
- 내부 슬롯 기반 선택 동작과 조언 결과는 그대로 유지된다.
- 카드의 내용, 동일한 디자인, 접근 가능한 포커스와 비활성 상태가 유지된다.
- 관련 자동 테스트와 실제 화면 검증이 통과한다.
