## 1. 목적

실제 캠페인의 게시판 화면에서 수배지 다섯 장이 판을 거의 가득 채우며 규칙적인 그리드로 보이는 문제를 개선한다. 수배지와 내부 콘텐츠를 함께 줄이고 손으로 하나씩 붙인 듯한 위치·회전 차이를 줘 길드 게시판의 물성을 강화한다.

동시에 임시 번호형 던전 이름 15개를 정식 보스 전설형 이름으로 바꾸고, 우측 던전 정보·계약 조건 뒤의 장면 이미지를 제거해 정보 가독성을 높인다.

이번 변경은 게시판이 보여 주는 정보, 공고 선택 순서, 진입 조건, 보상, 파티 편성, 계약 동작을 바꾸지 않는다.

## 2. 현재 구현

- `components/game/U3BoardScreen.tsx`는 최대 다섯 개 공고를 실제 `<button>` 수배지로 렌더링한다.
- `app/u3-board.css`는 수배지 영역을 3열×2행 균등 그리드로 만들고 카드가 각 셀을 채우게 한다.
- 카드별 이동량과 회전각은 약 1도 미만이라 3장 위·2장 아래의 정렬감이 더 강하다.
- 수배지 제목, 위험도, 테마 장면, 보상, 상태 문구와 핀은 여러 U3 CSS 파일에 나뉘어 크기가 정의되어 있다.
- `lib/content/campaign-dungeons.ts`의 표시 이름은 `거미굴 1`부터 `묘지 5`까지 번호형 임시 이름이다.
- 우측 `u3-contract-card`는 테마 장면 스프라이트를 배경으로 사용하고 별도 scrim을 덮는다.

## 3. 사용자 승인으로 확정한 방향

### 3.1 수배지 크기와 배치

- 기준 게시판에서 각 수배지의 가로·세로 점유 크기를 현재 그리드 셀 대비 약 80%로 줄인다.
- 다섯 수배지의 실제 가로·세로 크기는 동일하게 유지한다. 크기까지 제각각으로 만들지 않는다.
- 단순히 `transform: scale()`로 그림만 줄이지 않는다. 실제 레이아웃 점유 크기와 클릭 영역을 함께 줄인다.
- 카드마다 서로 다른 행·열 위치, 상하좌우 오프셋, 회전각을 부여한다.
- 회전은 대략 `-2.5deg`에서 `2.5deg` 안으로 제한한다. 현재보다 차이는 분명하게 보이되 내용이 기울어 읽기 어려워지지 않게 한다.
- 다섯 장이 서로 겹치지 않으며 게시판 테두리, 길잡이 등급 UI, 우측 패널을 침범하지 않는다.
- DOM 순서와 키보드 탭 순서는 기존 공고 순서를 그대로 보존한다. 시드나 렌더마다 위치를 무작위로 다시 뽑지 않는다.
- hover, focus, 선택, 잠금 상태는 기존 외곽선과 색 외 단서를 유지한다.

### 3.2 내부 콘텐츠 축소

카드 외곽만 줄여 내용이 빽빽해지지 않도록 다음 요소를 함께 축소한다.

- 내부 여백과 행 사이 간격
- 핀
- 던전 이름과 테마 라벨
- 위험도 별과 별 사이 간격
- 테마 장면 슬롯
- 보상 아이콘·수치
- 진입 가능·선택 중·진입 불가 상태 문구

축소 후에도 던전 이름은 생략 부호로 숨기지 않고 최대 두 줄 안에서 전부 읽을 수 있어야 한다. 보상과 상태 문구는 잘리거나 카드 밖으로 넘치지 않아야 한다.

### 3.3 반응형 경계

- 1920×1080 고정 캔버스에서는 다섯 장의 빈 공간과 불규칙성이 분명히 보여야 한다.
- 1280×720 기준에서도 카드가 겹치거나 잘리지 않아야 한다.
- 최소 지원 크기 1024×640에서는 회전과 오프셋을 줄여 가독성과 클릭 안정성을 우선한다.
- 가로·세로 스크롤을 새로 만들지 않는다.

## 4. 던전 표시 이름

사용자가 승인한 보스·전설 중심 톤을 적용한다. 새 보스 이름을 만들지 않고 [던전 테마와 생태](../../systems/DUNGEON_THEMES_AND_ECOLOGY.md)의 정식 보스 목록과 각 슬롯의 초기 위험도 구간을 맞춘다. 같은 보스가 두 슬롯을 담당하면 장소 전승을 달리해 이름을 구분한다.

## 5. 우측 계약 상세 배경

- `u3-contract-card`에 적용되는 `theme-scenes-wide.avif` 배경 이미지를 제거한다.
- 테마별 배경 위치 modifier와 장면을 가리기 위한 scrim 요소·스타일도 함께 제거한다.
- 우측 카드에는 기존 U3 상세 영역과 어울리는 어두운 단색 또는 공통 질감만 사용한다. 새로운 장면 이미지나 대체 삽화는 추가하지 않는다.
- 던전 이름, 위험도, 보상, 잠금 사유, 생존 인원별 계약 결과의 구조와 순서는 유지한다.
- 카드 내부 텍스트가 배경 장면을 전제로 사용하던 강한 그림자는 단색 바탕에서 필요한 수준으로만 남긴다.

수배지 안의 작은 테마 장면은 게시판에서 던전 테마를 구분하는 정보이므로 유지한다. 제거 대상은 우측 던전 정보·계약 조건 뒤의 큰 배경 장면뿐이다.

## 6. 구현 경계

### 콘텐츠

- `lib/content/campaign-dungeons.ts`: 15개 슬롯의 표시 이름을 확정 이름으로 교체한다.
- `lib/content/campaign-dungeons.test.ts`: ID·위험도·순서와 함께 15개 정확한 이름을 회귀 검증한다.

### 게시판 컴포넌트와 스타일

- `components/game/U3BoardScreen.tsx`: 우측 배경 전용 theme modifier, scrim 마크업, 과거 설명 주석을 제거한다.
- `app/u3-board.css`, `app/u3-card-theme.css`, `app/u3-responsive-layout.css`, `app/u3-large-screen.css`: 수배지 실제 크기·배치와 내부 요소 축소를 한 계약으로 정리하고 우측 장면 배경 규칙을 제거한다.
- 기존 CSS 파일의 역할을 존중하며 이번 변경과 무관한 U3 화면 스타일은 재구성하지 않는다.

## 7. 검증

### 자동 검증

1. 현재 번호형 이름과 균등 배치·배경 이미지 계약을 대상으로 실패하는 테스트를 먼저 추가한다.
2. 15개 던전의 ID, 새 이름, 테마, 초기 위험도, 순서를 정확히 검증한다.
3. 수배지 컨테이너가 카드의 실제 크기와 개별 배치 규칙을 소유하고, 다섯 장이 서로 다른 위치·회전을 갖는지 검증한다.
4. 우측 계약 상세에서 scrim과 테마 배경 modifier가 사라지고, 해당 카드에 장면 배경 이미지가 적용되지 않는지 검증한다.
5. 기존 공고 선택, 잠금, 계약, 캠페인 초기화 테스트와 타입 검사·린트를 실행한다.

### 브라우저 검증

실제 통합 경로 `/campaign`에서 인트로를 지나 게시판으로 진입해 1920×1080 화면을 확인한다.

1. 수배지 다섯 장이 현재보다 작고 판에 빈 공간이 생긴다.
2. 위치와 회전 차이가 즉시 보이면서도 카드가 겹치거나 잘리지 않는다.
3. 긴 새 던전 이름 15개가 수배지와 우측 상세에서 읽힌다.
4. 공고를 바꿔 선택해도 우측 정보 뒤에 테마 장면 이미지가 나타나지 않는다.
5. 선택·잠금·키보드 focus와 계약 버튼이 기존처럼 동작한다.
6. 스크롤, Next 오류 오버레이, 콘솔 오류가 없다.

사용자 확인용 화면은 프리뷰 전용 경로가 아니라 `/campaign`에서 제공한다. 사용자가 시각 결과를 승인하기 전에는 구현 브랜치를 기준 브랜치나 `main`에 병합하지 않는다.

## 8. 범위 밖

- 게시판에 표시하는 공고 수 변경
- 수배지마다 서로 다른 크기 적용
- 겹쳐 쌓이는 카드 또는 렌더마다 달라지는 무작위 배치
- 던전 ID, 위험도, 생태 패키지, 보스 배정 변경
- 수배지의 작은 테마 장면 제거 또는 신규 이미지 제작
- 우측 정보 구조, 계약 규칙, 파티 편성 변경
- 다른 캠페인 화면의 카드 크기나 배경 변경

## 9. 완료 기준

- 수배지와 모든 내부 요소가 함께 작아지고 다섯 장이 읽기 쉬운 불규칙 배치를 이룬다.
- 15개 번호형 던전 이름이 정식 보스 전설형 이름으로 교체된다.
- 우측 던전 정보·계약 조건 뒤의 테마 장면 이미지와 전용 scrim이 제거된다.
- 1024×640부터 1920×1080까지 게시판에 겹침, 잘림, 새 스크롤이 없다.
- 관련 자동 테스트, 타입 검사, 린트와 `/campaign` 브라우저 검증을 통과한다.
- 사용자가 로컬 화면을 보고 반영 여부를 결정할 수 있다.
