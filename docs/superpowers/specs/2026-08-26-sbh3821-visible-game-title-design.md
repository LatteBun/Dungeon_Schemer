# 사용자 노출 게임 제목 변경 설계

- 작성자: sbh3821
- 작성 도구: Codex
- 작성일: 2026-08-26
- 상태: 검토 요청

## 목표

플레이어가 화면·브라우저·설치된 웹 앱에서 보는 게임 제목을 기존
`Dungeon Schemer`에서 `용사님, 이쪽입니다`로 통일한다.

## 변경 범위

- 메인 메뉴의 대형 `<h1>` 제목
- 루트 페이지의 브라우저 탭 제목
- 검색·공유에 쓰이는 루트 설명
- iOS 홈 화면 웹 앱 제목
- Web App Manifest의 `name`과 `short_name`
- 업적 페이지의 브라우저 탭 제목 접미사

제목은 따옴표 없이 정확히 `용사님, 이쪽입니다`로 표시한다. 기존 표어
`그들은 당신의 말을 믿는다`와 다른 UI 문구는 유지한다.

## 변경하지 않는 범위

- Git 저장소·작업 폴더·패키지 이름
- `dungeon-schemer.*` localStorage 키
- `DUNGEON_SCHEMER_*` 에셋 폴더와 파일 경로
- TypeScript 식별자와 게임 규칙
- 과거 회의록·설계 기록·기술 문서에서 프로젝트를 가리키는 기존 이름
- manifest 설명의 게임 소개 문구

내부 식별자를 바꾸지 않아 기존 저장 데이터와 정적 에셋 경로의 호환성을 보존한다.

## 테스트

- 메인 메뉴 정적 렌더에 새 제목이 있고 기존 영문 제목이 없다.
- 루트 metadata와 Apple Web App 제목이 새 제목이다.
- 루트 metadata 설명에 기존 영문 제목이 남지 않는다.
- manifest의 긴 이름과 짧은 이름이 새 제목이다.
- 업적 페이지 metadata가 `길잡이 업적 기록 | 용사님, 이쪽입니다`이다.
- production build 뒤 메인 화면과 브라우저 문서 제목을 확인한다.

## 완료 기준

- 사용자가 접근 가능한 UI 및 앱 메타데이터에서 `Dungeon Schemer`가 더 이상
  게임 제목으로 노출되지 않는다.
- 저장 키·에셋 경로·규칙 동작에는 변경이 없다.
