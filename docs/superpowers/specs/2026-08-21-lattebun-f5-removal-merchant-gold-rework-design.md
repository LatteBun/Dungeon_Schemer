# F5 아이템 시스템 제거 및 상인 골드 개입 재설계

- 작성일: 2026-08-21
- 대상: `LatteBun/Dungeon_Schemer`
- 작업: F5 아이템 콘텐츠 제거 + 공용 `merchant` 사건 30종 재설계
- 상태: 브레인스토밍 승인 완료, 구현 전 Spec

## 1. 목적

기존 작업표의 `F5 아이템 콘텐츠`는 치료제·독·식량·정보 두루마리·유인용 미끼 같은 별도 아이템 풀을 전제로 했다. 이 구조를 실제 플레이에 연결하려면 소지·보관·수량·사용 시점·조건부 선택지·소모·보스 사용·원정 간 지속 여부까지 추가로 결정해야 한다.

이 복잡성은 현재 프로토타입의 핵심인 다음 흐름을 흐린다.

> 던전의 상황과 생태를 읽는다 → 도움·방해·중립 조언 중 하나를 고른다 → 신뢰와 생존 결과가 바뀐다.

따라서 F5를 독립 시스템으로 구현하지 않는다. 대신 상인 사건을 다음의 단순한 자원 개입으로 재정의한다.

> 플레이어는 자신의 골드를 써서 용사 파티를 돕거나 방해한다. 아무것도 사지 않으면 골드를 아낀다.

이 설계의 목표는 네 가지다.

1. 인벤토리와 장기 아이템 상태를 제거한다.
2. 현재 골드를 원정 중 실제로 고민하게 되는 자원으로 만든다.
3. 공용 `merchant` 사건 30개를 동일한 상인 계약 아래 다시 정리한다.
4. 기존 정보·생태 추론·지도 생성 규칙을 상인 시스템이 침범하지 않게 한다.

## 2. 범위 결정

### 2.1 제거

다음은 구현하지 않는다.

- 독립 `F5 아이템 콘텐츠` 작업
- `ItemDef` 같은 영구 아이템 정의 계약
- 인벤토리
- 아이템 수량
- 아이템 소유권
- 구매한 물건의 보관
- 원정 간 아이템 유지
- 캐릭터별 장비 슬롯
- 아이템 중첩
- 구매 후 임의 시점 사용
- 아이템 조건에 따라 사건 선택지 자체를 생성하는 구조
- 정보 두루마리/정보상 계열
- 가짜 지도 저장
- 아이템을 보스전까지 들고 가서 임의로 사용하는 구조

### 2.2 유지

다음은 유지한다.

- 현재 골드
- 누적 획득 골드
- 상인 사건
- 사건의 `help / harm / neutral` 3선택 구조
- `trade` / `item` 등 기존 effect tag는 필요 시 사건 행동 표현용으로 사용 가능
- 상인 장면 안에서 물약·붕대·음식·밧줄·연막 같은 물건을 소재로 사용하는 것

중요한 구분은 다음과 같다.

> 사건 문장에 아이템이 등장하는 것과 아이템 시스템이 존재하는 것은 다르다.

상인에게서 산 물건은 **그 사건에서 바로 사용**되거나, 최대 **다음 전투 1회에만 적용되는 예약 효과**로 바뀐다. 플레이어 소지품으로 들어가지 않는다.

## 3. 작업표 변경 원칙

현재 `CAMPAIGN_REWORK_WORK_ASSIGNMENT.md`의 `F5 아이템 콘텐츠` 노드는 삭제한다.

의존성 그래프에서 다음 관계를 제거한다.

```text
D3 → F5
F5 → E3
```

`E3 사건`은 F5를 기다리지 않는다. 상인 골드 비용과 효과 해석은 E3의 사건 규칙 계약으로 들어간다.

기반 계층 설명도 `F1~F5`가 아니라 F5 삭제 후 실제 남은 항목 기준으로 갱신한다.

현재 작업표의 총 항목 수, 시작 가능 작업 목록, F5 행, F5를 언급하는 설명은 함께 정리한다.

과거 Superpowers Spec/Plan은 역사 기록이므로 원칙적으로 다시 쓰지 않는다. 현재 공식 작업표와 현재 시스템 문서를 갱신 대상으로 한다.

## 4. 상인 사건의 핵심 정체성

공용 사건 중 `merchant`는 다음 한 문장으로 정의한다.

> 상인이 제시한 물건이나 서비스를 보고, 플레이어가 자기 골드를 써서 파티를 돕거나 방해하거나, 구매하지 않고 골드를 아끼는 사건.

기본 계약은 다음과 같다.

| outcome | 골드 | 결과 |
| --- | ---: | --- |
| `help` | 소비 | 파티에 긍정 효과 |
| `harm` | 소비 | 파티에 부정 효과 |
| `neutral` | 0G | 구매하지 않음, 별도 효과 없음 |

### 4.1 가격과 의도의 관계

`help`와 `harm`의 가격을 같게 맞출 필요는 없다.

가격은 `help/harm` 여부가 아니라 **실제 효과 강도와 서비스 가치**로 정한다.

예:

```text
도움  정상 치료 6G → 중회복
방해  약한 수면제 4G → 다음 전투 약한 불리
중립  거래하지 않음 0G
```

또는

```text
도움  간단한 붕대 3G → 소회복
방해  강한 독성 시술 10G → 강한 불리
중립  거래하지 않음 0G
```

전체 콘텐츠 풀에서 싼 선택지가 특정 outcome에 치우치지 않게 한다.

## 5. 골드 경제 기준

현재 캠페인 경제 기준은 다음과 같다.

- 시작 현재 골드: `10G`
- 위험도별 3명 생존 골드 보상: `12 / 20 / 32 / 45 / 60G`
- 골드 승급: `150 / 320 / 600G`

상인 가격은 이 경제를 흔들지 않도록 아래 범위에서 시작한다.

| 가격대 | 비용 | 용도 |
| --- | ---: | --- |
| 소액 | 2~4G | 작은 즉시 효과 또는 작은 다음 전투 효과 |
| 일반 | 5~8G | 상인 사건의 주력 가격대 |
| 고가 | 9~11G | 강한 개입 |
| 특수 | 12~14G | 드문 최고급 서비스 |

`15G`는 잠정 상한 여유값으로 남기되 초기 merchant 30개에서는 기본적으로 사용하지 않는다.

### 5.1 밸런스 의도

- 시작 골드 10G로도 일부 도움/방해 선택을 실제로 사용할 수 있어야 한다.
- ★1 한 번의 정상 골드 보상 12G를 상인 한 번이 항상 다 소모하게 해서는 안 된다.
- 일반적인 상인 선택은 “고민되지만 지불 가능한” 수준이어야 한다.
- 강한 도움/방해는 연속 사용하기 어렵게 한다.
- 상인 소비가 골드 승급을 완전히 무력화하면 안 된다.
- 반대로 골드를 계속 모으기만 하는 것이 항상 최적이 되지 않게 한다.

B1 밸런스 재측정에서 실제 상인 등장 빈도와 소비량을 포함해 다시 검증한다.

## 6. 골드 부족 처리

골드가 부족해도 선택지는 숨기지 않는다.

예:

```text
응급 치료를 부탁한다 — 7G (골드 부족)
수면약을 사 준다 — 3G
거래하지 않는다 — 0G
```

규칙은 다음과 같다.

- 가격은 선택 전 화면에 표시한다.
- 현재 골드보다 비싼 `help/harm` 선택지는 표시하지만 실행할 수 없다.
- `neutral`은 항상 실행 가능하다.
- 골드가 부족하다고 다른 선택지로 자동 교체하지 않는다.
- 세 선택지의 outcome 자체는 항상 `help / harm / neutral` 하나씩 유지한다.

이 조건은 인벤토리 조건부 생성과 다르다. 선택지 데이터는 고정이고, 실행 가능 여부만 현재 골드와 가격을 비교한다.

## 7. 효과 지속 범위

상인 효과는 두 종류만 허용한다.

### 7.1 즉시형

구매가 실행된 사건에서 바로 처리하고 끝난다.

예:

- HP 회복
- HP 피해
- 현재 이동 피해 감소
- 현재 이동 피해 증가

### 7.2 다음 전투 1회형

구매 후 `다음 monster 사건 또는 보스전 1회`에 적용되고 즉시 사라진다.

예:

- 다음 전투 피해 감소
- 다음 전투 피해 증가
- 다음 전투 공격 유리
- 다음 전투 공격 불리

장기 상태가 되지 않도록 다음 제한을 둔다.

- 다음 전투 1회 이후 반드시 제거
- 던전 밖으로 유지 금지
- 원정 간 유지 금지
- 수량 없음
- 캐릭터별 장착 없음
- 여러 merchant 지속 효과 중첩 금지

구현 시 `pendingMerchantEffect` 같은 단일 예약 상태가 필요할 수 있으나, 이것은 인벤토리가 아니라 **다음 전투 한 번을 위한 임시 사건 효과**다.

이미 다음 전투형 효과가 있는 상태에서 새로운 다음 전투형 merchant 선택지를 어떻게 처리할지는 E3 구현 시 한 방식으로 고정한다. 우선순위는 새 효과로 교체하는 복잡한 시스템보다 **중첩을 만들지 않는 단순한 처리**다.

## 8. 정보상 제거

정보 판매는 merchant에서 제외한다.

상인이 다음을 판매하지 않는다.

- 비공개 활성 생태 규칙
- help/harm 정답
- 선택지 outcome
- 보스 약점
- 강한 연계용 clue
- 다음 지점의 실제 정답 정보
- 가짜 지도 상태

이유는 `INFORMATION_AND_DECEPTION.md`의 핵심이 이미 다음 구조이기 때문이다.

> 테마 전용 사건은 던전의 생태를 알아야 풀리고, 공용 사건은 그 장면을 자세히 읽어야 풀린다.

상인에게 돈을 주고 추론 정보를 사는 순간 기존 답사 기록·생태 규칙·상황 묘사 읽기의 가치가 약해진다.

따라서 merchant는 **정보를 파는 장소가 아니라 자원을 지불해 결과에 개입하는 장소**로 유지한다.

## 9. merchant 30개 최종 분류

기존 merchant 30개는 아래 5계열 × 6개로 재편한다.

| 계열 | 수량 | 중심 역할 |
| --- | ---: | --- |
| 치료 | 6 | 즉시 HP 관리, 일부 다음 전투 상태 |
| 식량·음료 | 6 | 즉시 HP 또는 다음 전투 상태 |
| 전투 준비 | 6 | 다음 전투 1회 효과 |
| 이동·안전 | 6 | 현재 이동/직후 위험 조정 |
| 수상한 서비스 | 6 | 고가·강한 도움/방해 |
| 합계 | 30 | |

기존 사건의 제목이나 소재가 새 계약에 맞으면 재사용할 수 있다. `저울`, `거스름돈`, `묶음 할인`처럼 본질이 “상인 사기 알아채기”에만 있는 사건은 억지로 살리지 않고 교체한다.

## 10. merchant 30개 콘텐츠 초안

아래 가격은 구현 초기값이며 B1에서 조정 가능하다.

### 10.1 치료 6개

#### M01 응급 약장수
- H `5G`: 정상 회복약 → 즉시 소~중회복
- X `4G`: 수면 성분이 강한 약 → 약한 즉시 피해 또는 다음 전투 약한 불리
- N `0G`: 거래하지 않음

#### M02 떠돌이 치료사
- H `7G`: 상처를 제대로 봉합 → 즉시 중회복
- X `3G`: 거친 처치 → 즉시 소피해
- N `0G`

#### M03 해독 전문상
- H `6G`: 정상 해독 처치 → 즉시 상태 개선/HP 보호
- X `5G`: 증상을 악화시키는 약 → 즉시 피해
- N `0G`

#### M04 붕대 장수
- H `3G`: 제대로 된 압박 붕대 → 즉시 소회복
- X `2G`: 피가 잘 멎지 않는 싸구려 붕대 → 즉시 소피해
- N `0G`

#### M05 진통제 상인
- H `4G`: 적정량 투여 → 다음 전투 피해 소폭 감소
- X `6G`: 과량 투여 → 다음 전투 불리
- N `0G`

#### M06 전문 치료소
- H `11G`: 고급 치료 → 즉시 대회복
- X `9G`: 위험한 시술 → 즉시 큰 피해
- N `0G`

### 10.2 식량·음료 6개

#### M07 물장수
- H `3G`: 깨끗한 물 → 즉시 소회복
- X `2G`: 상태가 좋지 않은 물 → 즉시 소피해
- N `0G`

#### M08 건조육 장수
- H `4G`: 잘 보관된 건조육 → 즉시 회복
- X `3G`: 상한 고기 → 즉시 피해
- N `0G`

#### M09 따뜻한 식사
- H `6G`: 제대로 된 식사 → 즉시 중회복
- X `4G`: 지나치게 무거운 식사 → 다음 전투 약한 불리
- N `0G`

#### M10 각성제 노점
- H `5G`: 적당한 각성제 → 다음 전투 유리
- X `7G`: 과도한 자극제 → 다음 전투 강한 불리
- N `0G`

#### M11 진정 음료
- H `4G`: 적정량 → 다음 전투 피해 소폭 감소
- X `5G`: 졸릴 정도로 과량 → 다음 전투 불리
- N `0G`

#### M12 농축 영양식
- H `8G`: 고급 영양식 → 즉시 회복 + 약한 다음 전투 이점
- X `6G`: 체질에 안 맞는 고농축 음식 → 즉시 불편 + 다음 전투 불리
- N `0G`

### 10.3 전투 준비 6개

#### M13 숫돌 장수
- H `5G`: 제대로 무기 정비 → 다음 전투 공격 유리
- X `3G`: 잘못된 연마 → 다음 전투 공격 불리
- N `0G`

#### M14 방어구 수선공
- H `6G`: 방어구 보강 → 다음 전투 피해 감소
- X `4G`: 관절을 지나치게 조임 → 다음 전투 불리
- N `0G`

#### M15 연막 도구상
- H `5G`: 적절한 연막 준비 → 다음 전투 피해 감소
- X `5G`: 파티 시야까지 가리는 연막 → 다음 전투 피해 증가
- N `0G`

#### M16 투척물 상인
- H `6G`: 몬스터 진형을 깨는 투척물 → 다음 전투 유리
- X `4G`: 파티 동선을 방해하는 투척물 → 다음 전투 불리
- N `0G`

#### M17 독성 물질 장수
- H `8G`: 몬스터 상대용 독성 물질 → 다음 전투 강한 유리
- X `9G`: 파티 장비에 해로운 약물 → 다음 전투 강한 불리
- N `0G`

#### M18 장비 대여상
- H `7G`: 튼튼한 임시 장비 → 다음 전투 유리

## 11. 이동·안전 계열 제한

이동·안전 merchant는 지도 생성 규칙을 바꾸지 않는다.

금지:

- 분기 추가
- 분기 삭제
- 지점 삭제
- 지점 건너뛰기
- 보스방 직행
- 방문하지 않은 지점 완료 처리
- 강한 연계 조건 무시
- 지도 시드 변경

허용:

- 현재 이동 피해 증감
- 다음 지점 진입 시 1회 피해 보정
- 현재 장면 위험 보정

따라서 E1 지도 생성은 merchant와 독립적으로 유지된다.

## 12. 기존 merchant 30개 수정 기준

현재 공용 merchant 데이터에는 `저울`, `거스름돈`, `묶음 할인`, `마지막 하나`, `금 간 병뚜껑`, `새 칼의 흠집`처럼 거래 사기를 관찰해 피하는 사건이 다수 있다.

기존 사건을 아래 기준으로 분류한다.

### A. 소재 유지 + 계약 재작성

물약·붕대·해독제·검·식량 등 새 5계열 안에 자연스럽게 들어가는 사건.

- 제목/상황 소재는 재사용 가능
- H/X/N은 새 골드 계약으로 다시 작성
- H/X에는 가격과 실제 효과를 부여
- N은 구매하지 않음으로 통일

### B. 부분 재사용

장면은 살릴 수 있지만 현재 정답 구조가 “사기를 간파한다”에 치우친 사건.

- 관찰 요소는 분위기나 선택 맥락으로 남길 수 있음
- 핵심 판단은 `내 골드를 써서 도움/방해`로 변경

### C. 교체

다음과 같은 사건은 새 merchant 정체성과 맞지 않으면 과감히 교체한다.

- 저울 눈속임만 맞히는 사건
- 거스름돈 계산만 맞히는 사건
- 묶음 할인 계산만 맞히는 사건
- 흥정 자체가 핵심이고 파티에 실제 도움/방해가 없는 사건

수량 30을 지키기 위해 기존 내용을 억지로 보존하지 않는다.

## 13. 데이터 계약 변경 방향

현재 `SituationEvent`의 조언 계약을 유지하되 merchant 선택에는 **골드 비용과 실제 사건 효과를 해석할 수 있는 데이터**가 필요하다.

구현 단계에서 필요한 최소 계약은 다음 개념을 표현해야 한다.

```text
merchant advice
- outcome: help | harm | neutral
- goldCost: number
- effect: 즉시형 또는 다음 전투 1회형
```

세부 타입명과 필드 구조는 구현 Plan에서 현재 도메인 타입을 확인한 뒤 최소 변경으로 정한다.

Spec은 다음을 강제한다.

- `neutral.goldCost === 0`
- `help.goldCost > 0`
- `harm.goldCost > 0`
- 비용은 음수 불가
- 현재 골드보다 큰 비용은 실행 거절
- 실제 결제된 골드는 현재 골드에서만 차감
- 상인 구매 자체는 누적 획득 골드를 감소시키지 않음
- 환불/이동을 새 획득 골드로 중복 기록하지 않음

`effectTags.item`을 삭제하거나 이름을 바꾸는 것은 이 Spec의 필수 목표가 아니다. 현재 콘텐츠에서 사건 행동을 분류하는 데 유용하면 유지한다. 다만 `item` 태그가 존재한다고 인벤토리 시스템을 추가해서는 안 된다.

## 14. E3 사건 규칙 책임

E3는 merchant 사건에서 다음을 책임진다.

1. 선택지 비용 확인
2. 골드 부족 선택 실행 거절
3. 조언 수용/의심/적발 처리
4. 실제 실행될 때만 골드 차감
5. 즉시 효과 적용
6. 필요 시 다음 전투 1회 효과 등록
7. 다음 전투 효과 소비 시 제거

중요:

> 조언을 선택했다고 바로 결제하지 않는다.

현재 조언 시스템은 파티원들이 수용/의심/적발을 판정하고, **한 명이라도 수용해야 행동이 실행**된다. 따라서 merchant 구매 비용도 실제 행동이 실행될 때만 차감하는 것이 기본 원칙이다.

아무도 수용하지 않아 기본 결과로 흘러가면 구매도 성립하지 않고 골드도 소모하지 않는다.

방해가 즉시 적발되어 실행되지 않는 경우도 구매가 성립하지 않는 방향을 기본으로 한다.

이 규칙은 “길잡이가 직접 행동하지 않고 조언한다”는 게임 원칙을 보존한다.

## 15. 신뢰와 merchant

merchant도 일반 공용 사건과 동일한 조언 반응 규칙을 사용한다.

- 도움 수용 → 실제 긍정 효과 + 기존 도움 신뢰 판정
- 방해 수용 → 실제 부정 효과 + 기존 방해 신뢰 판정
- 방해 적발 → 구매/효과 미실행 + 기존 적발 신뢰 판정
- 중립 수용 → 구매하지 않음 + 즉시 신뢰 변화 없음
- 전원 의심 → 기본 결과 + 골드 변화 없음

merchant 때문에 별도의 상인 신뢰 시스템을 만들지 않는다.

## 16. UI 요구사항

상인 사건은 일반 사건 카드 구조를 유지한다.

추가로 필요한 것은 가격 표시와 구매 불가 표시뿐이다.

예:

```text
[응급 치료를 부탁한다]  7G
[수상한 약을 사 준다]   4G
[거래하지 않는다]       0G
```

골드 부족:

```text
[응급 치료를 부탁한다]  7G  · 골드 부족
```

선택 전에는 다음을 표시하지 않는다.

- `help`
- `harm`
- `neutral`
- 실제 효과 수치
- 방해 적발 확률을 별도 상인 정보로 추가 표시

가격은 정보이지만 outcome은 아니다.

## 17. 밸런스 검증 항목

B1 또는 merchant 전용 테스트에서 최소 다음을 확인한다.

### 경제

- 시작 10G에서 실제로 선택 가능한 merchant 사건이 존재함
- ★1 구간에서 상인 한 번으로 평균 보상의 대부분을 항상 잃지 않음
- 정상 플레이에서 merchant 사용 때문에 승급이 사실상 불가능해지지 않음
- 상인을 계속 무시하는 전략과 적절히 사용하는 전략 사이에 결과 차이가 있음
- 방해 투자가 전멸 유품 수입과 결합될 때 무조건적인 최적 전략이 되지 않음

### 콘텐츠

- merchant 30개
- 5계열 각각 6개
- 모든 사건 H/X/N 정확히 1개씩
- 모든 N 비용 0G
- 모든 H/X 비용 양수
- 가격만 보고 outcome을 안정적으로 추측할 수 있는 편향이 없음
- 정보 판매 사건 0개
- 인벤토리 전제 문구 0개

### 상태

- 다음 전투형 효과는 1회 후 제거
- 던전 종료 후 merchant 효과 0개
- 원정 간 merchant 효과 유지 0개
- 중첩 불가 규칙 위반 0개

## 20. 수용 기준

이 설계가 구현 완료되었다고 보기 위한 기준은 다음과 같다.

1. 작업표에서 독립 F5 아이템 작업이 사라진다.
2. 인벤토리·아이템 소지·수량·원정 간 아이템 상태가 존재하지 않는다.
3. merchant 30개가 5계열 × 6개로 구성된다.
4. 모든 merchant는 H/X 구매, N 비구매 계약을 따른다.
5. H/X 가격은 효과 강도로 정하며 동일 가격을 강제하지 않는다.
6. N은 항상 0G다.
7. 골드 부족 선택지는 보이지만 실행할 수 없다.
8. 비용은 실제 조언이 수용되어 거래가 실행될 때만 차감된다.
9. 효과는 즉시 또는 다음 전투 1회까지만 지속된다.
10. 정보상/정보 두루마리/가짜 지도 시스템이 없다.
11. 이동·안전 merchant가 지도 구조 자체를 바꾸지 않는다.
12. 상인 소비가 누적 획득 골드 통계를 감소시키지 않는다.
13. 기존 정보·생태·신뢰 시스템의 핵심 계약을 변경하지 않는다.
14. B1이 상인 소비를 포함한 경제를 재측정할 수 있는 상태가 된다.

## 21. 설계 요약

```text
기존
골드 → 아이템 구매 → 보관 → 나중에 사용
                     ↓
          인벤토리/수량/조건부 선택지 필요

변경
골드 → merchant 조언 실행 → 즉시 효과
                         또는 다음 전투 1회 효과

help    = 내 골드를 써서 파티를 돕는다
harm    = 내 골드를 써서 파티를 방해한다
neutral = 아무것도 사지 않고 골드를 아낀다
```

상인 사건은 별도 아이템 시스템이 아니라 **현재 골드를 이용해 도움과 배신 의도를 실행하는 공용 사건**이다.
