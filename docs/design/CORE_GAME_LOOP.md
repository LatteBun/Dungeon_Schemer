# 핵심 게임 루프

## 캠페인 루프

```text
캠페인 생성
→ 인트로
→ 공고 게시판
→ 계약과 임시 파티 편성
→ 던전 탐험
→ 보스전
→ 정산·위험도·승급
→ 월드턴
→ 다음 게시판 또는 캠페인 엔딩
```

캠페인은 던전 15개를 모두 클리어하거나 조기 엔딩이 발생할 때까지 이 흐름을 반복한다. 한 원정의 HP·신뢰·사망·자원·던전 결과는 다음 원정에도 남는다.

## 1. 캠페인 생성

캠페인 시드로 다음을 한 번에 확정한다.

- 테마 3종을 5개씩 나눈 고정 던전 15개와 초기 위험도 ★1 3개 · ★2 4개 · ★3 4개 · ★4 3개 · ★5 1개
- 던전마다 초기 위험도로 정해지는 일반 Depth 수, 생태 패키지의 활성 규칙 3개와 출현 잡몹 목록. 시드는 같은 테마·위험도 안에서만 패키지를 바꾼다
- 5직업 × 6명, 5성격 × 6명의 캐릭터 30명
- 캐릭터별 20~45의 소지 골드와 성격별 초기 신뢰
- C급 길잡이, 현재 명성 30, 현재 골드 10, 누적 획득 골드 0

시작 골드 10은 누적 획득 골드에 포함하지 않는다. 캐릭터는 캠페인 도중 충원되지 않으므로 사망과 신뢰 0은 되돌릴 수 없다.

## 2. 공고 게시판

길잡이 등급으로 진입할 수 있는 위험도의 미클리어 던전을 위험도 높은 순으로 최대 5개까지 게시한다. 같은 위험도 안의 순서는 캠페인 시드와 월드턴으로 결정한다. 진입 가능한 공고가 5개보다 적으면 가장 가까운 진입 불가 던전을 위험도 낮은 순으로 채우고 `rankTooLow` 사유를 붙인다.

- 모든 공고는 출전 가능한 캐릭터 중 서로 다른 직업 **정확히 3명**의 임시 파티를 가진다. 부분 파티는 게시하지 않는다.
- 한 게시판에서는 같은 캐릭터를 두 공고에 중복 배정하지 않는다. 완전한 파티를 만들 수 있는 수만큼만 공고를 만든다.
- 던전과 캐릭터는 영구 1:1 관계가 아니다. `던전 A · 파티 1`로 원정한 뒤에도 다음 게시판은 출전 가능 풀에서 파티를 다시 계산한다.
- 방금 원정을 마친 캐릭터도 출전 가능하면 다음 게시판에 다시 나올 수 있다.
- 게시판에서는 생태 규칙이나 별도의 공개 환경 특성을 보여주지 않는다. 생태 추론은 계약 뒤 원정에 진입하면서 시작한다.
- 진입 불가 공고는 숨기지 않고 사유를 보여주되 선택할 수 없다.
- 진입 가능한 던전이 하나도 없으면 막힌 공고를 보여준 뒤 실직 엔딩으로 넘어간다. 완전한 파티를 하나도 만들 수 없는 경우도 같은 방식으로 다음 엔딩 판정에 넘긴다.

## 3. 계약과 파티 확인

계약 전에는 던전 이름과 현재 위험도, 진입 가능 여부와 잠금 사유, 계약 보상, 출전 캐릭터별 직업·성격·HP·신뢰·소지 골드를 확인한다. 생태 정답이나 추론용 규칙은 계약 전 정보가 아니다.

계약을 수락하면 E1 지도를 생성해 전체 경로 구조를 보여주고, E2가 C1의 `activeRuleIds` 3개를 다시 뽑지 않은 채 **현재 위험도**에 따라 공개한다.

```text
★1~2 → 3개
★3~4 → 2개
★5   → 1개
```

던전별 공개 우선순위는 고정되어 재도전으로 위험도가 오르면 공개 집합이 이전 집합의 부분집합으로 줄어든다.

## 4. 던전 탐험

```text
계약 수락
→ 지도와 공개 생태 확인
→ 지도에서 다음 지점 선택
→ 방문한 사건의 상황 묘사를 보고 조언 3개 중 하나를 선택
→ 살아 있는 파티원별 수용·의심·적발
→ 실행 또는 기본 결과
→ 사건 결과와 신뢰 변화 확인
→ 지도 복귀
```

모든 일반 노드는 조언 기회다. 도움·방해·중립과 정합·모순은 내부 판정값이며 선택 전후 UI에 정답 라벨로 공개하지 않는다. 플레이어는 E2가 공개한 생태와 현장 관찰, 이전 결과를 근거로 판단한다.

보스 관련 정보는 E3가 일반 지도 안의 **숨은 exact-once `special` cut**으로 예약한다. ★1·★2에서는 1개, ★3~★5에서는 2개의 cut을 두며, cut의 실제 사건 ID는 방문 순간 결정한다.

일반 사건의 category·선택·중복 방지·약한/강한 연계와 방문 시 물질화 방식은 E3가 소유한다. E2는 조언 판정과 `executed`만 소유하고, E3는 확정된 사건 효과와 공통 BattleEngine 결과를 저장한다.

조언 반응은 살아 있는 파티원마다 독립적으로 판정한다. 한 명이라도 수용하면 E2가 `executed: true`를 반환하고 E3가 선택 조언의 사건 효과를 정확히 한 번 적용한다. 아무도 수용하지 않으면 E3가 사건의 기본 결과를 적용한다. 한 명이 방해를 적발해도 다른 한 명이 수용했다면 실행 자체를 취소하지 않는다.

즉시형 신뢰는 사건 결과가 실제로 나온 뒤 확정한다. 보스 정보의 accepted/suspected 결과 기반 신뢰는 보스전까지 미루고, 방해가 그 자리에서 적발된 경우만 즉시 페널티를 적용한다.

merchant는 공용 사건이며 도움/방해 조언은 현재 골드를 써 즉시 효과 또는 다음 전투 한 번 효과를 남기고, neutral은 0G 비구매다. 비용 확인·실제 결제·효과 적용과 pending 정리는 E3 책임이다.

진행 화면의 하단 콘솔은 `행동 / 조언`과 `진행 기록`을 전환한다. 진행 기록에서 현재 원정의 공개 생태와 관찰 단서, 조언 반응·사건 결과·전투 기록을 다시 확인할 수 있지만, 관찰 단서를 숨은 규칙의 정답으로 자동 승격하지 않는다.

## 5. 보스전

보스방에서는 새 조언이나 직접 전투 개입을 제공하지 않는다. 현재 HP, 사건 결과, pending merchant effect, 수용한 보스 조언을 입력으로 전투를 자동 해결한다. 보스 조언의 유형과 의심 결과도 여기서 검증한다.

전투는 턴 단위로 진행하며 각 턴의 행동과 피해를 기록으로 남긴다. 플레이어는 공격이나 방어를 직접 조작하지 않는다. 앞선 판단과 누적된 상태가 결과로 드러난다.

파티원 한 명 이상 생존하면 던전 클리어, 전멸하면 실패다.

## 6. 정산과 다음 캠페인 상태

`settlement` 단계는 다음 순서로 상태를 만든다.

1. 생존자, 신뢰, 계약 보상 또는 전멸 손실과 유품 계산
2. 클리어한 던전 제거 또는 실패한 던전의 위험도 1 상승
3. 승급 가능 여부 갱신. 승급 자체는 플레이어가 승급 화면에서 직접 선택한다

`settlement`가 끝나면 `worldTurn` 단계로 넘어가 출전하지 않은 캐릭터를 휴식과 백그라운드 원정에 배정한다. `worldTurn`이 끝난 뒤에 엔딩을 판정하고, 계속되면 다음 게시판을 생성한다.

다음 게시판은 이전 게시판의 파티·던전 연결을 복사하지 않는다. `seed/worldTurn` 스트림으로 공고와 임시 파티를 함께 새로 만들며, 같은 입력에서는 결정적으로 같고 월드턴이 달라지면 다시 섞인다.

진입 가능한 던전이 하나도 없어 공고를 만들 수 없을 때도 같은 방식으로 즉시 `실직` 엔딩을 판정한다.

## 진행 단계

| 단계 | 식별자 | 역할 |
| --- | --- | --- |
| 인트로 | `intro` | 길잡이 역할과 캠페인 목표 안내 |
| 공고 게시판 | `campaignBoard` | 던전 공고 비교와 계약 선택 |
| 파티 확인 | `partyIntro` | 편성된 출전 캐릭터의 개인 상태 확인 |
| 경로 선택 | `pathChoice` | 계약 직후 공개된 전체 지도에서 다음 지점 선택 |
| 조언 | `adviceOpportunity` | 상황 묘사를 보고 조언 세 개 중 하나를 선택 |
| 보스전 | `bossFight` | 누적 상태로 턴 단위 자동 전투와 정보 검증 |
| 정산 | `settlement` | 보상·손실·던전 위험도 갱신과 승급 화면을 통한 승급 선택 |
| 월드턴 | `worldTurn` | 비출전 캐릭터의 휴식과 백그라운드 원정 처리 |
| 캠페인 종료 | `campaignEnded` | 정상 완주 등급 또는 조기 엔딩 표시 |

규칙에 없는 단계 전이는 거부한다. 전멸로 원정이 중간 종료되면 남은 사건과 보스전을 건너뛰고 정산으로 간다. `intro`는 캠페인당 한 번만 지나간다.

## 캠페인 자원

| 자원 | 의미 |
| --- | --- |
| 현재 명성 | 무료 승급 조건에 사용하며 0 미만이 될 수 없음 |
| 현재 골드 | 상인·사건 소비와 골드 승급에 사용하며 0 미만이 될 수 없음 |
| 누적 획득 골드 | 모든 실제 골드 수입을 더하며 엔딩 회고에만 사용 |
| pending merchant effect | 다음 `monster` 전투 또는 보스전에 한 번만 적용할 예약 효과. 없으면 `null` |

던전 진입 자격은 명성이 아니라 길잡이 등급이 정한다. 명성은 그 등급을 올리는 데 쓴다. pending merchant effect는 하나만 유지하며, 지도와 사건의 사전 배치를 바꾸지 않는다.

## 결과 피드백

모든 주요 선택은 다음 세 시점의 결과를 연결해서 보여준다.

- 즉시: 조언 반응, 사건 결과, HP·신뢰·골드 변화
- 원정 정산: 생존자, 보상, 명성, 유품, 던전 결과
- 캠페인: 승급 가능 여부, 월드턴의 회복과 백그라운드 결과, 다음 공고, 엔딩 위험
