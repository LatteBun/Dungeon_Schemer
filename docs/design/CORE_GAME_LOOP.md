# 핵심 게임 루프

## 캠페인 루프

```text
캠페인 생성
→ 공고 게시판
→ 계약과 파티 선택
→ 던전 탐험
→ 보스전
→ 정산·승급·파티 유지
→ 다음 게시판 또는 캠페인 엔딩
```

캠페인은 던전 15개를 모두 클리어하거나 조기 엔딩이 발생할 때까지 이 흐름을 반복한다. 한 탐험의 HP·신뢰·사망·자원·던전 결과는 다음 탐험에도 남는다.

## 1. 캠페인 생성

캠페인 시드로 다음을 한 번에 확정한다.

- C 6개, B 4개, A 3개, S 2개의 던전과 같은 등급 안의 정렬 순서
- 서로 다른 직업으로 구성된 3인 파티 15팀
- 직업·성격·초기 신뢰가 정해진 예비 인원 6명
- 파티원별 10~30의 소지 골드
- C급 길잡이, 현재 명성 0, 현재 골드 10, 누적 획득 골드 0

시작 골드 10은 누적 획득 골드에 포함하지 않는다.

## 2. 공고 게시판

남은 던전을 C→B→A→S 순으로 정렬하고 같은 등급은 캠페인 시드 순서를 유지한다. 앞에서부터 최대 5개 던전을 출전 가능한 완성 파티와 시드로 짝짓는다.

- 완성 파티가 1~4팀이면 그 수만큼만 공고를 만든다.
- 던전과 파티는 영구 1:1 관계가 아니다.
- 같은 던전은 실패 후 다른 파티와 연결될 수 있다.
- 방금 탐험한 파티도 다음 게시판에 즉시 등장할 수 있다.
- 명성이 부족한 공고는 보이지만 선택할 수 없다.

## 3. 계약과 파티 확인

계약 전에 던전 등급, 지원 최소 명성, 계약 보상, 전체 경로와 위험 성격, 파티원별 직업·성격·HP·신뢰·소지 골드를 확인한다.

## 4. 던전 탐험

```text
지도에서 다음 지점 선택
→ 정보 전달 기회가 있으면 카드 선택과 개인별 반응
→ 몬스터·휴식·상인·특수 사건
→ 지원·방해·아이템·거래·관망 행동
→ 즉시 결과 확인
→ 지도 복귀
```

카드는 모든 지점에서 나오지 않는다. 실제 선택 경로의 정보 전달 기회 횟수는 C 2회, B 3회, A 4회, S 5회다. 사건 행동은 카드와 별도로 선택한다.

## 5. 보스전

보스방에서는 새 카드나 직접 전투 개입을 제공하지 않는다. 현재 HP, 사건 결과, 아이템, 수용한 보스 정보 카드를 입력으로 전투를 자동 해결한다. 보스 정보의 진위와 의심 결과도 여기서 검증한다.

파티원 한 명 이상 생존하면 던전 클리어, 전멸하면 실패다.

## 6. 정산과 다음 캠페인 상태

정산은 다음 순서로 상태를 만든다.

1. 생존자, 신뢰, 계약 보상 또는 전멸 손실과 유품 계산
2. 던전 제거 또는 위험 등급 상승
3. 승급 점수 계산과 영구 등급 갱신
4. 예비 인원 충원 또는 생존자 자동 재편
5. 출전하지 않은 모든 생존자의 HP 회복
6. 엔딩 판정
7. 계속되면 다음 게시판 생성

## 진행 단계

| 단계 | 식별자 | 역할 |
| --- | --- | --- |
| 공고 게시판 | `campaignBoard` | 던전·파티 공고 비교와 계약 선택 |
| 파티 확인 | `partyIntro` | 출전 파티의 개인 상태 확인 |
| 경로 선택 | `pathChoice` | 공개된 전체 지도에서 다음 지점 선택 |
| 정보 전달 | `infoOpportunity` | 일부 지점에서 진실·거짓·중립 카드 선택 |
| 사건 | `event` | 사건별 행동 선택과 결과 처리 |
| 보스전 | `bossFight` | 누적 상태로 자동 전투와 정보 검증 |
| 정산 | `settlement` | 보상·손실·파티·던전·승급 갱신 |
| 캠페인 종료 | `campaignEnded` | 정상 완주 등급 또는 조기 엔딩 표시 |

규칙에 없는 단계 전이는 거부한다. 전멸로 탐험이 중간 종료되면 남은 사건과 보스전을 건너뛰고 정산으로 간다.

## 캠페인 자원

| 자원 | 의미 |
| --- | --- |
| 현재 명성 | 공고 지원과 승급 점수에 사용하며 음수가 될 수 있음 |
| 현재 골드 | 상인·사건에서 소비하며 0 미만이 될 수 없음 |
| 누적 획득 골드 | 모든 실제 골드 수입을 더하며 소비해도 줄지 않음 |
| 승급 점수 | `현재 명성 × 2 + 누적 획득 골드` |

식량과 개별 물품은 탐험 자원 또는 아이템으로 별도 관리한다.

## 결과 피드백

모든 주요 선택은 다음 세 시점의 결과를 연결해서 보여준다.

- 즉시: 카드 반응, 사건 결과, HP·신뢰·아이템 변화
- 탐험 정산: 생존자, 보상, 명성, 유품, 던전 결과
- 캠페인: 승급, 파티 충원·재편·회복, 다음 공고, 엔딩 위험
